## 1. 출력 - print `p.3`

Python에서 `print()` 함수는 원하는 정보나 자료를 콘솔에 출력하는 데 사용됩니다 `p.4`. 하나의 값을 출력할 때는 `print("출력할 내용")`과 같이 사용하며 `p.5`, 여러 자료를 출력하고 싶을 때는 콤마(`,`)로 구분하여 `print(값1, 값2)` 형태로 사용합니다 `p.6` `p.7`. 여러 줄의 출력을 원할 경우 `print()` 함수를 여러 번 사용할 수 있습니다 `p.8` `p.9`.

> **쉬운 설명**
>
> `print()` 함수는 컴퓨터가 우리에게 말을 걸게 하는 방법이라고 생각하면 쉬워요. 우리가 "안녕?"이라고 말하면 친구가 듣는 것처럼, `print()` 안에 무언가를 넣으면 컴퓨터가 그 내용을 우리에게 보여주는 거예요.
>
> - **하나만 출력할 때:** `print("점심 뭐 먹지?")` 라고 하면 컴퓨터 화면에 "점심 뭐 먹지?"가 나타나요.
> - **여러 개를 출력할 때:** `print("나이:", 20, "살")`처럼 여러 정보를 한 번에 보여주고 싶을 때는 콤마(`,`)로 연결하면 돼요. 그럼 "나이: 20 살" 이렇게 나옵니다. 컴퓨터는 콤마로 구분된 값들 사이에 자동으로 한 칸 띄어쓰기를 해준답니다.
> - **여러 줄 출력할 때:** 만약 삼행시처럼 "하늘", "땅", "바람"을 각각 다른 줄에 출력하고 싶다면, `print("하늘")`, `print("땅")`, `print("바람")` 이렇게 `print()`를 여러 번 사용하면 됩니다. 한 번 `print()`를 사용하면 자동으로 다음 줄로 넘어가서 출력돼요!

## 2. 기본 자료형 `p.10`

Python에는 여러 가지 **기본 자료형**이 있으며, 이들은 각기 다른 종류의 데이터를 표현합니다.

> **쉬운 설명**
>
> 자료형은 컴퓨터가 데이터를 어떤 종류로 이해할지 알려주는 '꼬리표' 같은 거예요.

### 숫자형 (Number) `p.11`

숫자로 이루어진 자료형입니다.

- **정수 (integer):** `3` (소수점이 없는 숫자)
- **실수 (float):** `3.14` (소수점이 있는 숫자)
- **복소수:** `3+4j` (실수부와 허수부를 가짐)

숫자형끼리는 다양한 연산이 가능합니다.

### 문자열 (String) `p.12`

문자나 문자들을 늘어놓은 것입니다.

- 큰따옴표(`" "`) 또는 작은따옴표(`' '`)로 감싸서 표현합니다.
- 예: `'Hello!'`, `'3.14'`, `"3.14"`

### 리스트 (List) `p.13`

여러 자료를 순서대로 보관하는 자료형입니다.

- 대괄호(`[]`) 안에 콤마(`,`)로 구분하여 원소를 나열합니다.
- 다른 종류의 자료형을 함께 담을 수 있습니다. 예: `['a', 'b']`, `['a', 2]`
- 자료 안에 **순서**가 존재합니다.

### 주석 (Comment) `p.14`

코드에 대한 설명을 추가하는 부분으로, 컴퓨터는 주석을 **무시**하고 실행하지 않습니다.

- **한 줄 주석:** `#` 기호를 사용합니다.
- **여러 줄 주석:** `""" """` 또는 `''' '''` (따옴표 세 번)을 사용합니다.

> **쉬운 설명**
>
> - **숫자형 (Number):** 우리가 일상생활에서 쓰는 숫자와 같아요.
>   - 정수: 1, 2, 100처럼 딱 떨어지는 숫자. 예: 시험 점수 90점
>   - 실수: 3.14, 0.5처럼 소수점이 있는 숫자. 예: 키 175.5cm
>   - 복소수: 수학에서 배우는 형태의 숫자인데, 프로그래밍에서는 잘 안 쓸 수도 있어요. `a + bj`
>   - 숫자들은 서로 더하거나 빼거나 곱할 수 있죠!
> - **문자열 (String):** 글자들의 모음이에요. 친구에게 메시지를 보내거나, 책을 읽는 것처럼 글자로 된 정보는 모두 문자열이에요.
>   - 반드시 **큰따옴표 또는 작은따옴표**로 감싸야 해요. 컴퓨터에게 "이건 글자야!" 하고 알려주는 거죠.
>   - 예: `"안녕하세요!"`, `'파이썬 재미있다'`, `"123"` (숫자처럼 보이지만 따옴표 안에 있으면 글자예요!)
> - **리스트 (List):** 여러 가지 물건을 담을 수 있는 '장바구니'와 같아요.
>   - 여러 개의 자료를 한꺼번에 담아 놓을 수 있어요. 심지어 숫자, 글자 등 **다른 종류의 자료**도 한 바구니에 같이 담을 수 있습니다.
>   - 순서가 중요해요! 리스트에 담긴 물건들은 순서대로 놓여 있어서, 첫 번째 물건, 두 번째 물건처럼 정확히 집어낼 수 있어요.
>   - 예: `['사과', '바나나', '딸기']` 또는 `[1, 'hello', 3.14]`
> - **주석 (Comment):** 코드 옆에 달아놓는 '메모' 같은 거예요.
>   - 우리가 코드를 이해하기 쉽게 설명하거나, 잠시 사용하지 않을 코드를 표시할 때 사용해요.
>   - 컴퓨터는 주석을 보면 "아, 이건 나한테 시키는 게 아니구나!" 하고 그냥 지나쳐 버려요. 실행되지 않아요!
>   - `#`을 쓰면 그 줄의 나머지 부분이 전부 주석이 되고, `"""` 또는 `'''`로 감싸면 여러 줄을 한 번에 주석으로 만들 수 있어요.

## 3. 변수 `p.15`

**변수(Variable)**는 자료를 "그릇"에 담아서 보관하고 필요할 때마다 재사용할 수 있게 하는 개념입니다 `p.16`. 자료를 담는 그릇에 이름을 붙여 사용하는 것이라고 이해할 수 있습니다.

### 변수 사용 방법 `p.17`

`변수 이름 = 자료` 형태로 사용합니다. `=` 기호는 오른쪽에 있는 자료를 왼쪽의 변수 이름에 할당한다는 의미입니다.

예시:
```python
num = 10          # 숫자 10을 num이라는 변수에 할당
name = "Michael"  # 문자열 "Michael"을 name이라는 변수에
grade = ['A+', 'B+', 'A0']  # 리스트를 grade라는 변수에
```

### 변수 이름 짓는 법 `p.18`

변수 이름에는 숫자, 알파벳, 한글, 언더바(`_`) 등을 사용할 수 있습니다.

- **권장:** 주로 알파벳으로 시작하는 이름을 사용합니다.

예시:
```python
python = "파이썬"
파이썬 = "Python"       # 한글 변수 이름도 가능
carrot_123 = 1234       # 알파벳, 언더바, 숫자 조합
```

### 변수 이름 규칙 (스네이크 표기법 vs. 카멜 표기법) `p.19`

- **스네이크 표기법 (Snake Case):** 단어와 단어 사이에 언더바(`_`)를 사용하여 구분합니다.
  - 예: `prod_name`, `prod_date`
- **카멜 표기법 (Camel Case):** 첫 단어는 소문자로 시작하고, 이후 단어의 첫 글자는 대문자로 시작합니다.
  - 예: `prodName`, `prodDate`

> **쉬운 설명**
>
> 변수는 정보를 담아두는 '이름표 붙은 상자'라고 생각하면 좋아요. 우리가 어떤 물건을 상자에 넣어두고 그 상자에 '책'이라고 이름표를 붙여놓으면, 나중에 '책' 상자를 찾아서 물건을 꺼내 쓸 수 있죠? 변수도 똑같아요!

### 변수 이름 주의점 `p.20`

- 변수 이름이 **숫자로 시작하면 안 됩니다**. (예: `1name` ❌)
- **숫자로만 구성된** 변수 이름은 금지됩니다. (예: `1234` ❌)
- Python 문법에서 사용하는 **예약어** (e.g., `print`, `if`, `for` 등)는 변수 이름으로 사용할 수 없습니다.
- 변수 이름에 **공백 문자**나 **연산자** (e.g., `+`, `-`, `%` 등)를 사용할 수 없습니다. (예: `prod name` ❌, `prod+date` ❌)

> - **변수 만들기:** `num = 10`이라는 코드는 "10이라는 숫자를 `num`이라는 이름표가 붙은 상자에 넣어두세요"라는 뜻이에요. 이제 `num`이라고 부르면 컴퓨터는 10이라는 숫자를 떠올리게 됩니다.
> - **왜 변수를 쓸까요?** 만약 `10`이라는 숫자를 여러 번 사용해야 한다면, 그때마다 `10`이라고 쓰는 것보다 `num`이라고 쓰는 게 훨씬 편하고, 나중에 이 값을 `20`으로 바꾸고 싶을 때 `num`의 값만 한 번 바꿔주면 되니 효율적이에요!
> - **변수 이름 규칙:**
>   - 숫자로 시작하면 안 돼요. `10apple`은 안 되고 `apple10`은 괜찮아요.
>   - 공백을 넣으면 안 돼요. `my name` (X) 대신 `my_name` (O)이나 `myName` (O)처럼 붙여 쓰거나 언더바를 써야 해요.
>   - 파이썬이 원래 쓰고 있는 단어(예약어)는 안 돼요. `print`나 `if` 같은 단어는 파이썬이 특별한 명령으로 알고 있기 때문에, 변수 이름으로 쓰면 컴퓨터가 혼란스러워해요.
> - **스네이크 표기법 vs 카멜 표기법:**
>   - **스네이크 표기법 (`my_name`):** 뱀처럼 언더바(`_`)가 기어가는 모양이라고 해서 스네이크 표기법이라고 불러요. 파이썬에서 가장 많이 쓰는 방식이에요.
>   - **카멜 표기법 (`myName`):** 낙타의 등처럼 중간에 대문자가 솟아올라 있다고 해서 카멜 표기법이라고 해요. 다른 프로그래밍 언어에서 자주 사용되지만 파이썬에서는 스네이크 표기법이 더 권장됩니다.

## 4. 자료형의 연산 `p.21`

Python에서는 자료형에 따라 다양한 연산이 가능합니다.

### 수학형 자료의 사칙연산 `p.22` `p.23`

- 더하기: `+`
- 빼기: `-`
- 곱하기: `*`
- 나누기: `/`

예시:
```python
print(3 + 5)  # 8
print(3 - 5)  # -2
print(3 * 5)  # 15
print(3 / 5)  # 0.6 (결과는 항상 실수형)
```

### 수학형 자료의 특수 연산 `p.25`

- **몫 연산자:** `//` (나눗셈의 몫을 정수로 반환)
- **나머지 연산자:** `%` (나눗셈의 나머지를 반환)
- **제곱 연산자:** `**` (거듭제곱)

예시:
```python
print(13 // 5)  # 2 (13을 5로 나눈 몫)
print(13 % 5)   # 3 (13을 5로 나눈 나머지)
print(2 ** 4)   # 16 (2의 4제곱)
```

### 문자형 자료의 연산 `p.27`

- **이어붙이기:** `+` (문자열과 문자열을 연결)
- **반복하기:** `*` (문자열을 특정 숫자만큼 반복)

예시:
```python
print("안녕" + "하세요")  # "안녕하세요"
print("안녕" * 3)         # "안녕안녕안녕"
```

> **쉬운 설명**
>
> ➕➖✖️➗ 자료형의 연산은 마치 수학 문제를 푸는 것과 같아요! 다만, 숫자와 글자는 푸는 방식이 조금 다르답니다.
>
> - **숫자형 연산:** 셈하기와 똑같아요!
>   - `+`, `-`, `*`, `/`는 우리가 아는 더하기, 빼기, 곱하기, 나누기예요.
>   - 예: `5 + 3`은 `8`이죠. `10 / 2`는 `5.0` (나누기는 결과가 항상 소수점 있는 숫자로 나와요)
>   - **조금 특별한 셈:**
>     - `//` (몫): `13 // 5`는 13을 5로 나눴을 때 '몫'인 `2`만 나와요. 나머지는 버리는 거죠.
>     - `%` (나머지): `13 % 5`는 13을 5로 나눴을 때 '나머지'인 `3`이 나와요.
>     - `**` (제곱): `2 ** 4`는 2⁴, 즉 `2 * 2 * 2 * 2 = 16`을 의미해요.
> - **문자열 연산:** 글자 가지고 장난치기!
>   - `+` (이어붙이기): 문자열을 `+`로 연결하면, 두 문자열이 합쳐져요. 예: `"안녕" + "하세요"`는 `"안녕하세요"`가 됩니다.
>   - `*` (반복하기): 문자열을 `*`와 숫자와 함께 사용하면, 그 문자열이 숫자만큼 반복돼요. 예: `"야호" * 3`은 `"야호야호야호"`가 됩니다.
>   - ⚠️ **주의!** 문자열끼리 빼거나 나눌 수는 없어요. 컴퓨터가 어떻게 해야 할지 모르거든요!

## 5. 문자열/리스트 접근하기 `p.29`

문자열과 리스트는 여러 원소로 이루어져 있으며, 각 원소의 **위치(인덱스)**를 이용하여 특정 원소에 접근하거나 일부분을 가져올 수 있습니다. 중요한 점은 인덱스는 항상 **0부터 시작**한다는 것입니다 `p.31`.

### 인덱스 (Index) `p.31`

문자열이나 리스트의 각 원소는 0부터 시작하는 고유한 위치 번호(인덱스)를 가집니다.

예시:
- 문자열 `"Ready"`의 각 문자는 `R(0)`, `e(1)`, `a(2)`, `d(3)`, `y(4)`와 같은 인덱스를 가집니다.
- 리스트 `[2, 4, 6, 8]`의 각 원소는 `2(0)`, `4(1)`, `6(2)`, `8(3)`과 같은 인덱스를 가집니다.
- 문자열에서는 공백 문자도 인덱스에 포함됩니다. 예: `"Hi! elice!"`는 0부터 9까지의 인덱스를 가집니다.

### 인덱싱 (Indexing) `p.32`

`index`를 사용하여 문자열이나 리스트의 **특정 위치의 단 하나의 원소**를 가져오는 방법입니다.

- **문법:** `String/List[index_number]`

예시:
```python
alpha = "Ready"
print(alpha[1])  # 'e'를 출력 (인덱스 1은 두 번째 문자)
```

### 슬라이싱 (Slicing) `p.33`

`index`를 사용하여 리스트나 문자열의 **일부분**을 잘라 가져오는 방법입니다.

- **문법:** `String/List[시작 인덱스 : 종료 인덱스]`
- 시작 인덱스: **포함됩니다.**
- 종료 인덱스: **포함되지 않습니다.** (종료 인덱스 바로 전까지 가져옵니다.)

예시:
```python
beta = [2, 4, 6, 8, 10, 12, 14]
print(beta[2:5])  # [6, 8, 10] 출력
                  # 인덱스 2(6)부터 인덱스 5(12) 전까지
```

> **참고:** 문자열 `"rescue"`와 `"secure"`가 다른 문자열인 이유는 원소의 배치 순서가 다르기 때문이며, 리스트 `[1, 2, 3]`과 `[3, 2, 1]`이 다른 리스트인 이유도 원소의 배치 순서가 다르기 때문입니다 `p.30`.

> **쉬운 설명**
>
> 문자열이나 리스트에서 원하는 부분을 쏙쏙 뽑아내는 방법이에요. 마치 책에서 특정 페이지를 찾거나, 어떤 단락만 잘라내는 것과 비슷하죠!
>
> - **인덱스 (Index):** 🏠 주소나 번지수 같은 개념이에요.
>   - 가장 중요한 규칙: 인덱스는 항상 **0부터 시작**해요! 우리가 보통 "첫 번째"라고 하면 1부터 세지만, 컴퓨터는 "첫 번째"를 0으로 센답니다.
>   - 예: `"Apple"`이라는 단어에서 A는 0번, p는 1번, 두 번째 p는 2번, l은 3번, e는 4번 주소를 가지고 있어요.
>   - 공백도 주소로 쳐줘요! `"Hi there"`에서 공백도 한 글자로 세서 주소가 매겨져요.
> - **인덱싱 (Indexing):** 딱 한 개의 원소만 뽑아내기!
>   - 주소를 알고 그 주소에 있는 한 글자나 한 항목만 콕 집어서 가져오는 방법이에요.
>   - `my_string[2]` 이렇게 대괄호 안에 주소(인덱스 숫자)를 넣으면 됩니다.
>   - 예: `word = "Python"`이라고 했을 때, `word[0]`은 `P`를, `word[3]`은 `h`를 출력해요.
> - **슬라이싱 (Slicing):** 여러 개의 원소를 잘라내기!
>   - 시작 주소부터 끝 주소까지, 원하는 범위의 여러 항목을 한꺼번에 가져오는 방법이에요.
>   - `my_list[시작_인덱스 : 끝_인덱스]` 이렇게 대괄호 안에 시작과 끝 주소를 `:`로 구분해서 넣어요.
>   - 여기서 중요! **끝_인덱스에 해당하는 항목은 포함되지 않아요!** ⛔️ 예를 들어, `[2:5]`라고 하면 2번, 3번, 4번 항목까지 가져오고 5번 항목은 가져오지 않는답니다.
>   - 예: `numbers = [10, 20, 30, 40, 50]`이라고 했을 때, `numbers[1:4]`는 `[20, 30, 40]`을 출력해요. (인덱스 1인 20부터 인덱스 4인 50 전까지!)
> - **순서의 중요성:** `"rescue"`와 `"secure"`는 글자는 같지만 순서가 다르기 때문에 컴퓨터는 완전히 다른 문자열로 인식해요. 리스트도 마찬가지예요. `[1, 2, 3]`과 `[3, 2, 1]`은 내용물은 같지만 순서가 달라서 다른 리스트라고 생각한답니다.

## 1. 입력 - input()

`input()` 함수는 사용자로부터 정보를 컴퓨터에게 전달할 때 사용됩니다 `p.4`. 사용자가 터미널에 값을 입력하고 Enter를 누르면, 이 값은 변수에 할당됩니다 `p.6`. `input()` 함수로 입력받은 모든 값은 기본적으로 **문자열(string) 자료형**으로 처리됩니다 `p.7`. 따라서 입력받은 문자열을 숫자처럼 사용하려면 **형 변환(type casting)**이 필요합니다 `p.9`. `int()` 함수로 정수로, `float()` 함수로 실수로, `str()` 함수로 문자열로, `list()` 함수로 리스트로 변환할 수 있습니다 `p.10`.

> **쉬운 설명**
>
> `input()` 함수는 여러분이 컴퓨터에게 질문을 하고, 컴퓨터가 그 답을 받아들이는 통로라고 생각하시면 쉬워요. 예를 들어, "당신의 이름은 무엇인가요?"라고 물어보면, 여러분은 키보드로 이름을 입력하겠죠? 그 이름이 `input()` 함수를 통해 컴퓨터에게 전달되는 거예요.
>
> 하지만 여기서 중요한 점! 컴퓨터는 여러분이 "10"이라는 숫자를 입력해도, 일단은 "열"이라는 글자로 받아들여요. 마치 여러분이 친구에게 "백 원"이라고 말했는데, 친구는 그게 돈이라는 의미가 아니라 그냥 "백 원"이라는 소리 자체로만 듣는 것과 비슷해요.
>
> 그래서 만약 이 "10"이라는 글자를 가지고 덧셈이나 뺄셈 같은 **계산**을 하고 싶다면, 컴퓨터에게 "이건 글자가 아니라 진짜 숫자야!"라고 알려줘야 해요. 이걸 **형 변환**이라고 부릅니다. `int("10")`이라고 하면 "10"이라는 글자가 정수 10으로 바뀌는 거죠.
>
> **비유:** 요리할 때 재료를 바로 쓰는 게 아니라, 껍질을 까거나 썰거나 하는 '가공'이 필요한 것과 같아요. `input()`으로 받은 재료는 '문자열 껍질'을 가진 상태이니, 요리(계산)에 맞게 '형 변환'이라는 가공을 해줘야 한답니다.

## 2. 논리형 자료와 비교연산

**논리형 자료(Boolean)**는 **참(True)**과 **거짓(False)** 두 가지 값만 가집니다 `p.13`. 이 논리형 자료는 숫자나 문자의 값을 비교하는 **연산자**를 통해 얻을 수 있습니다.

논리형 자료를 이용한 **논리 연산**을 통해 복잡한 논리식을 단순화할 수 있습니다 `p.16`.

> **쉬운 설명**
>
> 논리형 자료는 간단하게 **'예/아니오'**라고 답하는 것과 같아요. 컴퓨터에게 "3은 5보다 작니?"라고 물으면, 컴퓨터는 "응, 맞아! (True)"라고 답하죠. "7은 5와 같니?"라고 물으면, "아니, 틀려! (False)"라고 답하고요. 이런 '참/거짓'을 나타내는 것이 논리형 자료입니다.
>
> **비교 연산자**는 이런 질문을 던지는 도구들이에요. 마치 우리가 "내 키는 170cm와 같니?" (`==`), "내 나이는 20살보다 많니?" (`>`) 같은 질문을 하는 것과 같죠.
>
> 더 나아가, 복잡한 질문을 할 때는 **논리 연산자**를 사용해요.

### 비교 연산자 종류 `p.15`

| 연산자 | 의미 |
|--------|------|
| `==` | 같다 |
| `!=` | 다르다 |
| `>` | 왼쪽이 더 크다 |
| `<` | 오른쪽이 더 크다 |
| `>=` | 왼쪽이 크거나 같다 |
| `<=` | 오른쪽이 크거나 같다 |
| `and` | 모든 조건이 `True`일 때만 `True` `p.17` |
| `or` | 하나라도 `True`가 있으면 `True` `p.18` |
| `not` | 논리값을 뒤집음 (`True` ↔ `False`) `p.19` |

> - **`and` (그리고):** "오늘 날씨가 맑고(True) 그리고 바람도 안 불어(True)?" → 둘 다 맞아야 "응, 맞아!" (True)라고 답하죠. 하나라도 틀리면 "아니야!" (False).
> - **`or` (또는):** "오늘 점심으로 짜장면을 먹거나(True) 또는 짬뽕을 먹을까(False)?" → 둘 중 하나만 맞아도 "응, 맞아!" (True)라고 답할 수 있어요. 둘 다 아니어야 "아니야!" (False).
> - **`not` (아니야):** "오늘은 비가 안 와?" (`not` (비가 와?)) → 비가 오지 않는다면 "True"가 되죠. 즉, 원래의 논리값을 반대로 뒤집는 역할을 합니다.
>
> 이러한 논리 연산을 통해 여러 조건을 한 번에 확인하고, 그 결과에 따라 다른 행동을 지시할 수 있게 됩니다.

## 3. 만약에 내가 간다면 - 조건문

**조건문**은 특정 조건에 따라 프로그램이 **실행하는 명령을 다르게 할 때 사용**되는 구문입니다 `p.22`. 우리 삶에서 로그인 정보가 맞으면 홈페이지로 이동하고, 틀리면 경고 메시지를 출력하는 것과 같이, 조건에 따라 해야 할 일이 달라지는 경우가 많습니다 `p.21`.

```python
if i == 1:
    print(i)  # 조건이 True일 때 실행
```

**`if` 문:** 주어진 **조건이 True일 때만** 특정 명령을 실행합니다. `if 조건:` 다음에 오는 들여쓰기된 코드 블록이 조건이 True일 때 실행됩니다 `p.24` `p.25`.

> **쉬운 설명**
>
> 여러분이 아침에 집을 나서기 전에 "만약 비가 오면 우산을 가져가자!"라고 생각하는 것이 바로 **조건문**입니다. 여기서 "비가 온다"는 것이 **조건**이고, "우산을 가져가는 것"이 그 조건이 맞을 때 할 **명령**이죠.
>
> `if` 문은 이런 '만약 ~라면'을 컴퓨터 언어로 표현하는 방식이에요.
>
> ```python
> # 예를 들어, 변수 i가 1인지 확인해 봅시다.
> i = 1
> if i == 1:  # 만약 i가 1과 같다면 (조건이 True라면)
>     print("i는 1입니다.")  # 이 명령을 실행해!
> ```
>
> 컴퓨터가 `i == 1`이라는 조건을 확인했을 때, 그 답이 "참 (True)"이면 `print("i는 1입니다.")`라는 명령을 실행하는 거예요. 만약 `i`가 1이 아니라 2였다면, 이 명령은 실행되지 않고 그냥 지나치게 됩니다.
>
> **들여쓰기**는 아주 중요해요! `if` 문 아래에 똑같이 들여쓰기된 줄들은 모두 `if` 조건에 따라 움직이는 한 묶음의 명령이라고 보시면 됩니다. 마치 여러 개의 상자를 한 묶음으로 묶어 놓은 것과 같죠.

## 4. 조건이 맞지 않는다면

`if` 문에서 조건을 만족하지 못했을 때, 즉 조건이 `False`일 때 다른 명령을 실행하고 싶다면 `else` 또는 `elif` 문을 사용합니다.

```python
i = 1
if i == 1:
    print(i)      # 조건이 True일 때 실행
else:
    print(i + 1)  # 조건이 False일 때 실행
```

```python
score = 78
if score >= 90:
    print("A")
elif score >= 75:  # score가 90점 미만이면서 75점 이상일 경우
    print("B")
else:              # score가 75점 미만일 경우
    print("C")
```

- **`if-else` 문:** `if` 조건이 `True`이면 `if` 문 내부 명령을 실행하고, `False`이면 `else` 문 내부 명령을 실행합니다 `p.28`.
- **`if-elif-else` 문:** 여러 조건을 순차적으로 검사할 때 사용합니다. 첫 번째 `if` 조건이 `False`일 경우, 다음 `elif` 조건2를 검사하고, 그마저 `False`일 경우 다음 `elif` 조건을 계속해서 검사합니다. 모든 `if`와 `elif` 조건이 `False`일 경우 마지막 `else` 문이 실행됩니다 `p.30` `p.31`.

> **쉬운 설명**
>
> 다시 비 오는 날 우산을 가져가는 예시로 돌아가 볼까요? "만약 비가 오면 우산을 가져가자!" (`if`) "아니면, 그냥 빈손으로 나가자!" (`else`)
>
> 이처럼 `if` 조건이 거짓일 때 **'그 외의 경우'**에 무엇을 할지 정해주는 것이 `else` 문이에요. 비가 오지 않으면 우산을 가져가지 않는 것이죠.
>
> 그런데 조건이 더 복잡할 수도 있겠죠? "만약 점수가 90점 이상이면 'A'를 줘!" (`if`) "그게 아니라 만약 점수가 75점 이상이면 'B'를 줘!" (`elif`) "그것도 아니라면 'C'를 줘!" (`else`)
>
> 여기서 `elif`는 'else if'의 줄임말이에요. 첫 번째 `if` 조건이 아니었을 때, **또 다른 조건**을 확인하고 싶을 때 사용합니다. 컴퓨터는 위에서부터 차례대로 조건을 검사하다가 **처음으로 맞는 조건**을 발견하면 그에 해당하는 명령을 실행하고, 나머지 `elif`나 `else`는 무시하고 빠져나와요.
>
> 모든 `if`와 `elif` 조건을 다 검사했는데도 맞는 것이 하나도 없다면, 맨 마지막 `else` 블록의 명령이 실행됩니다. `else`는 마치 '마지막 선택지'와 같다고 생각하시면 돼요.

# 3. [강의자료] 리스트 _ 모아모아 다모아

## 요약

본 강의는 파이썬의 리스트 활용법과 시퀀스 자료형의 특징 및 활용에 대해 다루며, 효율적인 자료 관리를 위한 핵심 개념들을 소개합니다 `p.1`.

## 1. 리스트 활용 `p.3`

### `list.append(d)` `p.4`

리스트의 **마지막 원소 뒤에** 자료 `d`를 추가합니다. 오직 **한 개의 자료만** 추가할 수 있습니다.

```python
a = []
b = ["a", "b", "c"]
a.append(10)
b.append("d")
print(a, b)
```

**실행 결과:**
```
[10] ['a', 'b', 'c', 'd']
```

> **쉬운 설명**
>
> `append()`는 리스트의 맨 끝에 새로운 항목을 덧붙일 때 사용해요. 마치 장바구니에 물건을 하나씩 추가하는 것과 같아요. 장바구니가 비어있어도 첫 물건이 들어가고, 이미 물건이 있어도 항상 맨 뒤에만 추가되죠. 한 번에 하나씩만 추가할 수 있다는 점을 기억하세요!

### `list.insert(i, d)` `p.5`

지정된 **인덱스 위치 `i`에** 자료 `d`를 추가합니다. `append()`와 마찬가지로 오직 한 개의 자료만 넣을 수 있습니다.

```python
c = [1, 2, 4, 5]
c.insert(2, 3)
print(c)
```

**실행 결과:**
```
[1, 2, 3, 4, 5]
```

> **쉬운 설명**
>
> `insert()`는 `append()`와 다르게 원하는 **특정 위치**에 자료를 끼워 넣을 수 있어요. 예를 들어, `c.insert(2, 3)`는 리스트 `c`의 인덱스 2번 위치(세 번째 자리)에 숫자 3을 넣는다는 의미예요. 원래 그 자리에 있던 4는 뒤로 밀려나죠. 마치 책꽂이에 책을 꽂을 때, 특정 위치에 새 책을 꽂으면 기존 책들이 옆으로 밀려나는 것과 같아요.

### `list.remove(d)` `p.6`

리스트에서 **처음 나오는** 자료 `d`를 제거합니다.

```python
my_list = [3, 1, 2, 3]
my_list.remove(3)
print(my_list)
```

**실행 결과:**
```
[1, 2, 3]
```

> **쉬운 설명**
>
> `remove()`는 리스트에서 **특정 값**을 찾아서 제거해요. 만약 같은 값이 여러 개 있다면, **가장 먼저 나오는 값만** 제거합니다. 예를 들어 `[3, 1, 2, 3]`에서 `remove(3)`를 하면 맨 앞에 있는 3만 사라지고, 뒤에 있는 3은 그대로 남아요. 이름표가 붙은 물건을 찾아서 버리는 것과 비슷하다고 생각할 수 있어요.

### `list.sort()` `p.7`

리스트 내의 자료들을 **순서대로 정렬**합니다.

- 숫자형은 **오름차순**으로 정렬됩니다.
- 문자열은 **사전순** (알파벳 A부터 Z까지)으로 정렬됩니다.

```python
e = [6, 2, 4, 1]
f = ["carrot", "apple", "banana"]
e.sort()
f.sort()
print(e, f)
```

**실행 결과:**
```
[1, 2, 4, 6] ['apple', 'banana', 'carrot']
```

> **쉬운 설명**
>
> `sort()`는 리스트 안의 모든 자료를 깔끔하게 정돈해줘요. 숫자는 작은 것부터 큰 것 순서로, 글자는 사전에서 찾는 순서대로 바꿔줘요. 마치 파일들을 이름순이나 날짜순으로 정리하는 것과 같아요. `sort()`를 사용하면 **원래 리스트 자체가 정렬된 상태로 변경**된다는 점이 중요해요. (새로운 정렬된 리스트를 만드는 것이 아니라 원본을 바꿉니다!)

## 2. 시퀀스 자료형 `p.8`

### 시퀀스 자료형이란? `p.9`

**순서가 있는 자료형**을 의미하며, 파이썬에서는 **문자열(str)**, **리스트(list)** 등이 이에 속합니다.

- 문자열: `'Hello!'`, `'3.14'`, `"3.14"` (작은따옴표, 큰따옴표 모두 가능)
- 리스트: `[]` (빈 리스트), `['a', 'b']`, `['a', 2]` (다른 자료형 함께 사용 가능)

> **쉬운 설명**
>
> 시퀀스 자료형은 "순서대로 나열된" 자료들이라고 생각하면 쉬워요. 우리가 사용하는 문자열("안녕하세요")이나 리스트([1, 2, 3])가 대표적이죠. 이 자료형들은 각각의 원소(글자나 숫자)들이 특정한 순서를 가지고 있어서, 그 순서를 이용해 여러 가지 조작을 할 수 있어요. 마치 기차의 각 칸이 순서대로 연결되어 있는 것과 같아요!

### 시퀀스 자료형의 특징 (1): 인덱싱 및 슬라이싱 `p.10` `p.11`

원소 간의 순서가 존재하기 때문에 **인덱싱(Indexing)**과 **슬라이싱(Slicing)**이 가능합니다.

```python
a = "Hello"
b = ["e", "l", "i", "c", "e"]
print(a[1])    # 실행 결과: e
print(b[2:4])  # 실행 결과: ["i", "c"]
print(a[-1])   # 실행 결과: o
print(b[:4])   # 실행 결과: ["e", "l", "i", "c"]
print(b[2:])   # 실행 결과: ["i", "c", "e"]
```

> **쉬운 설명**
>
> 시퀀스 자료형의 가장 강력한 기능 중 하나가 바로 인덱싱과 슬라이싱이에요!
>
> - **인덱싱:** 특정 위치의 원소에 접근합니다.
>   - `a[1]`은 문자열 `a`의 두 번째 문자(`'e'`)를 가져옵니다. (인덱스는 0부터 시작)
>   - 음수 인덱스를 사용하여 뒤에서부터 접근할 수 있습니다. `a[-1]`은 문자열 `a`의 마지막 문자(`'o'`)를 가져옵니다. `p.11`
> - **슬라이싱:** 특정 범위의 원소들을 잘라냅니다.
>   - `b[2:4]`는 리스트 `b`의 인덱스 2부터 3까지의 원소(`'i'`, `'c'`)를 가져옵니다. (시작 인덱스는 포함, 끝 인덱스는 제외)
>   - 시작 인덱스나 끝 인덱스를 생략할 수 있습니다.
>   - `b[:4]`는 처음부터 인덱스 3까지 (원소 4개)를 가져옵니다. `p.11`
>   - `b[2:]`는 인덱스 2부터 끝까지를 가져옵니다. `p.11`
>
> **인덱싱**은 '몇 번째' 원소를 딱 짚어서 가져오는 거예요. 0부터 세기 시작한다는 것만 기억하면 쉬워요! `a[0]`은 첫 번째, `a[1]`은 두 번째… 그리고 `a[-1]`은 맨 마지막 원소를 가져오는 편리한 방법이에요. 마치 도서관에서 책꽂이 번호(인덱스)를 보고 특정 책 한 권(원소)을 찾아내는 것과 같죠.
>
> **슬라이싱**은 '어디부터 어디까지' 덩어리째 잘라내는 거예요. `b[2:4]`는 2번째부터 4번째 앞까지를 가져오는 거라서, 2번째와 3번째 원소만 포함돼요. 이 규칙(끝 인덱스는 포함 안 함)만 알면 헷갈릴 일이 없어요! 앞이나 뒤를 비워두면 "처음부터" 또는 "끝까지"라는 의미가 됩니다. 이건 김밥을 자를 때 "이만큼만 잘라줘!" 하는 것과 비슷해요!

### 시퀀스 자료형의 특징 (2): `in` 연산자 `p.12`

`in` 연산자로 시퀀스 안에 **특정 원소가 있는지 확인**할 수 있습니다. 존재하면 `True`, 존재하지 않으면 `False`를 반환합니다.

```python
a = "Hello"
b = ["e", "l", "i", "c", "e"]
print("e" in a)  # 실행 결과: True
print("E" in b)  # 실행 결과: False
```

> **쉬운 설명**
>
> `in` 연산자는 마치 "이것이 저 안에 있니?" 하고 물어보는 것과 같아요. 예를 들어, `print("e" in a)`는 "문자 'e'가 'Hello' 문자열 안에 있니?"라고 묻는 거죠. 있으면 `True` (응, 있어!), 없으면 `False` (아니, 없어!)라고 답해줘요. 대소문자를 구분하니 `"E" in b`는 `False`가 되는 거예요. 숨은 그림 찾기와 비슷하죠!

### 시퀀스 자료형의 특징 (3): `len()` 연산자 `p.13`

`len()` 연산자로 시퀀스 자료형의 **길이(원소의 개수)**를 확인할 수 있습니다.

```python
a = "Hello World"
b = ["e", "l", "i", "c", "e"]
print(len(a))  # 실행 결과: 11
print(len(b))  # 실행 결과: 5
```

> **쉬운 설명**
>
> `len()`은 "length(길이)"의 줄임말이에요. 시퀀스 자료형이 얼마나 많은 원소(글자나 아이템)를 가지고 있는지 알려줘요. "Hello World"는 공백 포함해서 총 11글자니까 `len(a)`는 11이 되는 거죠. 마치 연필 한 다발에 몇 자루의 연필이 있는지 세어보는 것과 같아요!

### 시퀀스 자료형의 특징 (4): `+` 연산자 `p.14`

`+` 연산자를 이용하면 **같은 종류의 시퀀스 자료**를 이어 붙일 수 있습니다. (서로 다른 종류의 시퀀스 자료는 합칠 수 없습니다.)

```python
c = "Good" + "Day"
print(c)  # 실행 결과: GoodDay

d = ["H", "e"] + ["l", "l", "o"]
print(d)  # 실행 결과: ["H", "e", "l", "l", "o"]
```

> **쉬운 설명**
>
> `+` 연산자는 시퀀스 자료형을 "합치기" 하는 거예요. 문자열끼리는 글자를 이어서 새로운 단어를 만들고, 리스트끼리는 원소들을 이어서 새로운 리스트를 만들어요. 마치 두 개의 레고 블록을 합쳐서 더 긴 블록을 만드는 것과 같죠! 중요한 건, **같은 종류끼리만 합칠 수 있다**는 점이에요. 문자열과 리스트를 `+`로 합칠 수는 없어요!

### 시퀀스 자료형의 특징 (5): `*` 연산자와 숫자 `p.15`

`*` 연산자와 숫자를 이용하면 시퀀스 자료를 **반복**할 수 있습니다.

```python
e = "Go!!" * 5
print(e)  # 실행 결과: Go!!Go!!Go!!Go!!Go!!

f = [13, 17, 19] * 3
print(f)  # 실행 결과: [13, 17, 19, 13, 17, 19, 13, 17, 19]
```

> **쉬운 설명**
>
> `*` 연산자는 시퀀스 자료를 "반복"하는 마법 같은 기능이에요. 문자열 `"Go!!"`를 `* 5` 하면 `"Go!!Go!!Go!!Go!!Go!!"`처럼 다섯 번 반복되고, 리스트 `[13, 17, 19]`를 `* 3` 하면 리스트의 내용이 세 번 반복된 새로운 리스트가 만들어져요. 마치 노래를 여러 번 반복 재생하는 것과 비슷해요!

### 시퀀스 자료형의 활용 `p.16`

시퀀스 자료형은 순서가 있는 다양한 정보를 가지고 있어서 다채롭게 활용될 수 있습니다.

- **공통적인 특징을 이용한 방법:**
  - 인덱스를 이용한 **인덱싱**과 **슬라이싱**.
  - 구성하는 원소 내 특정 원소의 **개수 구하기** (예: `my_list.count(value)`).

- **종류마다 활용법이 다를 수 있음:**
  - `list` 자료형은 `append()`를 이용하여 원소를 추가할 수 있지만, `str` 자료형은 `append()` 사용이 불가능합니다. (문자열은 변경 불가능한 자료형, immutable)
  - `str` 자료형은 특정 문자를 기준으로 분할할 수 있지만 (`.split()`), `list` 자료형은 분할(`split()`) 불가능합니다. (리스트는 이미 분할된 원소들의 집합이기 때문)

> **쉬운 설명**
>
> 시퀀스 자료형은 단순히 나열된 데이터가 아니라, 그 순서 덕분에 아주 유용하게 사용될 수 있어요.
>
> **공통적인 활용법**으로는 위에서 배운 인덱싱, 슬라이싱, `len()`, `in` 연산자 등이 있죠. 어떤 시퀀스든 이 방법들을 쓸 수 있어서 매우 편리해요!
>
> 하지만 시퀀스 자료형은 크게 '문자열', '리스트', '튜플' 등으로 나뉘는데, **이 종류에 따라 사용할 수 있는 기능이 달라요**. 예를 들어, 리스트는 `append()`로 원소를 추가할 수 있지만, 문자열은 한 번 만들어지면 내용을 바꿀 수 없어서 `append()`를 쓸 수 없어요. 반대로 문자열은 특정 문자를 기준으로 나누는 `split()` 같은 기능이 있지만, 리스트는 이미 나눠진 형태라서 이런 기능이 필요 없죠. 마치 도구 상자 안에 망치, 드라이버 등 여러 도구가 있는데, 각각 쓰임새가 다른 것과 같아요!
