# Pandas 라이브러리


## Pandas 라이브러리 소개

**Pandas**는 데이터 조작 및 분석을 위한 파이썬 라이브러리입니다. 데이터 분석에 유용한 **시리즈(Series)**와 **데이터프레임(DataFrame)**이라는 데이터 구조를 제공하며, 엑셀의 파이썬 버전으로 비유되기도 합니다.

### 🔍쉬운설명
Pandas는 파이썬으로 데이터를 쉽게 다룰 수 있게 해주는 도구 상자라고 생각하면 됩니다. 엑셀처럼 표 형태의 데이터를 만들고, 계산하고, 정리하는 데 아주 유용해요. 특히 **시리즈**는 1줄짜리 목록(엑셀의 한 열)이고, **데이터프레임**은 여러 줄과 여러 열이 있는 표(엑셀 시트 전체)라고 이해할 수 있습니다.

---

## Pandas를 배워야 하는 이유

Pandas는 다음과 같은 이유로 데이터 분석에 필수적입니다:

- **대용량 데이터**를 처리하기 용이합니다.
- 프로그래밍을 통한 **반복적인 작업** 및 머신러닝/자동화에 유리합니다.
- **딥러닝 모델**에 필요한 데이터 처리에 활용됩니다.

### 🔍쉬운설명
Pandas를 배워야 하는 가장 큰 이유는 실제 세상의 데이터가 너무 많고 복잡하기 때문입니다. 손으로 처리하기 힘든 많은 양의 데이터를 효율적으로 다루고, 똑같은 작업을 여러 번 반복해야 할 때 자동으로 처리할 수 있게 해줍니다. 또한, 인공지능 모델을 만들 때 모델이 이해할 수 있는 형태로 데이터를 미리 준비하는 데 Pandas가 핵심적인 역할을 합니다.

---

## 데이터프레임 (DataFrame)

데이터프레임은 Pandas 라이브러리에서 지원하는 **2차원 행렬 데이터 구조**로, 데이터를 표 형태로 저장합니다. 가로인 **행(row)**과 세로인 **열(column)**로 이루어져 있으며, 각 행과 열은 고유한 **인덱스(index)**를 가지고 있어 데이터를 쉽게 검색하고 필터링할 수 있습니다.

| index | 국어 | 수학 | 영어 |
|-------|------|------|------|
| 민수  | 95   | 88   | 96   |
| 도윤  | 72   | 72   | 68   |
| 서아  | 83   | 93   | 85   |
| 연우  | 89   | 80   | 94   |
| 하준  | 100  | 95   | 93   |

### 🔍쉬운설명
데이터프레임은 우리가 엑셀에서 보는 표와 똑같다고 생각하면 됩니다. 데이터프레임에는 가로줄인 **'행'**과 세로줄인 **'열'**이 있습니다. '행'에는 각각의 데이터 기록이 들어가고, '열'에는 데이터의 종류(예: 이름, 점수 등)가 들어갑니다. 각 행과 열에는 **'인덱스'**라는 고유한 이름표가 있어서, 원하는 데이터를 쉽고 빠르게 찾을 수 있습니다.

---

## 시리즈 (Series)

시리즈는 Pandas 라이브러리에서 지원하는 **1차원 데이터 구조**로, 각 원소는 **인덱스**와 **값(value)**으로 이루어져 있습니다. 인덱스는 숫자 또는 문자열로 지정할 수 있습니다.

### 🔍쉬운설명
시리즈는 데이터프레임의 한 **'열'**만 따로 떼어낸 것이라고 생각하면 됩니다. 예를 들어, 위 데이터프레임에서 '국어' 점수만 뽑아내면 하나의 시리즈가 됩니다. 각 데이터(값)에는 순서를 나타내는 **'인덱스'**가 붙어 있어, 특정 값을 쉽게 찾을 수 있습니다.

---

## 시리즈와 데이터프레임의 관계

데이터프레임에서 하나의 열 데이터를 추출하면 **시리즈**가 됩니다.

### 🔍쉬운설명
데이터프레임은 여러 개의 시리즈가 옆으로 나란히 붙어 있는 형태입니다. 마치 여러 권의 책이 책꽂이에 꽂혀 있는 것을 데이터프레임이라고 할 때, 각 책 한 권이 시리즈가 되는 것과 같습니다. 데이터프레임에서 특정 과목의 점수 열을 뽑으면 그 자체가 하나의 시리즈가 됩니다.

## Pandas 사용하기

Pandas 라이브러리를 사용하기 위해서는 먼저 불러오는 작업이 필요합니다. `import pandas as pd` 구문을 사용하여 Pandas를 `pd`라는 별명으로 불러와 사용합니다. CSV 파일을 불러오기 위해서는 `pd.read_csv()` 함수를 사용합니다.

```python
import pandas as pd
df = pd.read_csv('data/seoul_park.csv')
```

### 🔍쉬운설명
Pandas를 사용하려면 가장 먼저 `import pandas as pd`라고 입력해서 라이브러리를 우리 파이썬 코드 안으로 가져와야 합니다. `pd`는 Pandas를 편리하게 부를 수 있는 짧은 이름입니다. 그 다음, `.csv` 파일을 불러올 때는 `pd.read_csv('파일경로')`를 사용하면 됩니다. 마치 요리할 때 필요한 재료를 미리 준비하는 것과 같아요.

## 데이터 살펴보기

### 데이터 파일

Pandas는 다양한 형식의 데이터 파일을 불러올 수 있으며, 주로 **`.csv`** 파일 혹은 **`.xlsx`** 파일 형식을 사용합니다.

### 🔍쉬운설명
Pandas는 여러 종류의 데이터 파일을 열 수 있는 만능 도구입니다. 특히 `.csv`(쉼표로 구분된 텍스트 파일)나 `.xlsx`(엑셀 파일)와 같은 가장 흔히 사용되는 데이터 파일들을 쉽게 처리할 수 있습니다.

---

### 강의에 활용할 데이터

강의에서는 **2016년 1월 1일부터 2019년 3월 31일까지의 서울대공원 입장객 데이터**를 활용합니다. 이 데이터는 조류독감으로 인한 폐쇄 기간(2016년 12월 18일 ~ 2017년 3월 27일) 동안의 기록은 없으며, 입장객 수, 분류, 공휴일 여부, 날씨 등이 기록되어 있습니다. `data` 폴더 안에 `"seoul_park.csv"` 파일로 저장되어 있습니다.

### 🔍쉬운설명
이 강의에서 사용할 데이터는 서울대공원에 입장한 사람들의 정보입니다. 2016년부터 2019년 3월까지의 기록인데, 특이하게 조류독감 때문에 문을 닫았던 기간의 데이터는 빠져있어요. 이 데이터에는 날짜, 공휴일 여부, 날씨, 유료 입장객 수(어른, 청소년, 어린이, 외국인, 단체), 무료 입장객 수, 그리고 총 입장객 수가 들어있습니다. 이 정보를 통해 사람들이 언제 대공원에 많이 왔는지, 날씨나 공휴일이 영향을 미쳤는지 등을 분석해볼 수 있습니다.

---

### 데이터 불러오기: `read_csv()`, `read_excel()`

파일로 저장된 데이터를 불러와 데이터프레임으로 저장합니다.

- `.csv` 파일은 `read_csv()`를 사용합니다.
- `.xlsx` 파일은 `read_excel()`을 사용합니다.

```python
df = pd.read_csv('data/seoul_park.csv')
```

위 코드는 `data` 폴더 안의 `seoul_park.csv` 파일을 불러와 변수 `df` 형태로 저장합니다.

### 🔍쉬운설명
데이터를 분석하려면 먼저 컴퓨터에 있는 파일을 파이썬으로 가져와야겠죠? `.csv` 파일은 `pd.read_csv()` 함수를 써서 불러오고, `.xlsx` 파일은 `pd.read_excel()` 함수를 써서 불러옵니다. 이렇게 불러온 데이터는 `df`와 같은 변수에 저장해서 나중에 사용합니다. **`df`는 '데이터프레임'의 줄임말**로 자주 사용되는 변수 이름입니다.

---

### 데이터 일부 확인: `head()`, `tail()`

데이터를 확인하는 데 사용됩니다. `df.head()`는 기본적으로 **상위 5개의 행**을, `df.tail()`은 **하위 5개의 행**을 보여줍니다. 괄호 안에 숫자를 넣어 보여줄 행의 개수를 지정할 수 있습니다.

```python
df.head()   # 데이터프레임의 상위 5개 행 출력
df.tail()   # 데이터프레임의 하위 5개 행 출력
```

### 🔍쉬운설명
데이터프레임을 통째로 보면 너무 많아서 한눈에 파악하기 어렵습니다. 이때 `head()` 함수는 데이터프레임의 맨 위부터 몇 줄을 보여주고, `tail()` 함수는 맨 아래부터 몇 줄을 보여줍니다. 이 함수들을 사용하면 전체 데이터를 다 보지 않고도 데이터가 어떻게 생겼는지, 어떤 정보들이 들어있는지 빠르게 훑어볼 수 있습니다. 마치 긴 책의 목차와 맨 뒤 결론 부분을 먼저 읽어보는 것과 비슷합니다.

---

### 데이터 정보 확인: `info()`

`info()` 메서드는 데이터프레임의 전반적인 정보를 확인하는 데 사용됩니다. 어떤 컬럼이 있는지, 각 컬럼에 몇 개의 값이 있는지(**Non-Null Count**), 그리고 어떤 형태로(**Dtype**) 저장되어 있는지 등을 확인할 수 있습니다.

```python
df.info()
```

### 🔍쉬운설명
`info()` 함수는 데이터프레임의 **'건강검진 기록'** 같은 역할을 합니다. 이 함수를 실행하면 각 열의 이름은 무엇인지, 비어있는 값(결측치)은 없는지, 그리고 각 열에 어떤 종류의 데이터(숫자, 글자, 날짜 등)가 들어있는지 한눈에 알 수 있습니다. 데이터를 본격적으로 분석하기 전에 이 정보를 확인하여 어떤 부분을 고쳐야 할지 미리 파악할 수 있습니다.

---

### 데이터프레임에서 특정 컬럼 추출

데이터프레임에서 컬럼 이름을 활용해 특정 컬럼을 추출할 수 있습니다. 단일 컬럼을 추출할 때는 **시리즈** 형태로 추출되며, `df["컬럼이름"]`과 같이 대괄호 안에 컬럼 이름을 문자열로 넣어줍니다.

```python
df["어른"]
```

위 코드는 `df` 데이터프레임에서 `"어른"` 컬럼의 데이터를 추출합니다.

### 🔍쉬운설명
데이터프레임에서 특정 열(컬럼)만 골라서 보고 싶을 때가 있습니다. 이때는 `df['원하는_컬럼_이름']`처럼 대괄호 안에 컬럼 이름을 따옴표로 묶어 넣어주면 됩니다. 이렇게 추출된 하나의 열은 아까 배운 **'시리즈'** 형태가 됩니다. 마치 여러 과목 성적표에서 특정 과목의 성적만 따로 보는 것과 같습니다.

---

### 데이터프레임에서 여러 개의 컬럼 추출

리스트를 활용하면 여러 개의 컬럼을 **데이터프레임** 형태로 추출할 수 있습니다. `df[["컬럼이름1", "컬럼이름2"]]`와 같이 대괄호 안에 추출할 컬럼 이름들을 리스트로 묶어줍니다.

```python
df[["공휴일", "어른"]]
```

위 코드는 `df`에서 `"공휴일"`과 `"어른"` 컬럼을 추출합니다.

### 🔍쉬운설명
만약 한 번에 여러 개의 열을 보고 싶다면, 대괄호를 두 번 사용합니다. `df[['첫째_컬럼_이름', '둘째_컬럼_이름']]`처럼 대괄호 안에 보고 싶은 컬럼 이름들을 리스트(`[]`)로 묶어서 넣어주면 됩니다. 이렇게 뽑아낸 데이터는 다시 여러 열을 가진 **'데이터프레임'**이 됩니다.

---

### 데이터 숫자 세기: `value_counts()`

`value_counts()` 메서드는 해당 컬럼에 어떤 값들이 몇 개씩 저장되어 있는지 알고 싶을 때 사용됩니다.

```python
df["날씨"].value_counts()
```

위 코드는 `"날씨"` 컬럼에 있는 값들의 개수를 세어줍니다.

### 🔍쉬운설명
`value_counts()` 함수는 특정 열에 어떤 종류의 값들이 있고, 각 값이 몇 번씩 나타나는지 세어주는 역할을 합니다. 예를 들어 '날씨' 열에 '맑음', '흐림', '비' 등의 값이 있다면, 이 함수를 사용해서 '맑음'이 몇 번, '흐림'이 몇 번 나타났는지 쉽게 알 수 있습니다. 마치 투표 결과를 집계하는 것과 비슷해요.

## 데이터 변환하기 1

### 데이터 타입 변환의 필요성

데이터는 항상 원하는 타입으로 되어있지 않을 수 있습니다. 특히 실습 데이터의 숫자들은 종종 텍스트(`object`) 타입으로 저장되어 있어, 덧셈이나 뺄셈 등의 **연산이 불가능**한 경우가 많습니다. 데이터 분석의 정확성을 높이려면 올바른 **데이터 타입으로 변환**하는 과정이 필수적입니다.

### 🔍쉬운설명
데이터 분석을 하다 보면 숫자가 **'숫자'**가 아닌 **'글자'**로 저장되어 있는 경우가 많습니다. 예를 들어 `'123'`이 숫자 `123`이 아니라 '일이삼'이라는 글자로 저장되어 있으면, 여기에 1을 더하는(`+1`) 계산을 할 수 없겠죠? 그래서 이런 '글자' 형태의 숫자를 진짜 '숫자' 형태로 바꿔줘야 제대로 된 계산을 할 수 있습니다. 이것이 바로 **데이터 타입 변환**이 필요한 이유입니다.

---

### 데이터 타입 변환: `astype()`

`astype()` 메서드는 해당 컬럼의 데이터 타입을 원하는 타입으로 변환할 때 사용합니다.

```python
df["컬럼이름"].astype(변환할 타입)
```

예를 들어, `"어른"` 컬럼의 데이터를 정수(`int`) 타입으로 변환하여 다시 `"어른"` 컬럼에 저장(덮어씌우기)하는 코드는 다음과 같습니다.

```python
df["어른"] = df["어른"].astype(int)
```

### 🔍쉬운설명
`astype()` 함수는 특정 열의 데이터 형식을 원하는 대로 바꿔주는 마법사 같은 역할을 합니다. 예를 들어, '나이' 열의 데이터가 글자(`object`)로 되어 있다면 `df['나이'].astype(int)`를 써서 정수(`int`)로 바꿀 수 있습니다. 이때 **원본 데이터가 바로 바뀌는 것이 아니라**, 바뀐 새로운 데이터가 만들어지므로 `df['나이'] = ...`와 같이 다시 저장해 주어야 원본 열이 변환된 값으로 갱신됩니다.

---

### 데이터프레임 변환 시 유의사항

Pandas의 메서드들은 원본 데이터프레임(또는 시리즈)을 바로 변환하지 않고, 변환된 **새로운 데이터프레임(또는 시리즈)을 반환**합니다. 따라서 원본 데이터프레임을 변환하려면 반환된 값을 다시 원본 변수에 덮어씌워주는 작업이 필요합니다.

```python
df["어른"].astype(int)               # 변환된 시리즈를 반환하지만, 원본은 그대로
df["어른"] = df["어른"].astype(int)  # 변환된 시리즈를 원본 df의 "어른" 컬럼에 저장
```

### 🔍쉬운설명
Pandas에서 데이터를 변환하는 대부분의 함수들은 원본 데이터를 직접 바꾸지 않고, 새로운 변환된 데이터를 만들어 돌려줍니다. 쉽게 말해, 원본 사진을 건드리지 않고, 변환된 새 사진을 만들어주는 것과 같습니다. 만약 원본 사진을 새 사진으로 교체하고 싶다면, `원본_변수 = 변환된_새로운_데이터`와 같이 **명시적으로 다시 저장하는 과정**이 꼭 필요합니다. 이걸 잊으면 아무리 변환해도 데이터가 바뀌지 않는다고 생각할 수 있습니다.

---

### 데이터 타입 변환: `to_numeric()`

`pd.to_numeric()` 함수는 해당 컬럼의 데이터 타입을 **숫자 타입**으로 변환할 때 사용합니다.

```python
pd.to_numeric(df["컬럼이름"])
```

예를 들어, `"유료합계"` 컬럼의 데이터를 숫자로 변환하여 다시 `"유료합계"` 컬럼에 저장하는 코드는 다음과 같습니다.

```python
df["유료합계"] = pd.to_numeric(df["유료합계"])
```

### 🔍쉬운설명
`pd.to_numeric()` 함수도 `astype(int)`와 비슷하게 데이터를 숫자로 바꾸는 역할을 합니다. 특히 데이터 안에 숫자로 변환할 수 없는 값이 섞여 있을 때 `errors='coerce'`와 같은 옵션을 사용해서 에러를 처리하는 등의 **유연한 기능**을 제공합니다. 이 함수 역시 변환된 결과를 다시 저장해 주어야 합니다.

---

### 한꺼번에 타입 변환하기

변환해야 하는 여러 컬럼들을 리스트로 만들고, `for`문을 활용하면 한꺼번에 타입 변환이 가능합니다.

```python
columns = ['유료합계', '어른', '청소년', '어린이', '외국인', '단체']
for i in columns:
    df[i] = pd.to_numeric(df[i])
```

### 🔍쉬운설명
만약 여러 개의 열에 대해 똑같은 데이터 타입 변환 작업을 해야 한다면, 일일이 하나씩 코드를 작성하는 것은 비효율적입니다. 이때는 변환할 열들의 이름을 **리스트로 묶어두고**, `for` 반복문을 사용해서 리스트 안에 있는 모든 열에 대해 한 번에 변환 작업을 수행할 수 있습니다. 마치 여러 사람의 신분증을 한 번에 스캔하여 정보를 입력하는 것과 같습니다.

---

### 데이터 타입 변환: `to_datetime()`

`pd.to_datetime()` 함수는 날짜/시간으로 변환 가능한 문자열, 정수, 실수를 **시간 타입(datetime)**으로 변환할 때 사용합니다.

```python
pd.to_datetime(df["컬럼이름"])
```

`"날짜"` 컬럼의 텍스트(예: `"2016-01-01"`)를 시간 타입으로 변환하여 다시 `"날짜"` 컬럼에 저장하는 코드는 다음과 같습니다.

```python
df["날짜"] = pd.to_datetime(df["날짜"])
```

### 🔍쉬운설명
날짜와 시간 정보는 일반 문자열이나 숫자와는 다르게 다루어져야 합니다. `pd.to_datetime()` 함수는 `'2023-10-26'`과 같은 문자열을 파이썬이 **'날짜'**로 인식하고 처리할 수 있는 특별한 형식으로 바꿔줍니다. 이렇게 날짜 타입으로 바꿔야 나중에 요일을 추출하거나, 기간을 계산하는 등의 날짜 관련 연산을 할 수 있습니다.

### 시간 타입을 활용한 데이터 변환: `dt`

시간 타입으로 변환된 컬럼은 **`dt` 접근자**를 통해 날짜와 시간에 대한 정보를 담고 있어 다양한 처리가 가능합니다.

- `dt.year`를 사용하여 년도 정보 추출: `df['연'] = df['날짜'].dt.year`
- `dt.month`를 사용하여 월 정보 추출: `df['월'] = df['날짜'].dt.month`
- `dt.day`를 사용하여 일 정보 추출: `df['일'] = df['날짜'].dt.day`
- `dt.dayofweek`를 사용하여 요일 정보 추출 (월~일: 0~6): `df['요일'] = df['날짜'].dt.dayofweek`

### 🔍쉬운설명
`pd.to_datetime()`으로 날짜 데이터를 진짜 '날짜'로 만들면, 이제 그 데이터에서 **`dt`**라는 특별한 도구를 사용해서 다양한 정보를 뽑아낼 수 있습니다. 예를 들어 `날짜.dt.year`라고 하면 해당 날짜의 **'연도'**만 쏙 뽑아주고, `날짜.dt.month`는 **'월'**만, `날짜.dt.day`는 **'일'**만 뽑아줍니다. `날짜.dt.dayofweek`는 요일을 숫자로 알려주는데, **월요일이 0이고 일요일이 6**입니다. 마치 특정 책의 목차를 보고 원하는 정보(연도, 월, 일, 요일 등)를 바로 찾아내는 것과 같습니다.

### 데이터 변환

데이터 분석의 정확성을 높이기 위해서는 데이터의 **값 변환**이 필요한 경우가 많습니다. 알아보기 쉬운 데이터로 바꾸거나, 단위를 통일하는 등 다양한 변환이 가능합니다.

### 🔍쉬운설명
데이터를 그냥 있는 그대로 분석하면 오류가 생기거나, 결과를 이해하기 어려울 수 있습니다. 예를 들어, '요일'이 `0, 1, 2...`로 되어 있으면 무슨 요일인지 바로 알기 어렵죠? 그래서 `0`을 '월', `1`을 '화' 등으로 바꾸거나, `'kg'`으로 되어 있는 단위를 `'g'`으로 통일하는 것처럼 데이터의 값을 알아보기 쉽고 통일된 형태로 바꿔주는 작업이 필요합니다. 이것이 **데이터 변환**의 목적입니다.

### 시리즈 연산을 통한 변환

데이터프레임의 각 열은 시리즈이므로, **시리즈 간의 연산**이 가능합니다. 다양한 컬럼의 연산을 활용하여 데이터를 변환하거나 새로운 컬럼을 생성할 수 있습니다.

```python
# "어른" 컬럼의 모든 값에 200을 더해 덮어씌우기
df["어른"] = df["어른"] + 200

# "동물원매출" 컬럼 생성 (입장객 수 * 요금)
df["동물원매출"] = df["어른"]*5000 + df["청소년"]*3000
```

※ 이 변환들은 실제 강의 진행 시에는 적용하지 않고 이론 설명에 사용됩니다.

### 🔍쉬운설명
데이터프레임의 각 열은 시리즈이기 때문에, 엑셀에서처럼 각 열의 값들을 가지고 서로 더하거나 빼거나 곱하는 등의 계산을 할 수 있습니다. 예를 들어, '어른' 입장료에 200원 할인을 적용하고 싶으면 `df['어른'] = df['어른'] - 200`처럼 계산할 수 있고, '동물원 매출'처럼 새로운 정보를 만들고 싶으면 각 입장객 수에 요금을 곱하고 더해서 새 열을 만들 수도 있습니다. 이처럼 **시리즈 연산**을 통해 데이터를 새롭게 만들거나 수정할 수 있습니다.

### 열 전체 변환: `map()`

`map()` 메서드는 데이터프레임의 특정 열 전체를 변환하는 데 사용됩니다. 딕셔너리 등을 사용하여 변환 방식을 지정하고 해당 컬럼에 적용합니다.

```python
df["컬럼이름"].map(딕셔너리 등)
```

### 🔍쉬운설명
`map()` 함수는 특정 열의 모든 값을 한 번에 다른 값으로 바꿔줄 때 사용합니다. 예를 들어, '요일' 열에 `0, 1, 2...` 숫자가 있는데, 이걸 '월', '화', '수'... 같은 한글로 바꾸고 싶을 때 유용합니다. **딕셔너리**(`{키: 값, ...}`)를 만들어서 "0일 때는 '월'로 바꿔줘, 1일 때는 '화'로 바꿔줘"라고 알려주면, `map()` 함수가 그 딕셔너리에 따라 모든 값을 자동으로 바꿔줍니다.

---

### 데이터프레임에 `map()` 적용하기

`df`의 `"요일"` 컬럼 값이 숫자로 표시되어 있을 때, 딕셔너리의 Key와 Value를 활용하여 숫자를 글자로 변경합니다.

```python
week = {0:'월', 1:'화', 2:'수', 3:'목', 4:'금', 5:'토', 6:'일'}
df['요일'] = df['요일'].map(week)
```

### 🔍쉬운설명
앞서 설명한 `map()` 함수의 실제 예시입니다. '요일' 열이 숫자로 되어 있는데, 0은 월요일, 1은 화요일... 이런 식으로 매칭되는 딕셔너리(`week`)를 만듭니다. 그리고 `df['요일'].map(week)`를 실행하면 '요일' 열의 모든 숫자가 해당 딕셔너리의 값(한글 요일)으로 한 번에 바뀝니다. 훨씬 알아보기 쉬워지겠죠?

---

### 데이터에 함수 적용: `apply()`

`apply()` 메서드는 데이터프레임에 함수를 적용할 때 사용됩니다. `map()`과 달리 복수의 컬럼에도 사용 가능합니다. **`axis`** 인자는 함수를 적용할 방향을 지정하며, `axis=0`이면 열 단위, `axis=1`이면 행 단위로 함수가 적용됩니다(기본값은 `0`).

```python
df["컬럼이름"].apply(함수, axis=0 또는 1)
```

### 🔍쉬운설명
`apply()` 함수는 `map()`보다 더 강력한 함수 적용 도구입니다. `map()`은 주로 하나의 열에 대해 값을 1대1로 바꿀 때 사용하지만, `apply()`는 더 복잡한 사용자 정의 함수를 만들어서 열 전체나 행 전체에 적용할 수 있습니다. **`axis=0`**은 각 '열'마다 함수를 적용하고, **`axis=1`**은 각 '행'마다 함수를 적용하라는 의미입니다. 마치 엑셀에서 특정 함수를 한 열 전체에 적용하거나, 한 행 전체에 적용하는 것과 비슷합니다.

---

### 데이터프레임에 `apply()` 적용하기

`'눈'`과 `'비'`를 `'눈/비'`로 합치는 `weather` 함수를 선언하고, `"날씨"` 컬럼에 `apply()`를 적용하여 값을 변환합니다.

```python
def weather(e):
    if e == '눈' or e == '비':
        return '눈/비'
    else:
        return e

df['날씨'] = df['날씨'].apply(weather)
```

### 🔍쉬운설명
`apply()` 함수의 예시입니다. '날씨' 열에 '눈', '비', '구름 많음', '맑음' 등의 값이 있을 때, '눈'과 '비'를 묶어서 **'눈/비'**라는 하나의 카테고리로 만들고 싶다고 가정해봅시다. 이때 `weather`라는 함수를 정의해서, 입력값이 '눈'이나 '비'면 '눈/비'를 돌려주고, 아니면 원래 값을 돌려주도록 합니다. 그리고 `df['날씨'].apply(weather)`를 실행하면 '날씨' 열의 모든 값이 이 `weather` 함수를 거쳐 새로운 값으로 변환됩니다.

### 참고: `lambda` 함수

`lambda` 함수는 간단하게 함수를 선언하는 문법입니다. 한 줄로 표현되며, 콜론(`:`) 왼쪽에는 인자를, 오른쪽에는 반환값을 작성합니다.

```python
# 일반 함수
def times2(x):
    return 2 * x

# lambda 함수로 표현
times2 = lambda x: 2 * x

# 두 개의 인자를 받는 일반 함수
def add(x, y):
    return x + y

# 두 개의 인자를 받는 lambda 함수로 표현
add = lambda x, y: x + y
```

### 🔍쉬운설명
`lambda` 함수는 **'익명 함수'**라고도 불리는데, 아주 간단한 함수를 만들 때 편리하게 한 줄로 작성할 수 있게 해줍니다. `def`로 시작하는 일반 함수처럼 이름을 따로 붙이지 않아도 되기 때문에 코드를 더 간결하게 만들 수 있습니다. `lambda 인자1, 인자2: 반환값` 형태로 사용하며, 콜론 `:` 왼쪽에는 함수가 받을 값(인자)을 쓰고, 오른쪽에는 그 인자를 가지고 무엇을 계산해서 돌려줄지(반환값)를 씁니다.

---

### `lambda` 함수를 활용한 `apply` 활용

위에서 정의한 `weather` 함수를 `lambda` 함수로 간단하게 표현하여 `apply()`에 바로 적용할 수 있습니다.

```python
df['날씨'] = df['날씨'].apply(lambda e: '눈/비' if e == '눈' or e == '비' else e)
```

### 🔍쉬운설명
`apply()` 함수는 외부 함수를 전달받아 사용하기도 하지만, **`lambda` 함수**를 사용하면 필요한 함수를 그 자리에서 바로 만들어서 적용할 수 있습니다. 위 예시처럼 '눈'과 '비'를 '눈/비'로 합치는 간단한 로직은 `lambda` 함수로 한 줄에 표현하여 코드를 훨씬 간결하게 만들 수 있습니다. `lambda e: ...`는 `e`라는 값을 받아서 `:` 뒤의 계산을 하고 그 결과를 돌려주라는 의미입니다. `if-else` 조건문도 `lambda` 함수 안에 함께 사용할 수 있습니다.

## 데이터 요약하기

### 데이터 요약

데이터 요약은 데이터의 정보를 요약해서 확인하기 위한 과정입니다. 데이터에 대한 정보를 미리 파악하여 추후 분석 방향을 판단하는 데 도움이 됩니다.

### 🔍쉬운설명
데이터 요약은 데이터를 본격적으로 분석하기 전에 **'데이터 탐색'**을 통해 데이터가 어떤 특징을 가지고 있는지 파악하는 과정입니다. 데이터의 평균은 얼마인지, 가장 큰 값과 작은 값은 무엇인지 등을 살펴보면서, 어떤 분석을 해야 할지 미리 계획을 세울 수 있습니다. 마치 여행 가기 전에 목적지의 날씨나 특징을 미리 알아보는 것과 같아요.

---

### 데이터 통계값 확인: `mean()`, `min()`, `max()`, `median()`

`mean()`, `min()`, `max()`, `median()` 등의 메서드를 사용하여 데이터의 통계값을 확인할 수 있습니다. 데이터프레임 전체 또는 특정 컬럼에 적용할 수 있습니다.

```python
df.mean()                   # 데이터프레임의 모든 숫자 컬럼에 대한 평균
df["컬럼이름"].mean()        # 특정 컬럼의 평균
```

### 🔍쉬운설명
`mean()`, `min()`, `max()`, `median()`은 데이터의 기본적인 통계 정보를 계산해주는 함수들입니다.

- **`mean()`**: 모든 값의 평균을 계산합니다.
- **`min()`**: 가장 작은 값을 찾아줍니다.
- **`max()`**: 가장 큰 값을 찾아줍니다.
- **`median()`**: 데이터를 크기 순으로 나열했을 때 가운데 있는 값을 찾아줍니다.

이 함수들을 사용하면 데이터가 전반적으로 어떤 수준인지, 범위는 어느 정도인지 등을 쉽게 파악할 수 있습니다.

---

### 데이터 전체 통계: `describe()`

`describe()` 메서드는 데이터프레임이나 시리즈의 간단한 통계 정보를 요약해서 확인 가능합니다. **평균(`mean`), 표준편차(`std`), 최소값(`min`), 25/50/75% 분위수, 최대값(`max`)** 등을 출력합니다.

```python
df.describe()
```

### 🔍쉬운설명
`describe()` 함수는 데이터프레임의 **'종합 건강검진 결과표'**와 같습니다. 이 함수 하나로 평균, 최소값, 최대값은 물론이고, 데이터가 얼마나 퍼져있는지(표준편차), 그리고 데이터를 100등분 했을 때 25등, 50등(중앙값), 75등에 해당하는 값은 얼마인지(분위수) 등 다양한 통계 정보를 한 번에 보여줍니다. 데이터를 빠르게 이해하고 특징을 파악하는 데 매우 유용합니다.

---

### 데이터 그룹화: `groupby()`

`groupby()` 메서드는 데이터를 특정 기준으로 그룹으로 묶어 분석할 때 사용됩니다. `df.groupby("컬럼이름1")["컬럼이름2"].집계함수()` 형태로 사용하며, `groupby()`를 적용한 결과는 `DataFrameGroupBy` 형태입니다.

```python
df.groupby("날씨")["총계"].mean()
```

위 코드는 `df`의 `"날씨"` 컬럼을 기준으로 그룹화하여 `"총계"` 값의 평균을 집계합니다.

### 🔍쉬운설명
`groupby()` 함수는 데이터를 특정 기준에 따라 여러 그룹으로 나눈 다음, 각 그룹별로 통계 계산을 할 때 사용합니다. 예를 들어, '날씨' 별로 '총 입장객 수'의 평균을 알고 싶다면, `groupby('날씨')`로 날씨별 그룹을 만들고, 그 그룹의 '총 입장객 수'에 대해 `mean()`(평균)을 계산할 수 있습니다. 마치 학생들을 **반별로 나눈 다음, 각 반의 평균 점수를 계산**하는 것과 같은 원리입니다.

---

### 2개 이상의 컬럼을 기준으로 그룹화

`groupby()`는 2개 이상의 컬럼을 기준으로 집계도 가능합니다. 컬럼 이름들을 리스트로 묶어 `df.groupby(["컬럼이름1", "컬럼이름2"])` 형태로 지정합니다.

```python
df.groupby(["날씨", "공휴일"])["총입장객수"].mean()
```

위 코드는 `df`의 `"날씨"`와 `"공휴일"` 컬럼을 기준으로 그룹화하여 `"총입장객수"` 컬럼의 평균값을 집계합니다.

### 🔍쉬운설명
`groupby()`는 한 가지 기준뿐만 아니라 **여러 가지 기준을 동시에** 사용해서 그룹을 나눌 수도 있습니다. 예를 들어, '날씨'와 '공휴일 여부' 두 가지 기준을 함께 사용해서 "비 오는 공휴일" 그룹, "맑은 평일" 그룹 등으로 더 세분화된 그룹을 만든 다음, 각 그룹의 '총 입장객 수' 평균을 계산할 수 있습니다. 이렇게 하면 데이터의 다양한 측면을 함께 고려한 분석이 가능해집니다.

---

### 특정 컬럼을 지정하지 않고 전체 컬럼에 대한 집계

`df.groupby("컬럼이름").집계함수()` 형태로 특정 컬럼을 지정하지 않으면, 그룹화된 데이터프레임의 **모든 숫자 컬럼**에 대해 집계 함수가 적용됩니다.

```python
df.groupby("날씨").mean()
```

위 코드는 `df`의 `"날씨"` 컬럼을 기준으로 그룹화하여 모든 컬럼의 평균값을 집계합니다.

### 🔍쉬운설명
`groupby()`를 사용할 때, 특정 컬럼의 집계를 명시하지 않으면, 그룹화된 데이터프레임에 포함된 **모든 숫자 컬럼에 대해 집계 함수가 자동으로 적용**됩니다. 예를 들어, `df.groupby("날씨").mean()`이라고만 하면, '날씨'별로 '유료합계', '어른', '청소년' 등 모든 숫자 관련 열의 평균을 한 번에 계산해 보여줍니다. 이렇게 하면 데이터의 전반적인 그룹별 특성을 빠르게 파악할 수 있습니다.

---

## 데이터 추출하기

### 데이터 추출

데이터 추출은 원하는 구간 또는 조건에 해당하는 데이터를 선택하는 과정입니다. 데이터 분석 결과를 얻기 위해, 적절한 데이터를 선택하고 추출하는 데 필요한 과정입니다.

### 🔍쉬운설명
데이터 추출은 수많은 데이터 중에서 우리가 정말 필요한 데이터만 골라내는 과정입니다. 예를 들어, 2018년 데이터만 보고 싶다거나, '성적'이 90점 이상인 학생들만 보고 싶을 때 데이터를 걸러내는 것이죠. 이렇게 원하는 데이터만 뽑아내야 더 정확하고 의미 있는 분석을 할 수 있습니다.

---

### 참고: Pandas 논리 연산자

Pandas에서는 복수 조건을 사용할 때 다음과 같은 논리 연산자를 사용합니다.

- `and` → `&`
- `or` → `|`
- `not` → `~`

소괄호 `()`를 사용하여 우선순위를 명시해야 합니다.

```python
# A가 30보다 크고 50보다 작다
(A > 30) & (A < 50)

# A가 30보다 크거나 B가 50보다 작다
(A > 30) | (B < 50)
```

> **주의**: 부등호는 한 번에 하나의 비교만 가능합니다 (예: `30 < A < 50` ❌)

### 🔍쉬운설명
데이터를 추출할 때 여러 조건을 동시에 적용해야 할 때가 많습니다. 이때 `and`나 `or` 같은 논리 연산자를 사용하는데, Pandas에서는 파이썬의 `and`, `or` 대신 **`&`(and), `|`(or), `~`(not)** 기호를 사용합니다. 여러 조건을 묶을 때는 꼭 `()` 소괄호를 사용해서 어떤 조건들을 먼저 묶어서 계산할지 명확히 해줘야 합니다. 예를 들어 '나이가 10세 이상이면서 키가 150cm 이상인 사람'을 찾을 때 `&`를 사용하고, '날씨가 맑음이거나 구름 조금인 날'을 찾을 때 `|`를 사용합니다.

---

### 조건에 따른 인덱싱: Boolean Indexing

비교 연산자나 논리 연산자를 사용하여 데이터프레임에서 조건에 맞는 행을 추출할 수 있습니다. `df[조건식]` 형태로 사용합니다.

```python
df[df["어른"] > 1000]
```

위 코드는 `df`의 `"어른"` 컬럼 값이 1000보다 크다라는 조건식을 만족하는 데이터를 추출합니다.

### 🔍쉬운설명
불리언 인덱싱은 **'참' 또는 '거짓' 조건**에 따라 데이터를 추출하는 방법입니다. 예를 들어, '어른' 입장객 수가 1000명보다 많은 날만 보고 싶다면, `df['어른'] > 1000`이라는 조건식을 만들 수 있습니다. 이 조건식은 각 행에 대해 `True`(참) 또는 `False`(거짓)를 반환하고, Pandas는 `True`인 행들만 골라내서 보여줍니다. 마치 질문에 "예"라고 답한 사람만 남기는 것과 같습니다.

---

### 논리 연산자를 활용한 Boolean Indexing

Pandas 논리 연산자를 활용하면 복잡한 조건을 추가하여 데이터를 추출할 수 있습니다.

```python
df[(df["어른"] > 1000) & (df["어린이"] > 1000)]
```

위 코드는 `df`의 `"어른"` 컬럼 값이 1000보다 크고 `"어린이"` 컬럼 값이 1000보다 크다라는 조건식을 만족하는 데이터를 추출합니다.

### 🔍쉬운설명
여러 개의 조건을 동시에 사용하여 데이터를 추출할 수 있습니다. 예를 들어, '어른' 입장객 수가 1000명보다 많고(`> 1000`), 동시에(`&`) '어린이' 입장객 수도 1000명보다 많은 날만 보고 싶다면 위 코드처럼 두 조건을 `&`로 연결하고 각각 소괄호로 묶어주면 됩니다. 이렇게 하면 원하는 데이터를 더 정교하게 필터링할 수 있습니다.

---

### 라벨을 활용한 데이터 추출: `loc`

`loc`은 **인덱스 이름**과 **컬럼 이름(라벨)**을 입력받아 해당 데이터를 추출할 때 사용합니다.

```python
df.loc["인덱스이름", "컬럼이름"]
df.loc[456, "총계"]                               # index가 456인 행의 "총계"
df.loc[[24, 67, 126], ["공휴일", "어른", "어린이"]]  # index가 24, 67, 126인 행
df.loc[35:40, :]                                  # index가 35부터 40까지의 모든 열
```

### 🔍쉬운설명
`loc`은 **'이름'**을 사용해서 데이터를 찾을 때 쓰는 도구입니다. 행의 이름(인덱스)과 열의 이름(컬럼명)을 정확히 알려주면 해당 위치의 데이터를 찾아줍니다.

- `df.loc['학생이름', '과목이름']`: 특정 학생의 특정 과목 점수를 찾을 때
- `df.loc[['학생1', '학생2'], ['과목A', '과목B']]`: 여러 학생의 여러 과목 점수를 찾을 때
- `df.loc['시작이름':'끝이름', :]`: 특정 이름부터 특정 이름까지의 모든 열 데이터를 찾을 때 (`:는 '모두'`라는 의미)

이름 기반이기 때문에 숫자로 된 인덱스도 그 **'숫자 자체'**가 이름으로 쓰입니다.

---

### `loc`과 Boolean Indexing을 활용한 데이터 추출

`loc`에서 인덱스이름 대신 Boolean Indexing을 활용하면 조건에 맞는 데이터 추출이 가능합니다.

```python
df.loc[(df["어른"] > 1000) | (df["어린이"] > 1000), ["날짜", "공휴일", "어른", "어린이", "총계"]]
```

위 코드는 `"어른"` 컬럼 값이 1000보다 크거나 `"어린이"` 컬럼 값이 1000보다 큰 행의 `"날짜"`, `"공휴일"`, `"어른"`, `"어린이"`, `"총계"` 컬럼 데이터를 추출합니다.

### 🔍쉬운설명
`loc`은 이름으로 찾을 때만 쓰는 것이 아니라, **`True/False` 조건식을 활용**해서 더 복잡한 조건으로 행을 선택할 때도 유용합니다. `df.loc[조건식, ['원하는', '열', '이름']]`처럼 사용하면, 조건식에 맞는 행들 중에서 원하는 열들만 뽑아낼 수 있습니다. 마치 "키가 170 이상이거나 몸무게가 70 이상인 사람들의 이름과 키만 보여줘"라고 요청하는 것과 같습니다. `loc`과 불리언 인덱싱을 함께 쓰면 아주 정교하게 데이터를 추출할 수 있습니다.

---

### 순서를 활용한 데이터 추출: `iloc`

`iloc`은 행과 열의 **위치(순서)**를 나타내는 정수를 입력받아 해당 데이터를 추출할 때 사용합니다.

```python
df.iloc[행의 위치, 열의 위치]
df.iloc[42, 5]      # 42번째 행의 5번째 열 데이터 추출
df.iloc[3:7, 4:7]   # 3~6번째 행의 4~6번째 열 데이터 추출
```

### 🔍쉬운설명
`iloc`은 **'순서'**를 사용해서 데이터를 찾을 때 쓰는 도구입니다. 파이썬에서 리스트의 인덱스처럼 **0부터 시작하는 순서 번호**를 사용합니다.

- `df.iloc[행_순서, 열_순서]`: 특정 순서의 행과 열이 만나는 값을 찾을 때
- `df.iloc[시작_행:끝_행, 시작_열:끝_열]`: 특정 범위의 행과 열을 찾을 때 (주의: 끝 순서는 포함되지 않음)

`loc`이 이름으로 찾는다면, `iloc`은 **'첫 번째', '두 번째'** 같은 순서로 찾는다고 생각하면 됩니다.

---

### `loc` vs `iloc`

- `loc`은 **index 이름**을 활용하여 인덱싱합니다.
- `iloc`은 **정수형 위치(순서)**를 활용하여 인덱싱합니다.

```python
grade.loc["연우", "수학"]   # "연우" 학생의 "수학" 점수 (80)
grade.iloc[3, 1]            # 3번째 인덱스(연우)의 1번째 컬럼(수학)
```

### 🔍쉬운설명
`loc`과 `iloc`의 가장 큰 차이점은 데이터를 찾는 방식입니다.

- **`loc`**은 **'이름표'(라벨)**를 보고 찾아갑니다. 예를 들어 '연우'라는 이름의 학생과 '수학'이라는 과목 이름을 보고 찾아갑니다.
- **`iloc`**은 **'순서'**를 보고 찾아갑니다. 예를 들어 0부터 세어서 3번째 학생(연우)과 1번째 과목(수학)의 순서를 보고 찾아갑니다.

두 함수 모두 데이터를 추출하는 데 사용되지만, 어떤 방식으로 데이터를 지정할지에 따라 선택하여 사용해야 합니다.

---

### `loc`과 `iloc`을 활용한 값 변환

`loc`과 `iloc`을 활용하여 특정 원소의 값을 변환할 수 있습니다. 바꿀 위치를 지정하고 해당 위치에 넣을 값을 지정합니다.

```python
df.loc["서아", "국어"] = 100   # "서아" 학생의 "국어" 점수를 100으로 변경
df.iloc[1, 1] = 99             # 1번째 인덱스(도윤)의 1번째 컬럼(수학)을 99로 변경
```

### 🔍쉬운설명
`loc`과 `iloc`은 데이터를 추출하는 것 외에도 **특정 위치의 값을 바꾸는 데도** 사용됩니다. 예를 들어, `df.loc['서아', '국어'] = 100`이라고 하면 '서아' 학생의 '국어' 점수가 100점으로 바뀝니다. `df.iloc[1, 1] = 99`라고 하면 두 번째 행, 두 번째 열의 값이 99로 바뀝니다. 마치 엑셀에서 특정 셀을 클릭해서 값을 수정하는 것과 같습니다.

---

## 데이터 정제하기

### 데이터 정제

원본(Raw) 데이터는 불완전하거나 부정확한 경우가 많습니다. 데이터가 누락되어 있거나, 잘못된 값이 포함되어 있는 경우 등 다양한 문제가 존재하며, 이러한 문제들을 해결하기 위해 데이터를 제거하거나 대체하는 등 다양한 정제 과정이 필요합니다.

### 🔍쉬운설명
데이터 정제는 **'더러운' 데이터를 '깨끗하게'** 만드는 과정입니다. 실제 데이터는 종종 비어있거나(결측치), 잘못 입력되었거나(오류값), 형식이 일관되지 않은 경우가 많습니다. 이런 문제들을 그대로 두고 분석하면 엉뚱한 결과가 나오기 때문에, 데이터 정제 과정을 통해 문제를 수정하거나 제거해서 데이터를 신뢰할 수 있는 상태로 만들어야 합니다. 마치 요리하기 전에 재료를 손질하는 것과 같습니다.

---

### 데이터 정렬: `sort_values()`

`sort_values()` 메서드는 데이터프레임의 특정 컬럼 값을 기준으로 전체 데이터를 정렬할 때 사용합니다.

```python
df.sort_values("컬럼이름", ascending=True 또는 False)
```

- `ascending=True`: 오름차순 정렬 (기본값)
- `ascending=False`: 내림차순 정렬

```python
df.sort_values("총계")                      # "총계" 컬럼을 기준으로 오름차순 정렬
df.sort_values("총계", ascending=False)     # "총계" 컬럼을 기준으로 내림차순 정렬
```

### 🔍쉬운설명
`sort_values()` 함수는 데이터를 특정 열의 값을 기준으로 정렬할 때 사용합니다. 예를 들어 '총 입장객 수'가 적은 날부터 많은 날 순서로 데이터를 보고 싶다면 `ascending=True`(오름차순), 많은 날부터 적은 날 순서로 보고 싶다면 `ascending=False`(내림차순)를 지정해주면 됩니다. 마치 시험 점수가 높은 순서대로 학생들을 정렬하는 것과 같습니다.

---

### 인덱스 재지정: `reset_index()`

`reset_index()` 메서드는 데이터프레임의 인덱스를 처음부터 다시 지정해줄 때 사용합니다. 데이터를 정렬하는 등의 작업을 하다 보면 인덱스가 뒤섞이게 되는데, 이때 `reset_index()`를 활용하여 인덱스를 초기화할 수 있습니다.

```python
df.reset_index()              # 기존 인덱스를 "index"라는 새 컬럼으로 추가하며 초기화
df.reset_index(drop=True)     # 기존 인덱스를 버리고 인덱스 초기화
```

`reset_index()`를 사용하면 기존의 인덱스를 저장하는 `"index"` 컬럼이 새로 생깁니다. 만약 기존 인덱스를 버리고 싶다면 **`drop=True`** 옵션을 사용합니다.

### 🔍쉬운설명
데이터를 정렬하거나 필터링하다 보면, 행들의 순서가 바뀌면서 원래의 인덱스(순서 번호)가 뒤죽박죽이 될 수 있습니다. `reset_index()` 함수는 이렇게 엉킨 인덱스를 **0부터 다시 깔끔하게 재정렬**해주는 역할을 합니다. 이때 원래의 인덱스를 새로운 `'index'`라는 열로 남겨둘 수도 있고, `drop=True` 옵션을 사용해서 아예 버릴 수도 있습니다. 마치 흩어진 카드들을 다시 1번부터 순서대로 정리하는 것과 같습니다.

---

### 데이터 삭제: `drop()`

`drop()` 메서드는 데이터프레임에서 특정 행이나 열을 삭제할 때 사용합니다.

```python
df.drop("행/열이름", axis=0 또는 1)
```

- `axis=0`: 행 삭제 (기본값)
- `axis=1`: 열 삭제

```python
df = df.drop(["유료합계", "무료합계"], axis=1)
```

위 코드는 `df`에서 `"유료합계"`, `"무료합계"` 컬럼(`axis=1`이므로)을 삭제하고 `df`에 저장(덮어씌우기)합니다.

### 🔍쉬운설명
`drop()` 함수는 데이터프레임에서 필요 없는 행이나 열을 지울 때 사용합니다. 무엇을 지울지는 '이름'으로 알려주고, 무엇을 지울지(행인지 열인지)는 `axis` 값으로 알려줍니다.

- **`axis=0`**: 행을 지웁니다. (`df.drop(지울_행_이름, axis=0)`)
- **`axis=1`**: 열을 지웁니다. (`df.drop(지울_열_이름, axis=1)`)

지운 결과는 새로운 데이터프레임으로 반환되므로, 원본에 적용하려면 **반드시 다시 저장**해야 합니다. 마치 보고서에서 불필요한 문단이나 표를 삭제하는 것과 같습니다.

---

### 열이름 바꾸기: `rename()`

`rename()` 메서드는 데이터프레임의 특정 열 이름을 바꿀 때 사용합니다.

```python
df.rename(columns={"바꿀컬럼이름": "새컬럼이름"})
```

```python
df = df.rename(columns={"총계": "총입장객수"})
```

위 코드는 `df`에서 `"총계"` 컬럼의 이름을 `"총입장객수"`로 변환한 뒤 `df`에 저장(덮어씌우기)합니다.

### 🔍쉬운설명
`rename()` 함수는 데이터프레임의 열 이름을 바꿀 때 사용합니다. 예를 들어 '총계'라는 열 이름을 '총입장객수'로 바꾸고 싶을 때 `df.rename(columns={'총계': '총입장객수'})`처럼 딕셔너리 형태로 **바꿀_이름: 새_이름**을 지정해줍니다. 이 함수도 변환된 결과를 반환하므로, 원본에 적용하려면 다시 저장해야 합니다. 이렇게 하면 열 이름이 더 명확해져서 데이터를 이해하기 쉬워집니다.

---

### 결측치 탐색: `isnull()`

`isnull()` 메서드는 데이터프레임의 각 원소가 **결측치(missing value)**인지 여부를 `True`/`False`로 반환합니다. `sum()`과 함께 사용하여 각 컬럼별로 결측치가 몇 개 존재하는지 확인할 수 있습니다.

```python
df.isnull()           # 각 원소가 결측치인지 True/False로 반환
df.isnull().sum()     # 각 컬럼별 결측치 개수 확인
```

데이터의 크기가 클 때는 `df.isnull().sum()`을 사용하여 한눈에 결측치 분포를 파악하는 것이 효율적입니다.

### 🔍쉬운설명
`isnull()` 함수는 데이터가 비어있는지(결측치인지)를 알려줍니다. 비어있으면 `True`, 아니면 `False`를 반환합니다. 데이터가 많을 때는 `df.isnull().sum()`처럼 `sum()` 함수를 뒤에 붙여서 사용하면, 각 열에 몇 개의 비어있는 값이 있는지 **숫자로 한 번에** 보여줍니다. 이렇게 하면 어느 열에 문제가 있고, 얼마나 심각한지 빠르게 파악할 수 있습니다. 마치 설문지에서 응답하지 않은 질문이 몇 개인지 세어보는 것과 같아요.

---

### 결측치 채우기: `fillna()`

`fillna()` 메서드는 데이터프레임 내의 **결측치를 다른 값으로 대체**하기 위해 사용합니다.

```python
df.fillna(대체값)
df["청소년"] = df["청소년"].fillna(int(df["청소년"].mean()))
```

위 코드는 `"청소년"` 컬럼의 결측치를 해당 컬럼의 평균값(`mean()`, 정수로 변환)으로 채워 넣고, 다시 `"청소년"` 컬럼에 저장합니다.

### 🔍쉬운설명
`fillna()` 함수는 비어있는 데이터(결측치)를 어떤 다른 값으로 **채워 넣을 때** 사용합니다. 예를 들어, '청소년' 입장객 수에 결측치가 있을 때, 그 결측치를 '청소년' 입장객 수의 평균으로 채울 수 있습니다. 그러면 데이터의 빈 공간이 채워져서 분석에 사용할 수 있게 됩니다. 결측치를 어떤 값으로 채울지는 데이터의 특성에 따라 **평균, 중앙값, 0** 등 다양한 방식으로 선택할 수 있습니다.

---

### 결측치 데이터 삭제하기: `dropna()`

`dropna()` 메서드는 데이터프레임 내의 **결측치가 포함된 행을 삭제**하는 데 사용합니다.

```python
df.dropna(subset="컬럼이름", ignore_index=True 또는 False)
```

- **`subset`**: 특정 컬럼에 결측치가 존재하는지를 검사합니다 (생략 시 전체 컬럼).
- **`ignore_index`**: `True`면 결측치가 존재하는 행이 삭제된 데이터프레임의 인덱스를 초기화하고, `False`면 그대로 둡니다 (기본값은 `False`).

```python
df = df.dropna(subset=["청소년"], ignore_index=True)
```

위 코드는 `df`에서 `"청소년"` 컬럼에 결측치가 있는 행을 삭제한 뒤 인덱스를 초기화하여 `df`에 저장(덮어씌우기)합니다.

### 🔍쉬운설명
`dropna()` 함수는 `fillna()`와 반대로, 결측치가 있는 행이나 열을 **아예 삭제해 버릴 때** 사용합니다.

- **`subset=['컬럼이름']`**: 특정 열에만 결측치가 있는 경우에만 해당 행을 지우도록 할 수 있습니다. 이 옵션을 사용하지 않으면 데이터프레임의 어떤 열이든 결측치가 하나라도 있으면 그 행 전체를 지워버립니다.
- **`ignore_index=True`**: 행이 삭제되면서 인덱스가 중간중간 비게 되는데, 이 옵션을 사용하면 인덱스를 0부터 다시 깔끔하게 정렬해줍니다.

결측치를 채울지, 아니면 삭제할지는 데이터의 양, 결측치의 중요도 등에 따라 신중하게 결정해야 합니다.

---

## 데이터 병합하기

### 데이터 병합

데이터 병합은 데이터가 여러 개로 분산되어 있거나, 추가 데이터를 합치고 싶은 경우에 사용됩니다. 데이터 병합을 통해 데이터의 일관성을 유지하고 분석 결과의 신뢰도를 높일 수 있습니다.

### 🔍쉬운설명
데이터 병합은 여러 개의 데이터를 하나로 합치는 과정입니다. 예를 들어, 한 파일에는 학생들의 성적 정보만 있고, 다른 파일에는 학생들의 개인 정보(이름, 주소 등)만 있다면, 이 두 파일을 합쳐야 완전한 정보를 얻을 수 있습니다. 이렇게 데이터를 합치면 더 풍부하고 정확한 분석을 할 수 있습니다. 마치 여러 조각으로 나뉜 퍼즐을 맞춰서 하나의 그림을 완성하는 것과 같습니다.

---

### 데이터 합치기: `concat()`

`concat()` 함수는 공통의 컬럼을 가지는 데이터프레임을 합치는 데 사용됩니다.

```python
pd.concat([데이터프레임1, 데이터프레임2], axis=0 또는 1,
          join='inner' 또는 'outer', ignore_index=True 또는 False)
```

- **`axis`**: `0`이면 위아래로(행 추가), `1`이면 좌우로(열 추가) 합칩니다 (기본값은 `0`).
- **`join`**:
  - `'outer'`: 컬럼을 합집합으로 처리하여 모든 컬럼을 포함합니다 (기본값).
  - `'inner'`: 컬럼을 교집합으로 처리하여 공통 컬럼만 포함합니다.
- **`ignore_index`**: `True`면 기존 인덱스를 무시하고 새로운 인덱스를 부여합니다 (기본값은 `False`).

### 🔍쉬운설명
`concat()`은 데이터를 **'이어붙이는'** 함수입니다. 두 개의 데이터프레임을 단순히 위아래로 붙이거나(행 추가), 옆으로 붙일 때(열 추가) 사용합니다.

- **`axis=0`** (기본값): 데이터프레임을 위아래로 붙여서 행의 수가 늘어납니다. 마치 엑셀 시트 아래에 다른 시트 내용을 복사해서 붙여넣는 것과 같습니다.
- **`axis=1`**: 데이터프레임을 좌우로 붙여서 열의 수가 늘어납니다.

`join` 옵션은 어떤 열을 기준으로 붙일지 결정하고, `ignore_index`는 붙인 후 인덱스를 새로 만들지 아니면 기존 인덱스를 유지할지 정합니다.

---

### 데이터 합치기: `concat()` 예시

`df`(2016-01-01 ~ 2019-03-31 서울대공원 입장객 데이터)와 `df2`(2019-04-01 ~ 2019-04-30 데이터)를 `concat`으로 병합하는 예시입니다.

```python
df_concat = pd.concat([df, df2], axis=0, join='inner', ignore_index=True)
```

- `axis=0`이므로 세로 방향으로 병합하고,
- `join='inner'`이므로 두 데이터프레임 모두에 포함된 컬럼만 가져오며,
- `ignore_index=True`이므로 인덱스를 다시 부여합니다.

`df_concat`은 2016년 1월 1일부터 2019년 4월 30일까지의 서울대공원 입장객 데이터(폐쇄 기간 제외)를 포함하게 됩니다.

### 🔍쉬운설명
실제 `concat()` 활용 예시입니다. 2016년부터 2019년 3월까지의 데이터(`df`)와 2019년 4월 데이터(`df2`)를 합쳐서 하나의 큰 데이터셋(`df_concat`)을 만드는 것입니다. `axis=0`은 위아래로 붙여서 월별 데이터를 이어 붙이는 것이고, `join='inner'`는 두 데이터에 공통으로 있는 열만 남기는 것입니다 (예를 들어 `df2`에 없는 열은 `df_concat`에 포함되지 않습니다). `ignore_index=True`는 데이터를 붙인 후 인덱스 순서를 0부터 다시 매겨서 깔끔하게 만듭니다.

---

### 데이터 합치기: `merge()`

`merge()` 함수는 **특정 컬럼을 기준(key)**으로 데이터를 합치는 데 사용됩니다.

```python
pd.merge(데이터프레임1, 데이터프레임2, on="컬럼이름",
         how='inner' 또는 'outer' 또는 'left' 또는 'right')
```

- **`on`**: 데이터프레임을 합칠 때 기준(key)이 되는 컬럼의 이름.
- **`how`**: 데이터프레임의 데이터를 합치는 방법으로 4가지 방법이 존재합니다.
  - `'inner'`: 두 데이터프레임에 모두 존재하는 데이터만 (교집합).
  - `'outer'`: 두 데이터프레임의 모든 데이터 사용 (합집합).
  - `'left'`: 데이터프레임1에 있는 모든 데이터.
  - `'right'`: 데이터프레임2에 있는 모든 데이터.

### 🔍쉬운설명
`merge()`는 `concat()`과는 다르게, 엑셀에서 `'VLOOKUP'`이나 데이터베이스에서 `'JOIN'`처럼 **특정 기준(열)을 가지고 데이터를 합칠 때** 사용합니다. 예를 들어, 두 개의 표에 '월'이라는 공통된 열이 있다면, 이 '월'을 기준으로 서로 관련된 데이터들을 찾아 합쳐줍니다. `how` 옵션은 어떤 방식으로 합칠지를 결정합니다.

- **`'inner'`**: 양쪽에 모두 있는 데이터만 합칩니다. (공통분모)
- **`'outer'`**: 양쪽의 모든 데이터를 합치고, 없는 부분은 비워둡니다. (전체)
- **`'left'`**: 첫 번째 데이터(`df1`)에 있는 모든 데이터를 기준으로 합치고, 두 번째 데이터(`df2`)에 없는 부분은 비워둡니다.
- **`'right'`**: 두 번째 데이터(`df2`)에 있는 모든 데이터를 기준으로 합치고, 첫 번째 데이터(`df1`)에 없는 부분은 비워둡니다.

---

### 예시로 보는 `merge()`

`merge()` 함수를 `inner`, `outer`, `left`, `right` `how` 옵션별로 사용하는 예시입니다.

**두 데이터프레임**:
- `df1` (월별 평균 입장객수): 월 3, 4, 5, 6 포함
- `df2` (월별 미세먼지): 월 5, 6, 7, 8 포함

```python
# inner merge: 월 5, 6만 존재
inner_df = pd.merge(df1, df2, on='월', how='inner')

# outer merge: 월 3, 4, 5, 6, 7, 8 모두 존재, 없는 값은 NaN
outer_df = pd.merge(df1, df2, on='월', how='outer')

# left merge: df1 기준, 월 3, 4, 5, 6만 존재, df2에 없는 값은 NaN
left_df = pd.merge(df1, df2, on='월', how='left')

# right merge: df2 기준, 월 5, 6, 7, 8만 존재, df1에 없는 값은 NaN
right_df = pd.merge(df1, df2, on='월', how='right')
```

### 🔍쉬운설명
이 예시들은 `merge()` 함수의 `how` 옵션이 어떻게 작동하는지 보여줍니다.

- **`inner`**: 두 표에 모두 '월 5'와 '월 6'이 있었기 때문에 이 두 월의 데이터만 합쳐집니다.
- **`outer`**: 모든 월(3, 4, 5, 6, 7, 8)의 데이터를 합치고, 한쪽에만 있는 데이터의 빈칸은 `NaN`(결측치)으로 채워집니다.
- **`left`**: 첫 번째 표(`df1`)에 있는 월(3, 4, 5, 6)을 기준으로 데이터를 합칩니다. 두 번째 표(`df2`)에 없는 월(3, 4)의 미세먼지 값은 `NaN`이 됩니다.
- **`right`**: 두 번째 표(`df2`)에 있는 월(5, 6, 7, 8)을 기준으로 데이터를 합칩니다. 첫 번째 표(`df1`)에 없는 월(7, 8)의 평균 입장객수 값은 `NaN`이 됩니다.

어떤 데이터를 기준으로 합칠 것인지에 따라 `how` 옵션을 적절히 선택하는 것이 중요합니다.

---

### 데이터 합치기: `merge()` 활용

서울대공원 입장객 데이터(`df`)와 미세먼지 데이터(`mm`)를 `"날짜"` 컬럼을 기준으로 `merge()` 하는 예시입니다.

```python
df_merge = pd.merge(df, mm, on="날짜", how='left')
```

`df`와 `mm`을 병합한 데이터프레임을 `df_merge`에 저장합니다. `on="날짜"`이므로 `"날짜"` 컬럼을 기준으로, `how='left'`이므로 왼쪽에 위치한 `df`의 `"날짜"` 컬럼을 기준으로 병합합니다.

이때 중요한 것은 핵심 데이터는 입장객 수 데이터이며, 서울대공원이 **폐쇄된 기간의 미세먼지 데이터는 의미가 없으므로** `how='left'`로 설정하여 입장객 데이터가 존재하는 날짜만을 남깁니다.

`df_merge`는 2016년 1월 1일부터 2019년 3월 31일까지의 서울대공원 입장객 수와 미세먼지 데이터(폐쇄 기간 제외)를 포함합니다.

### 🔍쉬운설명
이 예시는 실제 분석에서 `merge()`를 어떻게 사용하는지 보여줍니다. '서울대공원 입장객 데이터'와 '미세먼지 데이터'를 합칠 때, 단순히 모든 날짜의 미세먼지 정보를 가져오는 것이 아니라, **대공원이 문을 열었던 날짜의 미세먼지 정보만** 필요합니다. 그래서 `how='left'`를 사용해서 왼쪽에 있는 '입장객 데이터'의 날짜들을 기준으로 합치게 됩니다. 이렇게 하면 대공원이 문을 닫아서 입장객이 없었던 날의 미세먼지 정보는 가져오지 않게 되어, 필요한 데이터만 정확하게 분석할 수 있습니다.

# 시각화 (Matplotlib & Seaborn)

## 요약

이 강의 자료는 **Matplotlib**과 **Seaborn**을 활용한 데이터 시각화 기법에 대해 다룹니다. Matplotlib의 기본 문법부터 시작하여 선 그래프, 막대 그래프, 파이 차트, 히스토그램, 박스 그래프, 산점도 및 히트맵을 그리는 방법을 학습하고, 각 그래프의 구성 요소와 데이터를 효과적으로 표현하는 다양한 옵션을 상세히 설명합니다.

---

## Matplotlib 기본 문법

**Matplotlib**은 Python의 강력한 시각화 패키지입니다. 주로 `matplotlib.pyplot` 모듈을 `plt`라는 별칭으로 `import`하여 사용하며, Seaborn이나 Pandas와 같은 다른 패키지와 함께 사용하면 더욱 풍부한 시각화 기능을 활용할 수 있습니다.

**선 그래프 그리기**는 `plt.plot(xdata, ydata)` 함수를 사용하며, X축과 Y축 데이터를 순서대로 전달합니다. 그래프를 화면에 표시하려면 `plt.show()` 함수를 호출해야 합니다.

**그래프의 제목 설정**은 `plt.title("제목")` 함수를 통해 문자열을 전달하여 설정합니다. 축의 레이블은 `plt.xlabel("X축 레이블")`과 `plt.ylabel("Y축 레이블")` 함수로 설정할 수 있습니다.

**텍스트 크기 변경**은 `fontsize` 매개변수를 사용하여 제목이나 레이블의 글자 크기를 조절합니다.

**여러 그래프 함께 표시하기**는 `plt.plot()` 함수를 여러 번 호출하여 하나의 그림에 여러 선 그래프를 추가할 수 있습니다.

**그래프 범례 표시**는 `plt.legend()` 함수를 통해 각 그래프의 이름을 순서대로 전달하여 범례를 표시하거나, `plt.plot()` 함수 호출 시 `label` 매개변수로 이름을 지정한 후 `plt.legend()`를 호출하면 됩니다.

**`figure`와 `subplot`**은 Matplotlib에서 그래프를 구성하는 중요한 개념입니다.

- **여러 개의 `figure` 사용**: `plt.figure(ID, figsize=(width, height))` 함수를 사용하여 여러 개의 `figure` 객체를 생성하고 선택할 수 있습니다. 각 `figure`에 그래프를 그리고 제목을 설정할 수 있으며, `plt.show()`로 모든 `figure`를 화면에 표시합니다.
- **서브플롯 사용**: `fig, (ax1, ax2) = plt.subplots(rows, cols)` 함수를 사용하여 하나의 `figure` 안에 여러 서브플롯을 생성할 수 있습니다. 생성된 서브플롯은 `ax1.plot()`, `ax2.plot()`과 같이 개별적으로 접근하여 그래프를 그립니다.
- **`figure`**: 여러 그래프를 담을 수 있는 **'종이'**에 해당합니다.
- **`subplot` (axes)**: 실제 그래프가 그려지는 **'캔버스'**에 해당하며, `ax1`, `ax2` 등으로 지칭합니다. 하나의 `figure` 안에 여러 `subplot`을 배치할 수 있습니다.

**서브플롯이 겹치는 현상 방지**: 여러 서브플롯의 간격이 충분하지 않아 일부 텍스트나 그래프 요소가 겹칠 수 있습니다. 이를 방지하기 위해 **`constrained_layout=True`** 옵션을 `plt.subplots()` 함수에 전달하면 그래프 간의 위치를 자동으로 고려하여 배치합니다.

### 🔍쉬운설명
Matplotlib은 파이썬으로 그림을 그리는 데 쓰는 도구 상자라고 생각하면 됩니다. 우리가 그림을 그릴 때 종이(`figure`)와 캔버스(`subplot`)가 필요하듯이, Matplotlib에서도 **`figure`는 전체 그림이 그려질 큰 공간**을, **`subplot`은 그 안에 실제로 그림을 그리는 작은 공간**을 의미해요.

예를 들어, 하나의 그림에 선 그래프를 그리려면 `plt.plot()`을 사용하고, 그림을 화면에 띄우려면 `plt.show()`를 사용합니다. 제목이나 축 이름도 쉽게 붙일 수 있고, 글자 크기도 `fontsize`로 조절할 수 있습니다. 만약 여러 개의 선 그래프를 한 그림에 그리고 싶으면 `plt.plot()`을 여러 번 호출하면 되죠.

그리고 그래프에 어떤 내용이 담겨있는지 알려주는 범례(legend)는 `plt.legend()`로 표시할 수 있습니다. 만약 그림이 여러 개 필요하면 `plt.figure()`로 여러 장의 종이를 만들 수 있고, 한 장의 종이 안에 여러 개의 작은 그림(`subplot`)을 그리고 싶다면 `plt.subplots()`를 사용하면 됩니다. 이때 그림들이 겹치지 않도록 `constrained_layout=True` 옵션을 주면 자동으로 예쁘게 정렬해줍니다.

## Seaborn 기본 문법

**Seaborn**은 Matplotlib을 기반으로 하는 Python 데이터 시각화 라이브러리입니다. Matplotlib만 사용할 때보다 시각적으로 더 완성도 높고 간단하게 시각화하는 함수들을 제공합니다.

**라이브러리 불러오기**: Seaborn은 보통 `import seaborn as sns`로 불러오며, 여전히 Matplotlib의 함수들이 필요한 경우가 많으므로 `import matplotlib.pyplot as plt`와 함께 불러오는 것이 일반적입니다.

**선 그래프 그리기**: Seaborn에서 선 그래프는 `sns.lineplot(x=data_x, y=data_y)` 함수로 그립니다. Matplotlib의 `plt.plot()`과 유사하게 x, y축에 해당하는 데이터를 전달합니다. Seaborn은 Matplotlib보다 더 적은 코드로도 깔끔한 그래프를 그릴 수 있습니다.

**그래프 범례 표시**: Seaborn의 `lineplot()` 함수에서 `label` 매개변수를 사용하여 각 선에 이름을 지정하면, `plt.legend()`를 따로 호출하지 않아도 자동으로 범례가 표시됩니다. Seaborn의 대부분 매개변수는 Matplotlib과 유사하게 작동합니다.

**테마 사용하기**: `sns.set_style("테마이름")` 함수를 사용하여 내장된 테마(예: `"darkgrid"`, `"whitegrid"`, `"ticks"`, `"white"`, `"dark"`)를 적용하여 그래프의 스타일을 변경할 수 있습니다. 이를 통해 더 완성도 높은 시각화 그림을 그릴 수 있습니다.

### 🔍쉬운설명
Seaborn은 Matplotlib을 더 쉽고 예쁘게 사용할 수 있도록 도와주는 도우미 같은 라이브러리입니다. 마치 Matplotlib이 기본적인 미술 도구라면, **Seaborn은 예쁜 그림을 바로 그릴 수 있게 해주는 템플릿과 고급 붓**을 제공하는 거죠.

Seaborn을 쓸 때는 `import seaborn as sns`라고 부르고, Matplotlib과 함께 쓰는 경우가 많습니다. 선 그래프를 그릴 때 `sns.lineplot()`을 사용하면, Matplotlib보다 훨씬 간단하게 멋진 그래프를 만들 수 있습니다. 심지어 각 선의 이름을 `label`로 지정해주면, 범례도 알아서 딱! 하고 나타납니다.

`sns.set_style()` 함수로 `'darkgrid'`, `'whitegrid'` 같은 미리 정해진 테마를 적용해서 그래프의 분위기를 확 바꿀 수도 있어요. 이 테마들은 그래프를 더 전문적이고 보기 좋게 만들어줍니다.

## 선 그래프와 막대 그래프

### 선 그래프

선 그래프는 가로축과 세로축을 갖는 좌표 평면 상에 데이터를 선으로 표현한 그래프입니다.

- 막대 그래프와 함께 여러 데이터를 비교하는 데 유용합니다.
- **시간, 순서, 변화** 등에 따른 데이터의 추이와 패턴을 시각적으로 파악하기에 좋습니다.
- 간단하게 그려볼 수 있는 그래프 유형입니다.

---

### 선 그래프 그리기 (Seaborn vs Matplotlib)

- **Seaborn**: `sns.lineplot(x=year, y=python)` 함수를 사용하여 선 그래프를 그립니다. x, y축에 해당하는 데이터를 전달합니다.
- **Matplotlib**: `plt.plot(year, python)` 함수를 사용하여 선 그래프를 그립니다. x, y축에 해당하는 데이터를 전달합니다.

**축의 눈금 조절하기**: 기본적으로 x축 눈금은 자동으로 설정되지만, `plt.xticks([값1, 값2, ...])` 함수를 사용하여 특정 연도나 원하는 값으로 눈금을 직접 설정할 수 있습니다. Y축 눈금은 `plt.yticks()`로 설정합니다.

**선 그래프의 모양 변경**: 그래프의 시각적 직관성을 높이기 위해 선의 모양을 변경할 수 있습니다.

- **마커(`marker`)**: 데이터 포인트를 나타내는 작은 심볼입니다. `marker="."`와 같이 설정합니다.
- **선 모양(`linestyle`)**: 선의 형태를 설정합니다 (예: `--` 점선, `-` 실선). `linestyle="--"`와 같이 설정합니다.
- **색(`color`)**: 그래프의 색을 설정합니다 (예: `r` 빨강, `b` 파랑). `color="r"`와 같이 설정하며, 선 그래프 외 다른 그래프에도 적용 가능합니다.

**격자 추가하기**: `plt.grid(True)` 함수를 호출하여 그래프에 격자를 추가할 수 있습니다. `axis` 매개변수를 통해 격자를 표시할 축을 설정할 수 있으며, 기본값은 `"both"`입니다.

**데이터 묶기 (`groupby`)**: 데이터를 특정 기준으로 묶어(예: 월별) 집계(예: 평균)를 계산하여 시각화할 수 있습니다. Pandas의 `groupby()`와 `mean(numeric_only=True)` 함수를 활용합니다.

**Matplotlib으로 선 그래프 그리기 (월별 데이터)**: 묶인 데이터를 바탕으로 `plt.plot(df_mon["칼럼"], label="레이블")` 함수를 사용하여 월별 선 그래프를 그립니다. `plt.legend()`와 `plt.show()`를 함께 사용합니다.

**Seaborn으로 선 그래프 그리기 (월별 데이터)**: Seaborn의 `sns.lineplot(data=df, x="월", y="어른", errorbar=None)` 함수를 사용하여 데이터프레임을 직접 전달하고, x, y축에 해당하는 칼럼 이름을 지정하여 선 그래프를 그립니다. `errorbar=None`으로 설정하여 오차 막대를 표시하지 않을 수 있습니다. Seaborn을 사용하더라도 `plt.xticks()`와 같은 Matplotlib 함수로 옵션을 조절할 수 있습니다.

**오차 막대 (error bar)**: `sns.lineplot()`에서 `errorbar=None`을 전달하지 않으면 기본값으로 **95% 신뢰구간**의 오차 막대가 표시됩니다. 오차 막대는 데이터의 편차를 시각적으로 보여줍니다.

---

### 막대 그래프

막대 그래프는 가로축과 세로축을 갖는 좌표 평면 상에 데이터를 막대로 표현한 그래프입니다.

- 복수의 데이터를 비교하는 데 유용합니다.
- **값의 크고 작음**을 한눈에 파악하기 용이한 시각화 형태입니다.

**막대 그래프 그리기 (Seaborn vs Matplotlib)**:
- **Seaborn**: `sns.barplot(data=df, x="요일", y="청소년", errorbar=None)` 함수를 사용합니다. 데이터프레임을 `data`에 전달하고, x, y축에 해당하는 칼럼 이름을 `x`, `y`에 전달합니다. `errorbar=None`으로 오차 막대를 제거할 수 있습니다.
- **Matplotlib**: `plt.bar(df_week["요일"], df_week["청소년"])` 함수를 사용합니다. x, y축에 해당하는 데이터를 직접 전달합니다. Matplotlib은 세로 막대 그래프(`plt.bar()`)와 가로 막대 그래프(`plt.barh()`)를 모두 지원합니다.

**Seaborn으로 막대 그래프 그리기 (오차 막대)**: Seaborn의 `sns.barplot()` 함수는 기본적으로 **95% 신뢰구간**의 오차 막대를 보여줍니다. `errorbar=None`을 전달하여 이 오차 막대를 제거할 수 있습니다.

**그룹으로 묶어서 시각화하기**: `hue` 매개변수를 사용하여 특정 기준(예: `"공휴일"`)으로 데이터를 그룹화하여 시각화할 수 있습니다.

```python
sns.barplot(data=df, x="날씨", y="어린이", errorbar=None, hue="공휴일")
```

위와 같이 사용하면 공휴일 여부에 따른 어린이 입장객 수의 변화를 한눈에 파악할 수 있습니다.

### 🔍쉬운설명
선 그래프는 시간에 따른 변화나 어떤 순서에 따른 추이를 볼 때 아주 좋아요. 예를 들어, 연도별 파이썬 점유율이 어떻게 변했는지 한눈에 볼 수 있죠. Matplotlib의 `plt.plot()`이나 Seaborn의 `sns.lineplot()`으로 그릴 수 있습니다.

그래프를 더 깔끔하게 보이게 하려면 축의 눈금(`plt.xticks`), 선의 모양(`marker`, `linestyle`), 색깔(`color`)을 변경할 수 있습니다. 또한, `plt.grid(True)`로 격자를 추가하여 데이터를 더 쉽게 읽을 수 있도록 할 수도 있습니다. 데이터가 너무 많아서 복잡할 때는 `groupby`로 데이터를 묶어서 평균을 내는 등의 방법으로 요약해서 볼 수도 있어요. Seaborn의 `lineplot`은 기본적으로 데이터의 **오차 범위(error bar)**를 보여주는데, 필요 없으면 `errorbar=None`으로 끌 수 있습니다.

막대 그래프는 여러 항목을 서로 비교할 때 유용합니다. 예를 들어, 요일별 청소년 입장객 수를 막대로 표현해서 어느 요일에 청소년이 많이 왔는지 쉽게 알 수 있죠. Matplotlib에서는 `plt.bar()`로 세로 막대를, `plt.barh()`로 가로 막대를 그릴 수 있습니다. Seaborn에서는 `sns.barplot()`을 사용하는데, 여기에도 `errorbar=None`을 적용해서 오차 막대를 끌 수 있습니다. 특히 **`hue` 매개변수**를 사용하면 날씨와 공휴일처럼 두 가지 기준에 따라 데이터를 그룹 지어 비교할 수 있어서, 더 깊은 통찰력을 얻을 수 있습니다.

## 파이 차트와 히스토그램

### 파이 차트

파이 차트는 데이터의 **분포나 비율**을 시각화하는 그래프입니다. 전체 데이터에서 특정 범주가 차지하는 상대적인 비율을 원형으로 표현하며, 각 부채꼴의 중심각이 해당 범주의 비율을 나타냅니다. Matplotlib의 `pie()` 함수를 사용하여 그립니다 (Seaborn에는 파이 차트 기능이 별도로 없습니다).

**데이터 불러오기 및 준비**: 파이 차트를 그리기 위해서는 먼저 분석하려는 데이터를 준비해야 합니다. 특정 연도(`df["연"] == 2019`)의 데이터를 필터링하고, 필요한 칼럼(예: `"어른"`, `"청소년"`, `"어린이"`)만 선택하여 각 칼럼의 합계를 구합니다. 이렇게 준비된 데이터는 Pandas Series 형태로 `data_2019`에 저장됩니다.

**레이블과 데이터 나누기**: 파이 차트를 그리기 위해 `data_2019` 시리즈의 인덱스(레이블)와 값(데이터)을 각각 리스트로 변환합니다. `labels = data_2019.index.tolist()`와 `data = data_2019.tolist()`를 사용합니다.

**파이 차트 그리기**: `plt.pie(x=data, labels=labels)` 함수를 사용하여 파이 차트를 그립니다. `x`에는 각 범주의 비율을 나타내는 수치를, `labels`에는 각 값에 해당하는 이름을 전달합니다.

**비율 표시하기**: `autopct` 매개변수에 포맷 문자열(예: `"%1.1f%%"`)을 전달하여 각 부채꼴에 구체적인 수치(소수점 첫째 자리까지 표시하고 `'%'` 기호 붙이기)를 표시할 수 있습니다.

**범례 추가하기**: `plt.legend()` 함수를 호출하여 범례를 표시할 수 있습니다. `loc` 매개변수를 통해 범례의 위치를 조절할 수 있으며, 예를 들어 `loc='lower left'`는 범례를 왼쪽 아래에 배치합니다.

---

### 히스토그램

히스토그램은 특정 구간에 해당하는 **빈도**를 막대로 표현하는 그래프입니다.

- 데이터가 각 구간에 몇 개 포함되어 있는지 나타냅니다.
- 특정 값의 **빈도 분포**를 분석할 때 유용합니다.

**토요일 데이터 가져오기**: 히스토그램을 그리기 위해 특정 조건(예: `"요일"`이 `"토"`)을 만족하는 데이터를 필터링하여 새로운 데이터프레임(`df_sat`)에 저장합니다.

**히스토그램 그리기**:
- **Matplotlib**: `plt.hist(df_sat["어린이"], bins=10)` 함수를 통해 히스토그램을 그립니다. `bins` 매개변수에 구간의 수를 전달하여 몇 개의 막대로 나눌지 설정할 수 있습니다.
- **Seaborn**: `sns.histplot(data=df_sat, x="어른")` 함수를 통해 히스토그램을 그립니다. `data`에 데이터프레임을, `x`에 시각화할 칼럼 이름을 전달합니다.

**여러 개의 히스토그램 그리기**: Seaborn의 `histplot` 함수는 `hue` 매개변수를 사용하여 특정 기준(예: `"연"`)으로 그룹을 나누어 여러 히스토그램을 한 번에 그릴 수 있습니다. 이를 통해 **연도별 데이터 분포**를 비교할 수 있습니다.

**구간의 범위 설정하기**: `binrange=(min_val, max_val)` 매개변수를 사용하여 전체 구간의 범위를 직접 전달할 수 있습니다. `binrange`를 전달하지 않으면 데이터의 최소값과 최대값으로 자동 설정됩니다.

**겹치는 그래프 분리하기**: `multiple="dodge"` 매개변수를 `histplot`에 전달하여 여러 그룹의 막대가 겹치지 않고 나란히 표시되도록 분리할 수 있습니다. `shrink` 매개변수(예: `shrink=0.8`)로 각 막대의 너비를 조절할 수 있습니다 (원래 너비의 80%).

### 🔍쉬운설명
파이 차트는 **전체에서 각 부분이 얼마나 차지하는지** 보여줄 때 사용합니다. 마치 피자 한 판에서 각 토핑이 차지하는 조각의 크기를 보여주는 것과 같죠. Matplotlib의 `plt.pie()` 함수로 그릴 수 있어요. 파이 차트를 그리려면 먼저 각 부분이 얼마나 되는지(데이터)와 각 부분이 무엇을 의미하는지(레이블)를 준비해야 합니다. 그리고 `autopct` 옵션을 사용하면 각 조각에 퍼센트를 표시해서 더 정확한 정보를 알 수 있습니다. `plt.legend()`로 범례를 추가해서 어떤 색깔이 어떤 부분을 나타내는지 설명해줄 수도 있습니다.

히스토그램은 데이터가 **어떤 값들에 몰려있는지, 즉 데이터의 '분포'**를 볼 때 유용합니다. 예를 들어, 특정 날(토요일)에 어린이 입장객이 몇 명이었는지, 그 입장객 수가 어떤 범위에 많이 분포하는지 막대 그래프 형태로 보여주는 것이죠. Matplotlib의 `plt.hist()` 함수나 Seaborn의 `sns.histplot()` 함수를 사용합니다. `bins` 옵션으로 막대의 개수, 즉 구간의 수를 조절할 수 있고, `binrange` 옵션으로 전체 구간의 범위를 설정할 수도 있습니다. 만약 여러 그룹의 히스토그램을 한 번에 보고 싶을 때는 Seaborn의 `hue` 옵션을 사용하면 됩니다. 이때 막대들이 겹치지 않도록 `multiple="dodge"`와 `shrink` 옵션을 사용해 막대들을 예쁘게 분리해서 볼 수 있습니다.

## 박스 그래프

### 박스 그래프의 이해

박스 그래프(Box Plot)는 데이터의 **분포**를 보여주는 시각화 그래프입니다.

- 수치형 변수의 데이터를 요약하고 비교하는 데 사용됩니다.
- 단순히 평균만으로는 알 수 없는 데이터의 **이상치(Outliers), 중앙값(Median), 사분위수(Quartiles), 분포의 형태** 등을 파악할 수 있습니다.

**박스 (Box)**:
- **중간값(Median)**: 박스 안의 가운데 선입니다. 데이터를 크기 순으로 나열했을 때 정중앙에 오는 값입니다.
- **사분위수(Q1, Q3)**: 박스의 상단과 하단 경계입니다.
  - **Q1 (1사분위수)**: 전체 데이터 중 하위 25%에 해당하는 값입니다.
  - **Q3 (3사분위수)**: 전체 데이터 중 상위 25%에 해당하는 값입니다.
- **IQR (Interquartile Range)**: 박스의 높이를 나타내며, 중간 50%가 분포하는 범위를 보여줍니다.

**수염 (Whisker)**: 박스의 범위를 벗어나 확장된 선입니다. 일반적으로 Q1에서부터 `1.5 * IQR`만큼의 범위까지를 나타냅니다. 이 범위를 벗어나는 데이터는 이상치로 간주될 수 있습니다.

**이상치 (Outlier)**: 수염의 범위를 벗어난 값들입니다. 매우 극단적인 값이거나 잘못된 측정으로 인해 발생한 값일 수 있습니다. 박스 그래프에서는 보통 **점**으로 표시됩니다.

---

### 박스 그래프 그리기

**데이터 준비하기**: 박스 그래프를 그리기 위해 특정 조건을 만족하는 데이터를 필터링합니다. 예를 들어, `df[(df["연"] == 2018) & (df["월"] == 4)]`를 사용하여 2018년 4월 데이터만 선택하고 `df_2018_apr`에 저장합니다.

**Matplotlib으로 그리기**: `plt.boxplot(df_2018_apr["어린이"])` 함수를 사용하여 데이터프레임의 특정 열(예: `"어린이"`)을 선택하여 박스 그래프를 그립니다.

**여러 개 그리기**: 여러 열에 대한 박스 그래프를 한 번에 그릴 수 있습니다.
```python
plt.boxplot([df["어린이"], df["어른"], df["청소년"]])
```
리스트 형태로 데이터를 전달하고, `plt.xticks()`로 각 박스에 대한 레이블을 설정할 수 있습니다. `plt.title()`로 그래프 제목을 추가합니다.

**Seaborn으로 그리기**: `sns.boxplot(data=df_2018_apr, y="어린이")` 함수를 사용하여 Seaborn으로 박스 그래프를 그립니다. `data`에 데이터프레임을 전달하고 `y`에 표시할 칼럼 이름을 전달합니다.

**2018년 데이터 가져오기 (월별 분포)**: `df_2018 = df[df["연"] == 2018]`와 같이 특정 연도 데이터를 가져와 새로운 데이터프레임에 저장합니다. 이 데이터를 사용하여 월별 데이터 분포를 시각화할 수 있습니다.

**월별 어린이 입장객 분포 시각화**:
```python
sns.boxplot(data=df_2018, x="월", y="어린이")
```
x축에는 월별 데이터를, y축에는 어린이 데이터를 표시하여 월별 어린이 입장객의 추세와 분포를 박스 그래프로 한눈에 확인할 수 있습니다.

### 🔍쉬운설명
박스 그래프는 데이터가 어떻게 퍼져있는지를 상자와 수염 모양으로 보여주는 그래프입니다. 단순히 '평균'만 봐서는 알기 어려운 데이터의 중요한 특징들을 파악할 수 있도록 도와주죠.

상자 안의 가운데 선은 데이터의 **'중앙값'**을 나타냅니다. 데이터를 작은 값부터 큰 값까지 쭉 나열했을 때 딱 중간에 있는 값이에요. 상자의 위쪽과 아래쪽 경계는 각각 **'상위 25% 지점(Q3)'**과 **'하위 25% 지점(Q1)'**을 나타냅니다. 이 상자 안에 전체 데이터의 절반이 들어있다고 생각하면 됩니다. 상자의 높이는 **'IQR'**이라고 부르는데, 데이터가 얼마나 퍼져있는지(변동성)를 보여줍니다. 상자 밖으로 뻗어 나온 선은 **'수염'**이라고 부르는데, 일반적인 데이터의 범위를 나타냅니다. 보통 IQR의 1.5배까지의 범위를 보여주죠. 수염 밖의 점들은 **'이상치'**라고 합니다. 이 값들은 다른 데이터들과는 너무 동떨어져 있어서 특별하게 봐야 할 값일 수 있어요. 실수로 잘못 입력된 값일 수도 있고, 아니면 정말 극단적인 상황을 나타내는 값일 수도 있습니다.

이러한 박스 그래프는 Matplotlib의 `plt.boxplot()`이나 Seaborn의 `sns.boxplot()`으로 그릴 수 있습니다. 특히 `sns.boxplot()`은 데이터프레임을 직접 넘겨주고 x와 y축에 원하는 칼럼 이름을 지정해주면 **월별 분포처럼 여러 그룹의 데이터 분포를 한 번에 비교**하기에 아주 편리합니다.

## 산점도와 히트맵

### 산점도 그래프

산점도(Scatter Plot)는 **두 변수 간의 관계**를 시각화하는 데 사용되는 통계적 그래프입니다.

- 각 데이터 포인트는 그래프의 X축과 Y축 상에서 위치를 나타냅니다.
- 두 변수의 **상관관계**를 직관적으로 확인할 수 있습니다.

**Matplotlib으로 그리기**: `plt.scatter(df['어른'], df['청소년'])` 함수를 사용하여 산점도를 그립니다. X좌표는 한 변수(예: 어른 입장객 수)를, Y좌표는 다른 변수(예: 청소년 입장객 수)를 표시합니다. 그래프의 각 점은 하루의 데이터를 나타냅니다.

**Seaborn으로 그리기**: `sns.scatterplot(data=df, x='어른', y='어린이')` 함수를 사용하여 Seaborn으로 산점도를 그립니다. `data` 매개변수에 데이터프레임을 전달하고 `x`, `y`에 각각의 칼럼 이름을 전달합니다.

**특정 범위만 보기**: 산점도에서 대부분의 점이 특정 범위 내에 존재하고 극히 일부 점만 크게 벗어나 있을 수 있습니다. `plt.ylim(min_y, max_y)`와 `plt.xlim(min_x, max_x)` 함수를 이용하여 X축과 Y축의 범위를 제한함으로써, 데이터가 밀집된 부분을 더 자세히 관찰할 수 있습니다.

---

### 상관관계 분석

상관관계는 두 변수 사이의 **관련성 또는 연관성**을 의미합니다.

- 두 변수가 함께 움직이는 경향이 있을 때 상관관계가 있다고 합니다.
- **양의 상관관계**: 한 변수가 증가할 때 다른 변수도 증가하는 경우 (예: 공부 시간 증가 → 성적 증가)
- **음의 상관관계**: 한 변수가 증가할 때 다른 변수가 감소하는 경우 (예: 운동량 증가 → 체중 감소)

산점도에서 데이터 분포가 일직선에 가까울수록 상관관계가 **강하다**고 추측할 수 있습니다.

---

### 상관계수

상관계수는 두 변수 사이의 **선형적인 관계의 강도**를 나타내는 수치입니다.

- 상관계수 값이 **1에 가까울수록** 양의 상관관계가 강합니다.
- 상관계수 값이 **-1에 가까울수록** 음의 상관관계가 강합니다.
- 상관계수 값이 **0에 가까울수록** 두 변수 사이에는 거의 관계가 없거나, 선형적인 관계가 매우 약합니다.

**상관관계 구하기**: Pandas 데이터프레임의 `.corr(numeric_only=True)` 함수를 사용하여 수치형 열들 간의 상관계수를 계산할 수 있습니다. 결과는 **상관 행렬(Correlation Matrix)** 형태로 반환됩니다.

---

### 히트맵

히트맵(Heatmap)은 데이터 값의 상대적인 크기를 **색상으로 표시**하여 시각화하는 그래프입니다.

- 2차원 표 형태의 데이터를 사용하여 생성됩니다.
- 값의 크기에 따라 다른 색상 맵을 사용하며, **값이 클수록 진한 색, 작을수록 연한 색**으로 표현됩니다.

**히트맵 그리기**: `sns.heatmap(df_corr)` 함수를 사용하여 상관 행렬(`df_corr`)을 히트맵으로 시각화합니다. 히트맵을 통해 어떤 변수들 사이에 상관관계가 강한지(색이 진할수록 1이나 -1에 가까워 강한 상관관계), 어떤 변수들 사이에 상관관계가 약한지(색이 옅거나 0에 가까울수록 약한 상관관계)를 한눈에 파악할 수 있습니다.

### 🔍쉬운설명
산점도 그래프는 두 가지 데이터가 서로 어떤 관계가 있는지 **점으로 찍어서** 보여주는 그림입니다. 예를 들어, '어른 입장객 수'와 '어린이 입장객 수'를 각각 X축과 Y축에 두고 점을 찍으면, 어른이 많이 오는 날 어린이가 얼마나 오는지 등 두 데이터 간의 경향을 볼 수 있습니다. 점들이 한쪽 방향으로 모여 있으면 상관관계가 있다고 추측할 수 있죠. Matplotlib의 `plt.scatter()`나 Seaborn의 `sns.scatterplot()`으로 그립니다. 너무 넓은 범위에 점이 흩어져 보일 때는 `plt.xlim()`이나 `plt.ylim()`으로 축 범위를 좁혀서 특정 부분을 확대해서 볼 수도 있습니다.

상관관계는 두 데이터가 함께 움직이는 경향을 말합니다.

- **'양의 상관관계'**는 한 데이터가 늘어나면 다른 데이터도 늘어나는 경우 (예: 키가 클수록 몸무게도 많이 나가는 경향).
- **'음의 상관관계'**는 한 데이터가 늘어나면 다른 데이터는 줄어드는 경우 (예: 추운 날씨일수록 아이스크림 판매량 감소).

이 관계의 강도를 숫자로 나타낸 것이 **상관계수**입니다. 상관계수가 1에 가까울수록 양의 상관관계가 아주 강하고, -1에 가까울수록 음의 상관관계가 아주 강합니다. 0에 가까우면 거의 관계가 없다고 봅니다. 이 상관계수는 Pandas의 `.corr()` 함수로 쉽게 계산할 수 있습니다.

이러한 상관계수 값을 표로 보면 숫자가 많아 복잡한데, 이를 색깔로 나타내서 한눈에 보기 쉽게 만든 것이 **히트맵**입니다. Seaborn의 `sns.heatmap()` 함수를 사용하면 상관계수가 높을수록 진한 색으로, 낮을수록 옅은 색으로 표현하여 어떤 데이터들끼리 서로 강한 관계를 가지는지 시각적으로 바로 파악할 수 있습니다.
