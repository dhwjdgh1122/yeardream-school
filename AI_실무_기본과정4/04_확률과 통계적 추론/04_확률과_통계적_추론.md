## 1. 사건과 확률의 개념

### (1) 확률과 용어 정의

**확률(Probability)** 은 여러 가능한 결과 중 특정한 일이 일어날 가능성을 **0과 1 사이의 값**으로 표현한 수치입니다. 동전을 던졌을 때 앞면이 나올 확률이 **0.5**인 것이 대표적인 예죠.

* **실험(Experiment) 또는 시행(Trial):** 여러 가능한 결과 중 하나가 나타나도록 하는 행위 (예: 동전 던지기)
* **표본공간(Sample Space, $\Omega$ 또는 $S$):** 실험에서 나타날 수 있는 **모든 결과들의 집합** (예: 동전 던지기 표본공간 $\Omega = \{H, T\}$)
* **사건(Event, $A$):** 표본공간의 **일부분(부분집합)** (예: 앞면이 나오는 사건 $A = \{H\}$)

표본공간의 원소 수를 $N(\Omega)$, 사건 $A$의 원소 수를 $N(A)$라 할 때, 사건 $A$가 발생할 확률 $P(A)$는 다음과 같습니다.

$$P(A) = \frac{N(A)}{N(\Omega)} = \frac{\text{사건 } A\text{의 경우의 수}}{\text{전체 가능한 경우의 수}}$$

### (2) 추출 방법

데이터나 표본을 뽑을 때는 **추출 방식**에 따라 다음 시행에 영향을 주는지 결정됩니다.

| 구분 | 개념 | 특징 및 예시 |
| --- | --- | --- |
| **복원추출** | 추출했던 원소를 다시 집어넣고 다음 추출을 시행 | 모든 시행이 **동일한 조건**에서 실행됨 (예: 공을 뽑아 확인 후 다시 넣기) |
| **비복원추출** | 추출했던 원소를 다시 넣지 않고 다음 추출을 시행 | 앞선 시행의 결과가 **다음 시행에 영향**을 줌 (예: 공을 뽑아 확인 후 밖에 두기) |

### (3) 사건의 기본 연산

* **여사건 ($A^c$):** 사건 $A$에 포함되지 않는 사건들의 집합
* **곱사건 ($A \cap B$):** 사건 $A$와 $B$가 **동시에** 발생할 사건들의 집합
* **합사건 ($A \cup B$):** 사건 $A$ **또는** $B$가 발생할 사건들의 집합
* **배반사건 (Disjoint Events):** 두 사건이 동시에 일어날 수 없는 관계, 즉 **$A \cap B = \emptyset$** 인 사건

### (4) 확률의 공리와 정리

**공리(Axiom)** 란 증명 없이 자명하게 accepted되는 기본 전제입니다.

* **확률의 공리:**
1. 모든 사건 $A$에 대하여 **$0 \le P(A) \le 1$**
2. 표본공간 전체의 확률 **$P(\Omega) = 1$**
3. 서로 배반인 사건들 $A_1, A_2, \dots$에 대해 $P(\bigcup_{i=1}^{\infty} A_i) = \sum_{i=1}^{\infty} P(A_i)$


* **확률의 주요 정리:**
1. 여사건의 확률: **$P(A^c) = 1 - P(A)$**
2. 덧셈정리: **$P(A \cup B) = P(A) + P(B) - P(A \cap B)$**
3. 포함 관계: $A \subset B$ 이면 **$P(A) \le P(B)$**

### 🔍 쉬운설명

확률의 기본 용어들이 헷갈리시나요? **주사위 던지기 게임**으로 비유해보겠습니다!

* **실험/시행:** 주사위를 굴리는 행동 자체입니다.
* **표본공간 ($\Omega$):** 주사위를 굴렸을 때 나올 수 있는 숫자 전체 판인 `{1, 2, 3, 4, 5, 6}`입니다.
* **사건 ($A$):** "짝수가 나오는 경우"처럼 우리가 관심 있는 조건인 `{2, 4, 6}`을 말합니다.
* **확률:** 전체 6개 구멍 중 짝수 구멍이 3개 있으니 확률은 `3/6 = 0.5`가 됩니다.
* **복원 vs 비복원:** 제비뽑기 상자에서 뽑은 제비를 **다시 상자에 넣고** 다음 사람에게 넘기면 **복원추출**, 내가 **가져가 버리면** 다음 사람의 확률이 달라지는 **비복원추출**입니다!

## 2. 경우의 수, 순열, 그리고 조합

### (1) 경우의 수 계산 원리

* **합의 법칙:** 사건 $A$와 $B$가 **동시에 일어나지 않을 때**, $A$가 발생하는 경우가 $m$가지, $B$가 $n$가지라면 $A$ 또는 $B$가 일어나는 경우의 수는 **$m + n$** 입니다.
* **곱의 법칙:** 사건 $A$와 $B$가 **동시에 또는 잇달아** 일어날 때, 경우의 수는 **$m \times n$** 입니다.

### (2) 팩토리얼 (Factorial)

1부터 어떤 양의 정수 $n$까지의 정수를 모두 곱한 것을 **`팩토리얼(!)`** 이라고 합니다. ($0! = 1$, $1! = 1$)

Python의 재귀 함수를 이용해 팩토리얼을 다음과 같이 구현할 수 있습니다.

```python
def fac(n):
    if n == 0 or n == 1:
        return 1
    else:
        return n * fac(n - 1)

# 사용 예시
print(fac(4)) # 4 * 3 * 2 * 1 = 24

```

### (3) 순열, 조합, 중복순열, 중복조합 비교

1. **순열 (Permutation, $_n P _k$):** 서로 다른 $n$개 중 $k$개를 선택하여 **순서를 고려하여** 나열하는 경우의 수

$$_n P _k = n(n-1)(n-2)\cdots(n-k+1) = \frac{n!}{(n-k)!}$$


2. **조합 (Combination, $_n C _k$):** 서로 다른 $n$개 중 $k$개를 **순서 상관없이** 선택하는 경우의 수

$$_n C _k = \frac{_n P _k}{k!} = \frac{n!}{k!(n-k)!}$$


3. **중복순열 (Permutation with Repetition, $_n \Pi _r$):** 중복을 허용하여 **순서 있게** $r$개를 나열하는 경우의 수

$$_n \Pi _r = n^r$$


4. **중복조합 (Combination with Repetition, $_n H _r$):** 중복을 허용하여 **순서 없이** $r$개를 선택하는 경우의 수

$$_n H _r = _{n+r-1} C _r$$



#### 개념 정리 비교표

| 개념 | 순서 고려 여부 | 중복 허용 여부 | 수학 공식 | Python `itertools` 모듈 함수 |
| --- | --- | --- | --- | --- |
| **순열** | **O** | **X** | $_n P _k$ | `permutations(iterable, k)` |
| **조합** | **X** | **X** | $_n C _k$ | `combinations(iterable, k)` |
| **중복순열** | **O** | **O** | $n^r$ | `product(iterable, repeat=r)` |
| **중복조합** | **X** | **O** | $_{n+r-1} C _r$ | `combinations_with_replacement(iterable, r)` |

#### 파이썬 실습 코드

```python
from itertools import permutations, combinations, product, combinations_with_replacement

data = ['A', 'B', 'C']

# 1. 순열 (3개 중 2개 뽑아 순서대로 나열)
print("순열:", list(permutations(data, 2)))

# 2. 조합 (3개 중 2개 순서 없이 뽑기)
print("조합:", list(combinations(data, 2)))

# 3. 중복순열 (3개 중 중복 허용하여 2개 뽑아 나열)
print("중복순열:", list(product(data, repeat=2)))

# 4. 중복조합 (3개 중 중복 허용하여 2개 순서 없이 뽑기)
print("중복조합:", list(combinations_with_replacement(data, 2)))

```

순열과 조합의 차이가 머릿속에 한 번에 안 들어오시나요? **반장 선거와 대표 선발**을 기억하세요!

## 3. 조건부 확률과 독립

### (1) 조건부 확률 (Conditional Probability)

**조건부 확률**이란 특정한 사건 $B$가 일어났다는 **추가 정보(조건)** 가 주어졌을 때, 사건 $A$가 일어날 확률을 의미하며 **$P(A\vert{}B)$** 로 표기합니다.

$$P(A\vert{}B) = \frac{P(A \cap B)}{P(B)} \quad (단, P(B) > 0)$$

이를 활용하면 곱사건의 확률도 계산할 수 있습니다: **$P(A \cap B) = P(A) P(B\vert{}A) = P(B) P(A\vert{}B)$**

#### 예시 데이터 표 (수강생 30명 조사)

| 응답 \ 성별 | 남 | 여 | 계 |
| --- | --- | --- | --- |
| **A** | 10 | 5 | 15 |
| **B** | 8 | 7 | 15 |
| **계** | 18 | 12 | 30 |

1. **전체 학생 중 A를 선택한 확률:** $P(A) = \frac{15}{30} = 0.5$
2. **여학생임을 알았을 때, 그 학생이 A 응답일 확률:** $P(A\vert{}\text{여}) = \frac{P(A \cap \text{여})}{P(\text{여})} = \frac{5/30}{12/30} = \frac{5}{12} \approx 0.416$

### (2) 독립 (Independence)

두 사건 $A$와 $B$ 사이에 아무런 연관성이 없어서, **사건 $B$가 일어나든 말든 사건 $A$의 확률에 전혀 영향을 주지 않는 상태**를 **독립**이라고 합니다.

$$\text{두 사건 } A, B\text{가 독립일 조건} \iff P(A \cap B) = P(A) \times P(B)$$

독립일 때 조건부 확률은 다음과 같이 단순화됩니다.

$$P(A\vert{}B) = \frac{P(A \cap B)}{P(B)} = \frac{P(A) \times P(B)}{P(B)} = P(A)$$

---

### 🔍 쉬운설명

**조건부 확률**은 전체 분모(표본공간)를 싹 줄여버리는 **"조건 돋보기"** 역할을 합니다!

원래 전체 학생 30명 중에서 A 응답자를 찾을 때는 분모가 `30`이었죠. 하지만 **"선택된 학생이 여학생일 때!"** 라는 조건이 붙는 순간, 전체 남아있는 남학생 18명은 세상에서 사라지고 **여학생 12명만으로 표본공간(분모)이 축소**됩니다. 그래서 답이 `5/12`가 되는 것이죠!

반대로 **독립**은 "오늘 비가 올 확률"과 "내가 점심에 짜장면을 먹을 확률"처럼 **서로 아무런 상관이 없는 관계**를 뜻합니다.

## 4. 확률분포 (Discrete & Continuous)

### (1) 확률변수와 확률분포

* **확률변수 (Random Variable, $X, Y$):** 표본공간의 각 근원사건에 **실수값**을 대응시킨 함수입니다. (예: 동전 2번 던질 때 앞면이 나온 횟수 $X \in \{0, 1, 2\}$)
* **확률분포 (Probability Distribution):** 확률변수가 가질 수 있는 값들과 그 값을 가질 **확률의 대응 관계**를 나타낸 것입니다.

### (2) 이산확률분포 vs 연속확률분포

확률변수의 특성에 따라 다음과 같이 두 가지로 구분됩니다.

┌─────────────────────────────────────────┐
│              확률 변수 (X)              │
└────────────────────┬────────────────────┘
│
┌─────────────┴─────────────┐
▼                           ▼
┌──────────────┐            ┌──────────────┐
│ 이산확률변수 │            │ 연속확률변수 │
│ (셀 수 있음) │            │ (구간/연속적)│
└──────┬───────┘            └──────┬───────┘
│                           │
▼                           ▼
┌──────────────┐            ┌──────────────┐
│ 확률질량함수 │            │ 확률밀도함수 │
│   (PMF)      │            │   (PDF)      │
└──────────────┘            └──────────────┘

| 구분 | 이산확률분포 (Discrete) | 연속확률분포 (Continuous) |
| --- | --- | --- |
| **변수 특징** | $0, 1, 2$처럼 개수를 **하나씩 셀 수 있음** | 키, 무게, 시간처럼 **연속적인 구간**의 실수값 |
| **함수 종류** | **확률질량함수 (PMF)** $f(x) = P(X=x)$ | **확률밀도함수 (PDF)** $f(x)$ |
| **확률 조건** | 1. $0 \le f(x_i) \le 1$<br>

<br>2. $\sum f(x_i) = 1$ | 1. 모든 $x$에 대해 $f(x) \ge 0$<br>

<br>2. $\int_{-\infty}^{\infty} f(x)dx = 1$ |
| **특정 구간 확률** | 해당 값들의 확률을 합산 | $P(a \le X \le b) = \int_{a}^{b} f(x)dx$ (적분 면적) |

### (3) 누적분포함수 (CDF, Cumulative Distribution Function)

확률변수 $X$가 특정 값 $x$ 이하일 확률을 누적하여 나타낸 함수 **$F(x) = P(X \le x)$** 입니다.

* **이산형 CDF:** $F(x) = \sum_{y \le x} p(y)$
* **연속형 CDF:** $F(x) = \int_{-\infty}^{x} f(y)dy$

---

### 🔍 쉬운설명

* **이산확률분포 (확률질량함수):** 계단을 하나씩 오르는 것과 같습니다. 주사위를 던졌을 때 1이 나올 확률, 2가 나올 확률처럼 **딱딱 짚어서 말할 수 있는 확률**입니다.
* **연속확률분포 (확률밀도함수):** 완만한 경사로를 걸어 올라가는 것과 같습니다. 키가 정확히 '170.000000...cm'일 확률은 0에 가깝지만, **'169cm ~ 171cm 사이'일 확률은 그래프 아래 면적**으로 구할 수 있죠!

## 5. 다양한 확률분포 상세 분석

### (1) 주요 이산확률분포

#### 1) 베르누이 분포 (Bernoulli Distribution)

결과가 오직 **성공(1) 또는 실패(0)** 두 가지만 존재하는 단 1회의 시행을 다룹니다. (성공 확률 $= p$)

$$f(x) = \begin{cases} p & (x=1) \\ 1-p & (x=0) \end{cases}$$

#### 2) 이항 분포 (Binomial Distribution, $B(n, p)$)

성공 확률이 $p$인 베르누이 시행을 **$n$번 독립적으로 반복**했을 때, **성공 횟수 $X$** 의 분포입니다.

$$p(x) = \binom{n}{x} p^x (1-p)^{n-x} \quad (x = 0, 1, 2, \dots, n)$$

```python
import scipy.stats as stats
import numpy as np

n, p = 10, 0.5
stat_bin = stats.binom(n, p)

# PMF(확률질량) & CDF(누적확률)
print("5번 성공할 확률:", stat_bin.pmf(5))
print("5번 이하로 성공할 확률:", stat_bin.cdf(5))

# 표본 추출 (랜덤 샘플링)
samples = np.random.binomial(n, p, size=100)

```

#### 3) 초기하 분포 (Hypergeometric Distribution, $Hyper(M, n, N)$)

**비복원추출** 상황에서 크기가 $M$인 모집단(관심 원소 수 $n$)으로부터 크기 $N$의 표본을 뽑을 때 관심 원소의 개수 $X$의 분포입니다.

$$p(X=x) = \frac{\binom{n}{x} \binom{M-n}{N-x}}{\binom{M}{N}}$$

* **예제:** 흰 공 6개, 검은 공 4개가 든 상자에서 5개의 공을 비복원추출로 꺼낼 때, 흰 공이 3개일 확률은?

$$p(X=3) = \frac{\binom{6}{3} \binom{4}{2}}{\binom{10}{5}} = \frac{20 \times 6}{252} = \frac{10}{21} \approx 0.476$$



```python
# M: 전체 개수(10), n: 관심 원소 수(6), N: 추출 표본 수(5)
stat_hyp = stats.hypergeom(10, 6, 5)
print("흰 공 3개가 나올 확률:", stat_hyp.pmf(3))

```

#### 4) 포아송 분포 (Poisson Distribution, $Poi(\lambda)$)

단위 시간이나 단위 공간 내에서 **매우 드물게 발생하는 사건의 발생 횟수**에 대한 분포입니다. ($\lambda$: 평균 발생 횟수)

$$p(X=x) = \frac{e^{-\lambda} \lambda^x}{x!} \quad (x = 0, 1, 2, \dots)$$

> **이항분포의 포아송 근사:** 이항분포 $B(n, p)$에서 시행 횟수 $n$이 매우 크고 성공 확률 $p$가 매우 작을 때, $\lambda = np$ 인 포아송 분포로 근사할 수 있습니다.

### (2) 주요 연속확률분포

#### 1) 균일 분포 (Uniform Distribution, $U(a, b)$)

구간 $[a, b]$ 내의 모든 점에서 확률밀도가 일정하게 균일한 분포입니다.

$$f(x) = \begin{cases} \frac{1}{b-a} & (a \le x \le b) \\ 0 & (x < a \text{ or } x > b) \end{cases}$$

```python
stat_uni = stats.uniform(loc=0, scale=10) # [0, 10] 구간
print("x=5에서의 PDF:", stat_uni.pdf(5)) # 1/10 = 0.1

```

#### 2) 정규 분포 (Normal Distribution, $N(\mu, \sigma^2)$)

자연계 및 사회현상에서 가장 대표적인 **좌우대칭 종모양(Bell-shape)** 분포로, 평균 $\mu$와 표준편차 $\sigma$로 결정됩니다.

$$f(x\vert{}\mu, \sigma) = \frac{1}{\sigma \sqrt{2\pi}} \exp\left( -\frac{(x-\mu)^2}{2\sigma^2} \right)$$

* **표준정규분포 ($Z \sim N(0, 1)$):** 정규분포를 따르는 변수 $X$를 **$Z = \frac{X - \mu}{\sigma}$** 로 표준화한 분포입니다.

```python
mu, sigma = 0, 1
stat_nor = stats.norm(mu, sigma)

print("z=0에서의 확률밀도:", stat_nor.pdf(0))
print("z가 1.96 이하일 누적확률:", stat_nor.cdf(1.96)) # 약 0.975

```

## 6. 모집단, 표본, 그리고 통계적 추론

### (1) 모집단과 표본

* **모집단 (Population):** 조사/분석하고자 하는 **관심 대상의 전체 집단**
* **표본 (Sample):** 모집단의 특성을 추정하기 위해 **일부 추출한 집단**
* **모수 (Parameter):** 모집단의 특성을 나타내는 미지의 진짜 값 (예: 모평균 $\mu$, 모표준편차 $\sigma$)
* **통계량 (Statistics):** 표본으로부터 직접 계산해낸 값 (예: 표본평균 $\bar{X}$, 표본표준편차 $s$)

┌─────────────────────────────────────────┐
│             모집단 (Population)         │
│               - 모수 ($\mu, \sigma$)     │
└────────────────────┬────────────────────┘
│  ▲
표집 (Sampling)  │  │  추론 (Inference)
▼  │
┌─────────────────────────────────────────┐
│               표본 (Sample)             │
│            - 통계량 ($\bar{X}, s$)      │
└─────────────────────────────────────────┘

### (2) 통계적 추론 (Statistical Inference)

표본자료를 바탕으로 미지의 **모수(모집단의 성질)를 추정**하거나 모수에 관한 **가설의 옳고 그름을 판단**하는 과정입니다.

1. **점추정 (Point Estimation):** 모수의 값에 가장 가까울 것으로 예상되는 **단 하나의 값**을 제시하는 방법 (예: 모평균 $\mu$의 점추정량은 표본평균 $\bar{X} = \frac{1}{n} \sum X_i$)
2. **구간추정 (Interval Estimation):** 모수를 포함할 것으로 기대되는 **적절한 구간 $[하한, 상한]$** 을 제시하는 방법

### (3) 모평균의 구간추정 (신뢰구간)

모집단이 정규분포 $N(\mu, \sigma^2)$을 따르고 표준편차 $\sigma$가 알려져 있을 때, 표본 크기 $n$에 따른 **$100(1-\alpha)\%$ 신뢰구간**은 다음과 같습니다.

$$\left( \bar{X} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \; \bar{X} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}} \right)$$

> **예제 풀이:** $N(100, 10^2)$ 분포에서 크기 $n=15$인 표본을 뽑아 표본평균 $\bar{x}=105$를 얻었을 때, 모평균에 대한 95% 신뢰구간은? ($z_{0.025} = 1.96$)
> $$105 \pm 1.96 \times \frac{10}{\sqrt{15}} = 105 \pm 5.06 = (99.94, \; 110.06)$$
>

## 7. 통계적 가설검정 및 실습

### (1) 귀무가설과 대립가설

* **귀무가설 (Null Hypothesis, $H_0$):** 기각되기를 기대하며 설정하는 **기본 가설** (변화 없음, 효과 없음, 기존 상태 유지)
* **대립가설 (Alternative Hypothesis, $H_1$):** 표본자료를 통해 **입증하고자 하는 새로운 주장** (변화 있음, 효과 있음)

| 검정 종류 | 귀무가설 ($H_0$) | 대립가설 ($H_1$) |
| --- | --- | --- |
| **양측가설** | $H_0: p = 0.5$ | $H_1: p \ne 0.5$ |
| **단측가설 (우측)** | $H_0: p = 0.5$ | $H_1: p > 0.5$ |
| **단측가설 (좌측)** | $H_0: p = 0.5$ | $H_1: p < 0.5$ |

### (2) 가설검정의 오류 종류

| 실제 상태 \ 검정 결정 | $H_0$ 채택 ($H_0$ 기각 불가) | $H_0$ 기각 ($H_1$ 채택) |
| --- | --- | --- |
| **$H_0$ 참 (실제 효과 없음)** | 올바른 결정 | **제 1종 오류 ($\alpha$)** |
| **$H_0$ 거짓 (실제 효과 있음)** | **제 2종 오류 ($\beta$)** | 올바른 결정 |

* **제 1종 오류 ($\alpha$):** 실제로는 귀무가설이 참인데, 잘못하여 **귀무가설을 기각**하는 오류 (더 위험하게 판단하는 경우가 많음)
* **유의수준 (Significance Level, $\alpha$):** 제 1종 오류를 범할 확률의 **최대 허용 한계** (보통 **0.05** 또는 **0.01** 로 설정)

### (3) 가설검정의 판단 기준: P-value

**P-value (유의확률)** 는 귀무가설이 참이라는 가정하에, 현재 관측된 통계량보다 더 극단적인 값이 나올 확률입니다.

* **$P\text{-value} < \alpha$ (유의수준):** 귀무가설 기각 **($H_1$ 대립가설 채택)** $\rightarrow$ "통계적으로 유의미하다!"
* **$P\text{-value} \ge \alpha$ (유의수준):** 귀무가설 기각 실패 **($H_0$ 유지)**

### (4) 가설검정 수행 단계

1. 가설 설정 ($H_0$ vs $H_1$)
2. 유의수준 ($\alpha$) 결정
3. 검정통계량 선택 및 계산
4. P-value 계산 (또는 기각역 확인)
5. 가설 기각 여부 판단 및 결과 해석

### (5) 파이썬 실습: 이항 검정 및 모평균 가설검정

#### 1) 이항 검정 실습

동전을 20번 던졌을 때 앞면이 15번 나왔다면, 이 동전은 공정한 동전($p=0.5$)일까요?

```python
import scipy.stats as stats

# x: 성공 횟수(15), n: 총 시도(20), p: 귀무가설 상 확률(0.5)
# alternative: 'two-sided', 'less', 'greater'
p_val = stats.binomtest(k=15, n=20, p=0.5, alternative='two-sided').pvalue

print(f"P-value: {p_val:.4f}")

if p_val < 0.05:
    print("귀무가설 기각: 이 동전은 공정하지 않습니다.")
else:
    print("귀무가설 기각 불가: 이 동전은 공정하다고 볼 수 있습니다.")

```

#### 2) 모평균 가설검정 (Z-test 함수 구현)

모표준편차 $\sigma=10$으로 알려진 정규분포 모집단에서 크기 $n=15$인 표본을 뽑은 데이터가 있을 때, 모평균이 100인지 검정합니다.

```python
import numpy as np
import scipy.stats as stats

def ztest(stat_data, mu, sigma):
    n = len(stat_data)
    x_bar = np.mean(stat_data)
    # Z 검정통계량 계산
    z_stat = (x_bar - mu) / (sigma / np.sqrt(n))
    # 양측검정 P-value 계산
    p_value = 2 * (1 - stats.norm.cdf(abs(z_stat)))
    return z_stat, p_value

# 샘플 데이터 생성
sample_data = np.array([102, 105, 98, 108, 104, 100, 101, 109, 103, 107, 102, 105, 104, 106, 103])

z_stat, p_val = ztest(sample_data, mu=100, sigma=10)

print(f"Z 통계량: {z_stat:.4f}")
print(f"P-value: {p_val:.4f}")

if p_val < 0.05:
    print("귀무가설 기각: 모평균은 100이 아닙니다.")
else:
    print("귀무가설 기각 불가: 모평균이 100이 아니라고 말할 증거가 부족합니다.")

```

* **귀무가설 ($H_0$):** "피고인은 무죄이다." (기존의 생각, 무죄 추정의 원칙)

* **P-value:** 피고인이 무죄라고 할 때, **이런 결정적 증거가 나올 확률**입니다. 이 확률이 `0.05`보다 작을 정도로 희귀한 증거라면, 판사는 **"피고인 무죄(귀무가설)를 기각하고 유죄(대립가설)를 선언"** 하게 됩니다!
