# 확률과 통계: 시각화 및 논리적 자료 요약 
 다양한 데이터의 형태를 알아보고, 데이터를 **시각적**이자 논리적(수치적)으로 요약하는 방법을 파이썬 라이브러리(`pandas`, `matplotlib`, `numpy`, `scipy`)

---

## 1. 자료의 형태 (Data Types)

데이터 분석을 시작할 때 가장 먼저 해야 할 일은 우리가 다룰 **자료의 형태**가 무엇인지 파악하는 것입니다. 자료의 성격에 따라 사용할 수 있는 통계 기법과 그래프가 달라지기 때문이죠.

### 자료의 분류 구조도

```
                    ┌── 수치형 자료 (Quantitative) ──┬── 연속형 자료 (Continuous)
                    │                              └── 이산형 자료 (Discrete)
자료 (Data) ────────┤
                    └── 범주형 자료 (Qualitative)  ──┬── 순위형 자료 (Ordinal)
                                                   └── 명목형 자료 (Nominal)

```

---

### 수치형 자료 vs 범주형 자료

| 구분 | **수치형 자료 (Numerical / Quantitative)** | **범주형 자료 (Categorical / Qualitative)** |
| --- | --- | --- |
| **개념** | 수치로 측정이 가능한 자료

 | 수치로 측정이 불가능한 자료

 |
| **예시** | 키, 몸무게, 시험 점수, 나이 등

 | 성별, 지역, 혈액형 등

 |
| **주요 분석 기법** | **선형 회귀 분석 (Linear Regression)** 등

 | **로지스틱 회귀 분석 (Logistic Regression)** 등

 |

#### 1) 수치형 자료의 세부 구분

* **연속형 자료 (Continuous Data):** 연속적인 관측값을 가집니다. (예: 원주율 $3.14159\dots$, 시간 $09:12:23.21\dots$)


* **이산형 자료 (Discrete Data):** 하나하나 셀 수 있는 관측값을 가집니다. (예: 동영상 조회수, 사고 건수)



#### 2) 범주형 자료의 세부 구분

* **순위형 자료 (Ordinal Data):** 범주 사이의 순서나 서열에 의미가 있습니다. (예: 학점 $A+, A, A-$, 만족도 조사)


* **명목형 자료 (Nominal Data):** 범주 사이의 순서에 의미가 없습니다. (예: 혈액형 $A, B, O, AB$, 성별)



---

### ⚠️ 자료 형태 구분 시 주의사항

* **숫자로 표현된 범주형 자료:** 남자를 `1`, 여자를 `0`으로 표현했더라도 이는 숫자의 형태를 띤 **범주형 자료**입니다.


* **수치형 자료의 범주화:** 나이 값 자체는 **수치형 자료**이지만, 이를 `10대`, `20대`, `30대`처럼 구간화하면 **범주형 자료**로 변환됩니다.


* **연속형과 이산형의 변환:** 시간 측정 시 $09:12:23.21\dots$은 **연속형 자료**지만, 실무에서 $09\text{시 } 12\text{분}$으로 반올림하여 표현하는 경우 **이산형 자료**처럼 취급하여 사용하기도 합니다.



### 🔍 쉬운설명

데이터를 사람에 비유해 볼게요! **수치형 자료**는 '줄자나 체중계로 잴 수 있는 몸무게나 키'처럼 숫자에 실제 크기와 의미가 있는 데이터입니다. 반면 **범주형 자료**는 '혈액형이 O형인지 A형인지, 사는 동네가 어디인지'처럼 나누어 놓은 '그룹 상자'에 가깝습니다. 만약 설문지에서 '남자=1, 여자=2'라고 적었다고 해도 2번 여자가 1번 남자보다 2배 더 크다는 뜻이 아니듯이, 단순한 구분표는 수치가 아니라 **범주**라는 점을 기억해 주세요!

## 2. 범주형 자료의 요약

범주형 자료는 관측값의 크기보다 **어떤 범주에 속해 있는지**가 중요합니다. 따라서 각 범주별 개수와 전체에서 차지하는 비율을 요약해야 합니다.

### 도수와 상대도수

* **도수 (Frequency):** 각 범주에 속하는 관측값의 개수.


* **상대도수 (Relative Frequency):** 도수를 자료의 전체 개수로 나눈 비율.



#### 파이썬 코드 명령어 예시

`pandas`의 `value_counts()` 함수를 활용하여 손쉽게 도수와 상대도수를 구합니다.

```python
import pandas as pd

# 도수(Frequency) 계산
df['범주'].value_counts()

# 상대도수(Relative Frequency) 계산
df['범주'].value_counts(normalize=True)

# 도수분포표(Cross Tabulation) 제작
# 1개 범주
pd.crosstab(index=df['범주'], columns='count')

# 2개 범주 (교차표)
pd.crosstab(index=df['범주1'], columns=df['범주2'])

```

---

### 범주형 시각화 그래프 비교

| 그래프 종류 | **원형 그래프 (Pie Chart)** | **막대 그래프 (Bar Chart)** |
| --- | --- | --- |
| **파이썬 함수** | `plt.pie(수치, labels=라벨)`<br> | `plt.bar(x=라벨, height=수치)`<br> |
| **장점** | 전체에서 각 범주가 차지하는 **비율 파악**이 쉬움

 | 각 범주의 **도수 크기 차이 비교**가 용이함

 |
| **단점** | 범주 간의 미세한 크기 차이 파악이 어려움

 | 전체 대비 비율을 한눈에 비교하기는 어려움

 |

### 🔍 쉬운설명

범주형 자료를 시각화할 때, **원형 그래프**는 '피자 한 판을 여러 명이 나누어 먹을 때 **누가 몇 퍼센트(%)를 먹었는지** 비율'을 보여줄 때 최고입니다. 반면 **막대 그래프**는 '누가 피자를 **몇 조각** 먹었는지' 높이 차이로 직관적인 **개수 비교**를 할 때 아주 유용합니다.

## 3. 수치형 자료의 요약 (시각화 기법)

수치형 자료는 관측값의 종류 수에 따라 요약 방법이 달라집니다.

```
연속형 자료 요약 기법
├── 점도표 (Dot Diagram)
├── 도수분포표 (Frequency Table)
├── 히스토그램 (Histogram)
├── 도수다각형 (Frequency Polygon)
└── 줄기-잎 그림 (Stem-and-Leaf Plot)

```

---

### 수치형 시각화 기법 핵심 요약

1. **점도표 (Dot diagram):** 관측값 개수가 $20\sim25$개 이하로 적을 때 수직선 위에 점을 찍어 표기합니다.


2. **도수분포표 (Frequency Table):** 연속형 자료를 계급(Class) 구간으로 나누고 각 구간의 관측값 개수를 측정합니다.


3. **히스토그램 (Histogram):** 계급구간을 가로축($X$), 빈도(도수)를 세로축($Y$)으로 하는 막대 모양의 그래프입니다.


* 파이썬: `plt.hist(data)`



4. **도수다각형 (Frequency Polygon):** 각 계급구간의 중앙에 점을 찍고 선으로 연결한 그래프입니다. **여러 자료를 동시에 비교**할 때 히스토그램보다 알맞습니다.


5. **줄기-잎 그림 (Stem-and-Leaf Plot):** 앞 단위를 `줄기(Stem)`, 뒷 단위를 `잎(Leaf)`으로 나누어 나타냅니다.


* 장점: 원본 관측값을 유지하면서 분포를 시각화함.


* 단점: 데이터 개수가 너무 많으면 표현이 불가능함.


* 파이썬: `plt.stem(stems, values)`




---


### 🔍 쉬운설명

**줄기-잎 그림**은 이름 그대로 수치를 쪼개는 것입니다. 예를 들어 점수가 $35$점, $38$점이라면 $3$을 **줄기**, $5$와 $8$을 **잎**으로 기재합니다. 이렇게 하면 그래프의 모양도 보이면서 실제 점수인 $35$와 $38$이라는 알맹이 데이터를 잃어버리지 않는 큰 장점이 있답니다!

## 4. 수치를 통한 연속형 자료 요약 (논리적 요약)

그림이나 그래프는 작성자의 주관이 들어갈 수 있지만, **수치적 요약**은 객관적인 수치로 분포 상태를 완벽하게 제시합니다.

```
               ┌── 1) 중심위치의 측도 (Mean, Median, Mode)
               ├── 2) 퍼진 정도의 측도 (Variance, Standard Deviation, IQR)
수치적 요약 ───┼── 3) 도수분포표에서의 수치 요약
               └── 4) 상자그림 (Boxplot)

```

---

### 1) 중심위치의 측도 (Measure of Center)

* **평균 (Mean):** 모든 관측값의 합을 전체 개수로 나눈 값(무게중심).



$$\bar{x} = \frac{\sum_{i=1}^{n} X_i}{n}$$


* 특징: 가장 널리 쓰이지만, 극단값(Outlier)의 영향을 크게 받음.




* **중앙값 (Median):** 오름차순 정렬 시 가운데 위치하는 값.


* 특징: **극단값의 영향을 받지 않음**.




* **최빈값 (Mode):** 가장 빈번하게 등장하는 값 (주로 범주형/이산형에 사용).



```python
import numpy as np
from scipy import stats

mean_val = np.mean(data)       # 평균
median_val = np.median(data)   # 중앙값
mode_val = stats.mode(data)    # 최빈값

```

#### 분포의 모양에 따른 비교

* **대칭 분포 (단봉형):** `평균` = `중앙값` = `최빈값`

* **오른쪽 꼬리가 긴 분포 (양의 비대칭):** `평균` > `중앙값`

* **왼쪽 꼬리가 긴 분포 (음의 비대칭):** `평균` < `중앙값`


---

### 2) 퍼진 정도의 측도 (Measure of Dispersion)

중심위치만으로는 데이터가 얼마나 넓게 퍼져 있는지 알 수 없기 때문에 **산포도 측도**가 반드시 필요합니다.

* **분산 (Variance, $s^2$):** 편차(관측값 - 평균) 제곱의 합을 $n$으로 나눈 값.



$$s^2 = \frac{\sum_{i=1}^{n} (x_i - \bar{x})^2}{n}$$


* **표준편차 (Standard Deviation, $s$):** 분산의 양의 제곱근 ($s = \sqrt{s^2}$). 원래 관측값과 단위가 일치함.


* **범위 (Range):** `최댓값 - 최솟값`.


* **사분위수 범위 (IQR):** 제3사분위수($Q_3$) - 제1사분위수($Q_1$). 중간 50% 데이터의 퍼짐 정도를 나타내며, 극단값에 강함.


* **변동계수 (CV):** $(\text{표준편차} / \text{평균}) \times 100$. 단위가 다른 두 집단의 퍼진 정도를 비교할 때 사용.



```python
# 범위 계산
data_range = np.max(data) - np.min(data)

# 사분위수 계산
q1 = np.percentile(data, 25)
q3 = np.percentile(data, 75)
iqr = q3 - q1

```

---

### 3) 상자그림 (Box Plot)

다섯 가지 요약 수치(**최솟값, $Q_1$, $Q_2$(중앙값), $Q_3$, 최댓값**)를 상자와 선(수염)으로 표현한 시각화 방법입니다.

```python
import matplotlib.pyplot as plt

plt.boxplot(data)
plt.show()

```

### 🔍 쉬운설명

데이터의 '평균'만 보고 판단하면 왜곡이 생길 수 있습니다. 예컨대 4명의 재산이 각각 1억 원이고, 1명이 100억 원이라면 평균 재산은 20억 8천만 원이 됩니다. 하지만 이 모임의 전형적인 모습을 보여주는 수치는 중앙값(1억 원)이죠! extreme한 값(극단값)이 존재할 때는 **중앙값**과 사분위수 범위(IQR)를 쓰는 것이 훨씬 현명하답니다.

## 5. 두 변수 자료의 요약

하나의 변수뿐만 아니라, **두 개 이상의 변수가 서로 어떤 관계를 맺고 있는지** 분석하는 방법입니다.

```
두 변수 자료 요약
├── 범주형 x 범주형 ──> 분할표 (Cross Tabulation)
└── 수치형 x 수치형 ──> 산점도 (Scatter Plot), 공분산 (Covariance), 상관계수 (Correlation)

```

---

### 두 수치형 변수의 관계 측정

1. **산점도 (Scatter Plot):** 두 변수의 관측값을 좌표평면에 점으로 나타낸 그래프.


* 파이썬: `plt.scatter(x, y)`



2. **공분산 (Covariance):** 두 변수가 함께 변하는 경향성을 나타냄.


* 양수: 같은 방향으로 변화 (증가할 때 증가)


* 음수: 반대 방향으로 변화 (증가할 때 감소)


* 파이썬: `df.cov()`



3. **피어슨 상관계수 (Correlation Coefficient, $r$):** 두 변수의 선형 관계 강도를 $-1$부터 $1$ 사이의 숫자로 나타냄.


* $r = +1$: 완벽한 양의 선형 관계


* $r = -1$: 완벽한 음의 선형 관계


* $r = 0$: 선형 관계가 없음


* 파이썬: `df.corr()`




```python
# 공분산 및 상관계수 구하기
cov_matrix = df.cov()
corr_matrix = df.corr()

```

---

### 🚨 상관관계 vs 인과관계 (주의사항)

**"상관계수가 높다고 해서 반드시 원인과 결과(인과관계)인 것은 아닙니다!"**

* **예시:** 여름철 '아이스크림 판매량'이 늘어날 때 '상어 공격 횟수'도 증가하여 두 변수의 상관계수가 매우 높게 나옵니다.


* **오해:** 아이스크림을 많이 먹어서 상어가 공격했다? (X)


* **실제 원인:** '여름철 기온 상승'이라는 숨겨진 제3의 변수(잠재변수)가 두 변수 모두에 영향을 미친 것입니다.



### 🔍 쉬운설명

상관계수가 높다는 건 두 수치가 '같이 움직인다'는 것을 뜻할 뿐, 하나가 다른 하나의 '원인'이라는 뜻은 아닙니다. 데이터를 분석할 때는 꼭 숨겨진 세 번째 원인(예: 계절, 날씨 등)이 없는지 깊이 있게 살펴보는 눈을 길러야 합니다!
