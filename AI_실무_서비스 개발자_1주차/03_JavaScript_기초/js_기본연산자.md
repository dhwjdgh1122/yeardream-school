## 자바스크립트 기본 연산자와 수학 (JavaScript Basic Operators)

자바스크립트에서는 일반적인 수학적 연산 외에도 자바스크립트 특유의 다양한 연산자 동작 규칙을 제공한다. 연산자의 종류와 특성을 명확히 이해하는 것이 중요하다.

---

### 1. 연산자 기본 용어 정리

* **피연산자(Operand):** 연산자가 연산을 수행하는 대상 (`5 * 2`에서 `5`와 `2`)
* **단항(Unary) 연산자:** 피연산자를 하나만 받는 연산자
* **이항(Binary) 연산자:** 피연산자를 두 개 받는 연산자

```javascript
// 단항 마이너스 연산자: 피연산자의 부호를 반전
let x = 1;
x = -x;
alert(x); // -1

// 이항 마이너스 연산자: 뺄셈 수행
let a = 1, b = 3;
alert(b - a); // 2

```

---

### 2. 기본 수학 연산자

자바스크립트가 지원하는 기본 산술 연산자는 다음과 같다.

* **덧셈:** `+`
* **뺄셈:** `-`
* **곱셈:** `*`
* **나눗셈:** `/`
* **나머지(Remainder):** `%` - $a$를 $b$로 나눈 후의 나머지 정수를 반환
* **거듭제곱(Exponentiation):** `**` - $a$를 $b$번 곱한 값을 반환

```javascript
// 나머지 연산자 (%)
alert(5 % 2); // 1
alert(8 % 3); // 2

// 거듭제곱 연산자 (**)
alert(2 ** 4); // 16 (2 * 2 * 2 * 2)
alert(4 ** (1/2)); // 2 (1/2 거듭제곱은 제곱근)

```

### 🔍 쉬운설명

💡 **`%`와 `**` 연산자는 몫 나누기와 제곱 계산기!**
`%`는 피자를 똑같이 나누어 먹고 남은 '조각 수'를 구하는 연산자다. 예를 들어 피자 5조각을 2명이 나누어 먹으면 1조각이 남는다.
`**`는 '세포 분열'처럼 특정 수를 지정한 횟수만큼 거듭해서 곱해준다.

---

### 3. 이항 연산자 `+`와 문자열 연결

이항 연산자 `+`는 피연산자 중 **하나라도 문자열이면** 다른 피연산자도 문자열로 자동 형 변환하여 병합한다.

```javascript
alert('1' + 2); // "12"
alert(2 + '1'); // "21"
alert(2 + 2 + '1'); // "41" (왼쪽부터 연산되므로 2+2=4 진행 후 '1'과 결합)

```

> **주의:** 뺄셈(`-`), 나눗셈(`/`) 등 다른 산술 연산자는 문자열 피연산자를 만나면 이를 **숫자형으로 자동 변환**하여 연산한다.

```javascript
alert(6 - '2'); // 4
alert('6' / '2'); // 3

```

---

### 4. 단항 연산자 `+`와 명시적 숫자 변환

`+`가 단항 연산자로 사용되면, 피연산자가 숫자형이 아닐 경우 **숫자형으로 변환**하는 역할을 수행한다. 이는 `Number(...)`와 동일하게 작동하는 짧은 문법이다.

```javascript
alert(+true); // 1
alert(+"");    // 0

let apples = "2";
let oranges = "3";

// 단항 +가 먼저 적용되어 문자열을 숫자로 변환한 뒤, 이항 +가 덧셈 수행
alert(+apples + +oranges); // 5

```

### 🔍 쉬운설명

💡 **단항 `+`는 '문자열 해독기'!**
웹 페이지 폼(Form)에서 입력받은 값은 모양이 숫터처럼 보여도 실제로는 모두 '문자열'이다. 이때 변수 앞에 단항 `+` 기호를 붙여주면 "이 문자는 숫자로 읽어라" 하고 변환해 주는 스위치 역할을 한다.

---

### 5. 연산자 우선순위 (Precedence)

하나의 표현식에 여러 연산자가 있을 때 실행 순서는 **우선순위 숫자**에 의해 결정되며, 높은 숫자가 먼저 실행된다.

| 순위 | 연산자 이름 | 기호 |
| --- | --- | --- |
| **17** | 단항 덧셈 / 부정 | `+`, `-` |
| **16** | 지수 (거듭제곱) | `**` |
| **15** | 곱셈 / 나눗셈 | `*`, `/` |
| **13** | 이항 덧셈 / 뺄셈 | `+`, `-` |
| **3** | 할당 | `=` |

> **핵심 규칙:** 단항 연산자(`+`)의 우선순위(17)가 이항 덧셈 연산자(`+`)의 우선순위(13)보다 높기 때문에 `+apples + +oranges` 연산 시 단항 변환이 먼저 처리된다.

---

### 6. 할당 연산자와 복합 할당 연산자

* **할당 연산자 (`=`):** 연산자 우선순위가 3으로 매우 낮아 계산이 모두 끝난 후 실행된다. 연산 후 결과를 반환하는 특징이 있다.
* **할당 연산자 체이닝:** 오른쪽부터 우측 평가 후 좌측으로 순차 할당된다. (가독성을 위해 줄바꿈 권장)
* **복합 할당 연산자 (`+=`, `*=`, `-=` 등):** 변수의 값을 연산 후 다시 자기 자신에 저장할 때 사용한다.

```javascript
// 할당 연산자 체이닝
let a, b, c;
a = b = c = 2 + 2; // a, b, c 모두 4 저장

// 복합 할당 연산자
let n = 2;
n += 5; // n = n + 5 (7)
n *= 3 + 5; // n *= 8 과 동일 (56) -> 오른쪽 식이 먼저 평가됨

```

### 7. 증가·감소 연산자 (`++`, `--`)

숫자를 1 늘리거나 줄일 때 사용하며, **변수에만 적용**할 수 있다.

* **전위형 (`++counter`):** 피연산자를 1 증가시킨 **후의 새로운 값**을 반환
* **후위형 (`counter++`):** 피연산자를 1 증가시키기 **전의 기존 값**을 반환

```javascript
let counter1 = 1;
let a = ++counter1;
alert(a); // 2 (전위형: 증가된 후 값 반환)

let counter2 = 1;
let b = counter2++;
alert(b); // 1 (후위형: 증가 전 값 반환)

```

> **작성 팁:** 코드의 가독성을 위해 한 줄에 하나의 동작만 작성하고, 표현식 중간에 `++`/`--`를 섞어 쓰는 것은 지양하는 것이 좋다.

### 🔍 쉬운설명

💡 **전위형과 후위형의 차이는 '선불/후불'!**

* **전위형 (`++x`):** **선불 방식.** 먼저 1을 더해 계산을 마친 따끈따끈한 새 값을 반환한다.
* **후위형 (`x++`):** **후불 방식.** 일단 지금 가지고 있는 원래 값을 꺼내서 사용하고, 그 작업이 끝난 뒤 뒤에서 몰래 1을 더해둔다.

### 8. 기타 연산자

#### 비트 연산자 (Bitwise Operator)

인수를 32비트 정수로 변환하여 이진 단위 조작을 수행한다. 웹 개발 시 직접 다룰 일은 적지만 암호화 등의 저수준 작업에 활용된다.

* 종류: `&` (AND), `|` (OR), `^` (XOR), `~` (NOT), `<<`, `>>`, `>>>` (시프트)

#### 쉼표 연산자 (Comma Operator)

여러 표현식을 한 줄에서 평가할 수 있게 해주며, **마지막 표현식의 평가 결과만 반환**한다. 우선순위가 `=`보다 낮다.

```javascript
let a = (1 + 2, 3 + 4);
alert(a); // 7 (1+2는 평가 후 버려지고 3+4 결과만 반환)

```

### 9. 핵심 연산자 요약 표

| 구분 | 연산자 | 주요 특징 및 동작 |
| --- | --- | --- |
| **단항 `+**` | `+x` | 피연산자를 숫자형으로 명시적 변환 |
| **이항 `+**` | `a + b` | 피연산자 중 문자열이 있으면 **문자열 연결** 수행 |
| **산술 연산자** | `-`, `*`, `/`, `%`, `**` | 항상 피연산자를 숫자형으로 다룸 |
| **복합 할당** | `+=`, `-=`, `*=` 등 | 우측 식을 먼저 평가 후 변수 재할당 |
| **증가/감소** | `++`, `--` | **전위형**은 변경 후 값, **후위형**은 변경 전 값 반환 |
| **쉼표 연산자** | `,` | 나열된 표현식을 순차 평가 후 **마지막 결과만 반환** |

#### 연산자 동작 처리 흐름도

```text
[ 표현식 평가 시작 ]
         │
         ├─ 단항 + 연산자 발견 ────────► 피연산자를 숫자형(Number)으로 변환
         │
         ├─ 이항 + 연산자 발견 ────────► 피연산자 중 문자열 존재?
         │                                   ├─ YES ──► 문자열 결합 (String)
         │                                   └─ NO  ──► 숫자 덧셈 (Number)
         │
         ├─ 기타 산술 연산자(-, *, / 등) ─► 모든 피연산자를 숫자형으로 변환 후 연산
         │
         └─ ++ / -- 연산자 위치 ───────► 전위형(++x): 증가 후 값 반환
                                             └─ 후위형(x++): 증가 전 기존 값 반환

```
