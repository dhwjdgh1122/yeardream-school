# 함수 표현식

기본 함수 선언문 방식으로 함수를 만들었을 때는

```js
function sayHi() {
  alert('hello');
}
```

위처럼 작성했다면,

함수 표현식을 사용해서 생성할 수 있다.


```js
let sayHi = function () {
  alert('hello');
};
```

함수를 생성하고 변수에 값을 할당하는 것처럼 함수가 변수에 할당되었다.

- 함수를 만들고 그 함수를 변수 `sayHi`에 할당하기

함수는 값이기 때문에 `alert`를 이용하여 함수 코드를 출력할 수도 있다.

```js
function sayHi() {
  alert('hello');
}

alert(sayHi); // 함수 코드가 보인다.
```

마지막 줄에서 `sayHi` 옆에 괄호가 없기 때문에 함수는 실행되지 않는다. 자바스크립트에서 함수는 값이다. 따라서 함수를 값처럼 취급할 수 있다. 위 코드에선 함수 소스코드가 문자형으로 바뀌어 출력된다.


# 콜백 함수

함수를 값처럼 전달하는 예시, 함수 표현식에 관한 예시를 살펴보자

매개변수가 3개 있는 함수, `ask(question, yes, no)`를 작성

각 매개변수에 대한 설명은 아래와 같다.

`question` - 질문

`yes` - "yes"라고 답한 경우 실행되는 함수

`no` - "no"라고 답한 경우 실행되는 함수

함수는 반드시 `question(질문)`을 해야 하고, 사용자의 답변에 따라 `yes()`나 `no()`를 호출한다.



```js
function ask(question, yes, no) {
  if (confirm(question)) yes()
  else no();
}

function showOk() {
  alert('동의');
}

function showCancel() {
  alert('취소버튼');
}

ask("동의하십니까?", showOk, showCancel);
```

### 동작 순서

1. 함수 선언 및 메모리 등록
   - `ask`, `showOk`, `showCancel` 함수 3개가 만들어지고 실행 준비를 마친다.
   `ask` 함수는 3개의 빈 박스(매개변수 `question`, `yse`, `no`)를 가지고 있다.

2. `ask(...)` 함수 호출
   - ```js
     ask("동의하십니까?", showOk, showCancel);
     ```
   - `ask` 함수를 호출하면서 3개의 인수(값)를 전달한다.
   - 첫 번째 인수 : 문자열 `"동의하십니까?"`
   - 두 번째 인수 : 함수 `showOk` (괄호 () 없이 이름만 전달하여 함수 자체를 전달한다.)
   - 세 번째 인수 : `showCancel` 함수 자체를 전달한다.

3. 매개변수 값 전달 및 복사
   - `ask` 함수 선언부의 매개변수 박스 안으로 전달받은 값들이 복사된다.
   - `question` <- `"동의하십니까?"`
   - `yes` <- `showOk` ( `yes()`를 부르면 `showOk()`가 실행됨)
   - `no` <- `showCancel` (`no()`를 부르면 `showCancel()`이 실행됨)

4. `ask` 함수 내부 본문 실행
   - ```js
      if (confirm(question)) yes()
      else no();
      ```
   - `confirm("동의하십니까?")` 확인창이 브라우저에 뜬다.
  
5. 사용자 선택에 따른 분기 실행
   - 확인을 누른 경우 (`confirm` 결과가 `true`)
   1. `if(true)` 가 되어 `yes()` 가 실행되다.
   2. `yes` 상자 안에는 `showOk` 함수가 들어있으므로, 결국 `showOk()`가 호출된다.
   3. `showOk()` 내부 코드가 실행되어 `alert("동의하셨습니다.")` 창이 뜬다.

   - 취소를 누른 경우 (`confirm` 결과가 `false`)
   1. `else` 문으로 넘어가 `no()`가 실행된다.
   2. `no`상자 안에는 `showCancel` 함수가 들어있으므로, 결국 `showCancel()`가 호출된다.
   3. `showCancel` 내부 코드가 실행되어 `alert("취소 버튼")` 창이 뜬다.

### 핵심

- `showOk()` 가 아닌 `showOk`를 전달한 이유
   - `showOk()` 처럼 괄호를 붙이면 "함수를 즉시 실행한 결과값"을 전달하라는 의미가 된다.
   - 괄호 없이 `showOk` 만 쓰면 "함수 모양 그 자체(레시피)"를 전달하는 것이며, 나중에 `ask` 함수 내부에서 상황에 맞게 실행(`yes()` 또는 `no()`)하게 된다.



**함수 `ask`의 인수, `showOk`와 `showCancel`은 콜백 함수 또는 콜백이라고 부른다.**


아래와 같이 함수 표현식을 사용하면 코드 길이가 짧아진다.

```js
function ask(question, yes,no) {
  if(confirm(question)) yes()
  else no();
}

ask(
  "동의하십니까?",
  function () { alert("동의");},
  function () { alert("취소버튼");}
);
```

`ask(...)` 안에 함수를 선언했고, 이렇게 이름 없이 선언한 함수는 **익명 함수**라고 부른다. 익명 함수는 (변수에 할당된 게 아니기 때문에). `ask` 바깥에선 접근할 수 없다.



# 함수 선언문 vs 함수 표현식

차이에 대해 알아보자.

첫 번째는 문법이다.

- 함수 선언문 : 함수는 주요 코드 흐름 중간에 독자적인 구문 형태로 존재한다.

```js
// 함수 선언문
function sum(a,b) {
  return a+b;
}
```

- 함수 표현식 : 함수는 표현식이나 구문 구성 내부에 생성된다.
```js
// 함수 표현식
let sum = function(a,b) {
  return a+b;
};
```

두 번째 차이는 자바스크립트 엔진이 언제 함수를 생성하는지에 있다.

**함수 표현식은 실제 실행 흐름이 해당 함수에 도달했을 때 함수를 생성한다. 따라서 실행 흐름이 함수에 도달했을 때부터 해당 함수를 사용할 수 있다.**

**함수 선언문은 함수 선언문의 정의되기 전에도 호출할 수 있다.**

이게 가능한 이유는 내부 알고리즘 때문이다. 자바스크립트는 스크립트를 실행하기 전, 준비단계에서 전역에 선언된 함수 선언문을 찾고, 해당 함수를 생성한다.



# 정리

함수 선언문과 함수 표현식 중 무엇을 선택해야 할까?

함수 선언문을 이용해 함수를 선언하는 걸 먼저 고려하는 게 좋다. 함수 선언문으로 함수를 정의하면, 함수가 선언되기 전에 호출할 수 있어서 코드 구성을 좀 더 자유롭게 할 수 있으며 가독성이 좋다.

그러나 함수 선언문을 사용하는게 부적절할 때는 함수 표현식을 사용하는 것이 좋다.


추가로 설명을 하자면,

일단 함수 선언문으로 작성을 하고, 만약 `if`문 안에서 조건부로 함수를 생성해야 하거나, 변수나 콜백 자리(인수)에 바로 념겨줘야 할 때만 함수 표현식으로 전환하자.
