# 논리 연산자

자바스크립트엔 세 종류의 논리 연산자 `||`(OR), `&&`(AND), `!`(NOT)이 있다.



# || (OR)
'OR' 연산자는 두 개의 수직선 기호로 만들 수 있다.

```js
result = a || b;
```

전통적인 프로그래밍에서 OR 연산자는 불린값을 조작하는 데 쓰인다. 인수 중 하나라도 `true`이면 `true`를 반환하고, 그렇지 않으면 `false`를 반환한다.

```js
alert( true || true); // true
alert( false || true); // true
alert( true || false); // true
alert( false || false); // false
```

피연산자가 불린형이 아니면, 평가를 위해 불린형으로 반환된다.

예를 들어, 연산 과정에서 숫자 `1`은 `true`로, 숫자 `0`은 `false`로 바뀐다.

```js
if (1 || 0) { // ture || false 와 동일하게 동작
  alert(truthy);
}
```

OR 연산자 `||`은 `if`문에서 자주 사용한다.

```js
let hour = 12;
let isWeekend = true;

if(hour < 10 || hour >18 || isWeekend) {
  alert("영업시간이 아닙니다"); // 주말이기 때문에
}
```

# 첫 번째 truthy를 찾는 OR 연산자 '||'

피연산자가 불린형인 경우만을 다루는 거 이외에도 자바스크립트에서만 제공하는 논리연산자 'OR'의 '추가'기능에 대해 알아보자

추가 기능은 아래와 같은 알고리즘으로 동작한다.

OR 연산자와 피연산자가 여러 개인 경우:

```js
result = value1 || value2 || value3;
```

이때, OR `||` 연산자는 다음 순서에 따라 연산을 수행한다.

- 가장 왼쪽 피연산자부터 시작해 오른쪽으로 나아가며 피연산자를 평가한다.
- 각 피연산자를 불린형으로 변환한다. 변환 후 그 값이 `true`이면 연산을 멈추고 해당 피연산자의 **변환 전** 원래 값을 반환한다.
- 피연산자 모두를 평가한 경우(모든 피연산자가 `false`로 평가되는 경우)엔 마지막 피연산자를 반환한다.

핵심은 **반환 값이 형 변환을 하지 않은 원래 값이라는 것이다.**

정리하면, OR `||` 연산자를 여러 개 체이닝(chaining)하면 첫 번째 truthy를 반환한다. 피연산자에 truthy가 하나도 없다면 마지막 피연산자를 반환한다.


```js
alert( 1 || 0); 
```
1. 왼쪽 피연산자 `1` 확인
2. 숫자 `1`을 불린형으로 평가하면 `truthy`(참으로 간주)
3. `||` 연산자는 `truthy`를 만나면 뒤에 뭐가 오든 전체 결과가 참이라는 것을 알기 때문에, 오른쪽 피연산자 `0`는 쳐다보지도 않고 즉시 평가를 멈춘다.
4. 변환되기 전의 원래 값인 `1`을 그대로 반환한다.


# 핵심 원리 심화: Truthy / Falsy와 타입
### 1. Truthy / Falsy의 판별 기준

자바스크립트 엔진이 피연산자를 true로 볼 것인가 false로 볼 것인가 판단하는 기준은 정해진 Falsy 목록이다.

- Falsy (거짓으로 평가되는 8가지 값):
false, 0, -0, 0n(BigInt), ""(빈 문자열), null, undefined, NaN

- Truthy (참으로 평가되는 값):
위 8가지 Falsy 목록을 제외한 나머지 모든 값
(예: 0이 아닌 숫자 3, 비어있지 않은 문자열 "바이올렛", 빈 배열 [], 빈 객체 {} 등)

### 2. 불린 평가 시 주의점 (typeof는 변하지 않음)

- 피연산자가 조건문이나 논리 연산자 내부에서 truthy로 평가되더라도, 값 자체의 타입(typeof)이 불린형으로 변경되는 것은 아니다.

- 예를 들어 typeof 3은 여전히 "number"이며, "바이올렛"의 typeof 역시 "string"이다.

- 자바스크립트 엔진은 평가 과정에서만 '참 같은 값(truthy)'으로 참/거짓 판정을 수행하고, 최종 결과는 타입 변환이 일어나지 않은 원래 형태의 값을 그대로 전달한다.


```js
let firstName = "";
let lastName = "";
let nickName = "바이올렛";

alert( firstName || lastName || nickName || "익명" ); // "바이올렛"
```

firstName("")과 lastName("")은 Falsy(빈 문자열)이므로 통과.

nickName("바이올렛")은 비어있지 않은 문자열이므로 Truthy로 판정.

평가를 즉시 중단하고 원래 타입인 문자열 "바이올렛"을 그대로 반환하여 출력함.


##  단락 평가

위에서 말했다시피, OR `||`은 왼쪽부터 시작해서 오른쪽으로 평가를 진행하는데, truthy를 만나면 나머지 값들은 건드리지 않은 채 평가를 멈춘다. 이런 프로세스를 `단락 평가` 라고 한다.

단락 평가의 동작 방식은 두 번째 피연산자가 변수 할당과 같은 부수적인 효과를 가지는 표현식 일 때 명확히 볼 수 있다.

아래 코드를 실행하면 두 번째 메시지만 출력된다.

```js
true || alert("not print");
false || alert("print");
```

첫 번째 줄의 `||` 연산자는 `true`를 만나자마자 평가를 멈추기 때문에 `alert`가 실행되지 않는다.

단락 평가는 연산자 왼쪽 조건이 falsy일 때만 명령어를 실행하고자 할 때 자주 쓰인다.


# && (AND)

AND 연산자 `&&`

```js
result = a && b;
```

AND 연산자는 두 피연산자가 모두 참일 때 `true`를 반환한다. 그 외의 경우는 `false`를 반환한다.

```js
alert( true && true );   // true
alert( false && true );  // false
alert( true && false );  // false
alert( false && false ); // false
```

```js
let num1 = 1;
let num2 = 2;

if (num1 ==1 && num2 ==2) {
  alert("num1과 num2 정상출력");
}
```

OR 연산자와 마찬가지로 AND 연산자의 피연산자도 타입에 제약이 없다.

```js
if (1 && 0) 
```
- 피연산자가 숫자형이지만 불린형으로 바뀌어 true && false가 된다.


# 첫 번째 falsy를 찾는 AND 연산자 &&

```js 
result = value1 && value2 && value3;
```

1. 가장 왼쪽 피연산자부터 시작해 오른쪽으로 나아가며 피연산자를 평가한다.
2. 각 피연산자는 불린형으로 변환된다. 변환 후 값이 `false`면 평가를 멈추고 해당 피연산자의 **변환 전** 원래 값을 반환한다.
3. 피연산자 모두가 평가되는 경우(모든 피연산자가 `true`로 평가되는 경우)엔 마지막 피연산자가 반환된다.


위 동작 순서 알고리즘은 OR 연산자의 알고리즘과 유사하다.

차이점은 OR 연산자는 첫 번째 truthy를 반환하지만, AND 연산자는 첫 번째 falsy를 반환한다.

정리하자면 평가 중단 조건은 OR은 `truthy`를 만났을 때이고, AND는 `false`를 만났을 때이다.


### `&&`의 우선순위가 `||` 보다 높다.
- 우선순위 `AND` > `OR`



# ! (NOT)

논리 연산자 NOT의 기본 문법

```js
result = !value;
```

`NOT` 연산자는 인수를 하나만 받고, 다음 순서대로 연산을 수행한다.

1. 피연산자를 불린형`(true / false)`으로 변환한다.
2. 1에서 변환된 값의 역(반대)을 반환한다.

```js
alert( !true); // false
alert( !0); // true
```

내장 함수 `Boolean`을 사용하면 `!!`을 사용한 것과 같으 결과를 도출할 수 있다.

그럼 `!!`은 결국 역으로 반환했다고 다시 역으로 반환하는거면 제자리 걸음인데 왜 써야하고 언제 쓰는걸까? 라고 생각이 들 수 있다.

"어떤 값이 있는지 없는지 여부를 오직 `ture / false` 딱 2개로만 명확히 딱 잘라서 표현하고 싶을때 사용한다.

## 사용자 "로그인 여부"를 확인할 때

회원 정보를 다룰 때 `user` 변수에는 사용자 정보 객체 `{name: "오정호", id: 123}`가 들어있거나, 로그아웃 상태라면 `null`이 들어있다.


1. `!!`를 안쓸때
```js
let user = { name: "오정호", id: 123 };

let isLoggedIn = user; // isLoggedIn에 객체 전체가 그대로 들어감
console.log(isLoggedIn); // { name: "오정호", id: 123 }
```
- 로그인했니? 라고 물어봤는데 "응" 이라고 대답하는게 아니라 "오정호,id는123이야"라고 내 정보를 통째로 대답한다.

2. `!!`를 쓸때
```js
let user = { name: "오정호", id: 123 };

let isLoggedIn = !!user; // user 객체를 명확한 true/false로 변환
console.log(isLoggedIn); // true
```

- 객체 안에 뭐가 들었든 상관없이, 오직 **"로그인함(true)"** 또는 **"로그인 안함(false)"** 이라는 신호만 남겨서 다른 코드에 전달할 수 있다.
