# 자바스크립트 기본 상호작용 : alert, prompt, confirm 

웹페이지를 이용하다 보면 안내창이 뜨거나, 입력값을 요구하는 창을 흔히 볼 수 있다. 자바스크립트에서는 브라우저와 사용자가 상호작용할 수 있도록 최소한의 기본 UI 기능 3가지를 제공한다.

바로 `alert`, `prompt`, `confirm`이다. 각각의 역할과 사용법, 그리고 차이점을 명확히 알아본다.

---

# 모달(Modal) 창이란?

오늘 다룰 3가지 함수가 실행되면 브라우저 화면 중앙에 작은 창이 하나 생성된다. 이를 모달 창(Modal Window)이라고 부른다.

## 💡 모달(Modal)의 핵심 특징

* **상호작용 제약**: 모달 창이 떠 있는 동안은 페이지의 나머지 부분과 상호작용할 수 없다.
* **실행 중단**: 사용자가 '확인'이나 '취소' 버튼을 누르기 전까지 바깥의 다른 버튼을 클릭하거나 텍스트를 드래그할 수 없으며, **스크립트 실행도 잠시 정지**된다.

```
┌────────────────────────────────────────────────────────┐
│  웹페이지 (클릭 불가, 일시 정지 상태)                     │
│                                                        │
│        ┌──────────────────────────────────────┐        │
│        │ [ 모달 창 ]                          │        │
│        │ 메시지 내용...                       │        │
│        │                [확인]  [취소]        │        │
│        └──────────────────────────────────────┘        │
│                                                        │
└────────────────────────────────────────────────────────┘

```

### 🔍 쉬운설명

모달 창은 '식당의 호출 벨'이나 '도로의 일시정지 표지판'과 같다. 운전을 하다가 일시정지 표지판을 만나면 차를 완전히 멈추고 확인을 해야만 다시 출발할 수 있듯이, 브라우저도 모달 창이 뜨면 사용자가 답변(버튼 클릭)을 줄 때까지 모든 작업을 멈추고 기다리는 것이다.

---

## 1. alert - 단순 메시지 전달

사용자에게 **단순한 알림이나 경고 메시지**를 전달할 때 사용한다.

```javascript
alert("Hello JavaScript!");

```

* 사용자가 **'확인'** 버튼을 누를 때까지 창이 유지된다.
* 메시지만 보여주는 역할이므로 **반환값(Return value)이 없다(`undefined`).**

### 🔍 쉬운설명

`alert`는 일종의 '단방향 확성기'다. "선생님, 다음 주 월요일은 휴강입니다!" 하고一方적으로 정보만 전달한 뒤, 상대방이 "네(확인)"라고 고개를 끄덕이면 자기 할 일을 끝내는 것과 같다.

---

## 2. prompt - 사용자에게 값 입력받기

사용자에게 메시지를 보여줌과 동시에, 텍스트를 직접 입력받을 수 있는 입력 필드(Input)를 제공한다.

### 기본 문법

```javascript
let result = prompt(title, [default]);

```

* `title`: 사용자에게 보여줄 안내 문자열
* `default`: 입력 필드에 처음에 채워둘 **기본값 (선택 사항)**

### 사용 예시

```javascript
let age = prompt('나이를 입력해주세요.', '');
alert(`당신의 나이는 ${age}살입니다.`);

```

### 💡 prompt의 반환값

* **확인 클릭 시**: 입력 필드에 작성한 **문자열**을 반환
* **취소 / ESC 클릭 시**: `null`을 반환

📌 **개발자 꿀팁!**
`default` 값은 생략해도 작동하지만, 구형 브라우저(예: Internet Explorer)에서의 버그 방지 및 코드 안정성을 위해 입력할 기본값이 없더라도 빈 문자열(`''`)이라도 넣어주는 습관을 들이는 것이 좋다.

### 🔍 쉬운설명

`prompt`는 '기입식 설문지'다. "이름을 적어주세요 [    ]" 라고 써있는 종이를 건네는 것과 같다. 사용자가 이름을 적고 내면(`확인`) 작성한 글자가 전달되고, 종이를 그냥 구겨서 버리면(`취소/ESC`) 아무것도 제출하지 않은 상태(`null`)가 된다.

---

## 3. confirm - 확인 / 취소 선택받기

사용자에게 **예/아니오(Yes/No)** 형태의 질문을 던지고 선택을 받을 때 사용한다.

### 사용 예시

```javascript
let isHuman = confirm("당신은 사람인가요?");
alert(isHuman); 

```

### 💡 confirm의 반환값

* **'확인' 클릭 시**: `true` 반환
* **'취소' / ESC 클릭 시**: `false` 반환

### 🔍 쉬운설명

`confirm`은 '찬반 투표함'이다. "정말로 이 파일을 삭제하시겠습니까?"라는 질문에 [도장(확인)]을 찍으면 `true`가 되고, [거절(취소)]을 누르면 `false`가 되어 이후 로직을 조건문(`if`)으로 나누어 처리할 수 있게 해준다.

---

## 📝 한눈에 보는 요약표

| 함수 | 주요 역할 | 확인 클릭 시 반환값 | 취소/ESC 클릭 시 반환값 |
| --- | --- | --- | --- |
| `alert` | 단순 메시지 보여주기 | 없음 (`undefined`) | 없음 (`undefined`) |
| `prompt` | 텍스트 입력받기 | 입력한 **문자열** | `null` |
| `confirm` | 참/거짓 선택받기 | `true` | `false` |

---

## ⚠️ 자바스크립트 기본 대화상자의 한계

이 3가지 함수는 사용하기에 매우 편리하지만, 실제 서비스 중인 웹사이트(쇼핑몰, SNS 등)에서는 잘 쓰이지 않는다.

1. **디자인 변경 불가**: 브라우저 기본 OS/스타일로만 출력되므로 CSS를 통한 디자인 스타일링이 불가능하다.
2. **페이지 실행 일시 정지**: 모달 창이 열려 있는 동안 웹페이지 전체의 렌더링과 동작이 일시 정지된다.

따라서 실무에서는 HTML, CSS, JavaScript나 프레임워크(React, Vue 등)를 활용하여 직접 디자인하고 제어할 수 있는 '커스텀 모달(Custom Modal)'을 주로 제작하여 사용한다.

### 🔍 쉬운설명

`alert`, `prompt`, `confirm`은 '순정 순정 피처폰의 기본 폰트와 알림창'과 같다. 간단하게 쓰기엔 좋지만 예쁘게 꾸밀 수 없다. 반면 실무에서 쓰는 커스텀 모달은 '스마트폰 앱 내의 예쁜 디자인 팝업'처럼 브랜드에 맞게 자유자재로 꾸며서 사용하는 것이다.

기본 대화상자의 작동 원리와 반환값 개념을 단단하게 잡아두면, 향후 커스텀 모달을 제작하고 제어할 때도 훨씬 쉽게 이해할 수 있다.
