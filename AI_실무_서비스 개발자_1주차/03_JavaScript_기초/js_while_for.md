# while, for 반복문

여러 동작을 반복해야하는 경우, 반복문을 사용해서 동일한 코드를 여러 번 반복하는 기능을 쓰자


## while 반복문

```js
while (condition) {
  // 코드
  // '반복문 본문(body)`이라 불림 
}
```

`condition`(조건)이 truthy 이면 반복문 본문의 코드가 실행된다.

```js
let i =0;
while (i<3) {
  alert(i);
  i++;
}
```
1. 변수 i는 처음에 0의 값이 들어가있음
2. i가 3보다 작을때까지 반복한다
3. 화면에i를 출력을
4. 변수 i는 계속 증가한다
5. 처음엔 0이므로 3보다 작다 0출력
6. i++ 실행, i는 1이됨, 3보다 작으니 1출력
7. 반복
8. i가 3이되었음 더 이상 실행되지 않음 

i++가 없었다면 이론적으로 반복문이 영원히 반복되었을거임 why? i는 영원히 0의 값이 들어가있기 때문에 계속 truthy이기 때문에 0을 출력, 하지만 i++으로 i가 3이 된순간 false이기 때문에 더 이상 본문(body)를 실행하지 않아서 종료된다.


# for 반복문
```js
for (begin; condition; step) {
  // 반복문 본문
}
```

```js
for (let i=0; i<3; i++) {
  alert(i);
}
```
변수 i가 3보다 작을때까지 i를 출력하고 i는 증가된다.



# 반복문 빠져나오기 break

반복문의 조건이 falsy가 되면 반복문이 종료된다. 하지만 특별한 지시자인 break를 사용하면 언제든 원하든 때에 반복문을 빠져나올 수 있다.

```js
let sum = 0;

while (true) {

  let value = +prompt("숫자를 입력하세요.", '');

  if (!value) break; // (*)

  sum += value;

}
alert( '합계: ' + sum );
```

- `+prompt` 에서의 `+`은 단항 플러스 연산자로써, 피연산자가 숫자가 아니면 숫자형으로 강제 변환한다.
- `prompt`는 사용자가 입력하는 텍스트를 문자열(String)으로 받아들이기 때문이다.
