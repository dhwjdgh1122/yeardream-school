# nullish 병합 연산자 '??'

nullish 병합 연산자 `??`를 사용하면 짧은 문법으로 여러 피연산자 중 그 값이 '확정되어있는' 변수를 찾을 수 있다.

`a ?? b` 의 평가 결과는 다음과 같다.

- `a`가 `null`도 아니고 `undefined`도 아니면 `a`
- 그 외의 경우는 `b`

nullish 병합 연산자 `??` 없이 `x = a ?? b`와 동일한 동작을 하는 코드를 작성하면 다음과 같다.

```js
x = (a !== null && a !== undefined) ? a : b;
```

또 다른 예시로 `firstName`, `lastName`, `nickName` 이란 변수에 사용자 이름이나 별명을 저장하는데, 사용자가 아무런 정보도 입력하지 않는 케이스도 허용한다고 가정하자.

화면엔 세 변수 중 실제 값이 있는 변수의 값을 출력하는데, 세 변수 모두 값이 없다면 '익명의 사용자'가 출력되도록 해보자

이럴 때 nullish 병합 연산자 `??`를 사용하면 값이 정해진 변수를 간편하게 찾을 수 있다.

```js
let firstName = null;
let lastName = null;
let nickName = "바이올렛";

// null이나 undefined가 아닌 첫 번째 피연산자
alert(firstName ?? lastName ?? nickName ?? "익명의 사용자"); // 바이올렛
```

# 핵심 정리

Nullish 병합 연산자 `??`는 왼쪽 피연산자가 `null` 또는 `undefined`일 때만 오른쪽 값을 반환하는 논리 연산자이다.



### OR 연산자 `||` 와의 차이:
 - `||` 연산자는 `0`, `""(빈문자열)`, `false` 등도 falsy로 취급하여 대체값을 반환하지만, `??`는 이 값들을 유요한 값으로 인정한다.


```js
// OR 연산자 (||)
console.log(0 || 100);       // 100 (0을 falsy로 취급)
console.log("" || "기본값");  // "기본값" (""을 falsy로 취급)

// Nullish 병합 연산자 (??)
console.log(0 ?? 100);       // 0 (0을 유효한 값으로 취급)
console.log("" ?? "기본값");  // "" (""을 유효한 값으로 취급)
console.log(null ?? 100);    // 100
```


숫자 `0` 이나 빈 문자열 `""`을 기본값으로 덮어씌우지 않고 유지해야 하는 옵션 설정이나 데이터 처리 작업 시 `??`를 사용한다.
